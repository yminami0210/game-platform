# 使用している素材とライセンス

第三者の素材（ライブラリ、フォント、画像、音源）は使用していません。

| 種別 | 内容 | 出所 |
|---|---|---|
| コード | index.html / style.css / app.js / tools/*.mjs | このリポジトリのオリジナル |
| 脚本 | scenarios/*.json | このリポジトリのオリジナル |
| 見取り図 | app.js が SVG で描画 | このリポジトリのオリジナル |
| フォント | 端末の標準フォント（明朝体指定） | 端末依存・同梱なし |

開発時の動作確認に Playwright（Apache-2.0）を使いますが、配布物には含みません。
