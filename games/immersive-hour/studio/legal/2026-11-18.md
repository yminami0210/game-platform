## 項目別

### 1. 外部ライブラリ・フォント・画像・音 — GREEN
- index.html の外部参照は `style.css` と `app.js` のみ。CDN・Webフォント・img・audio なし（Grep 確認）。
- font-family はOS搭載フォント名の指定のみ（Hiragino Mincho ProN / Yu Mincho / Noto Serif JP / ui-monospace）。同梱・配信はしていない。
- 第三者ライブラリなし。tools/e2e.mjs は Playwright を使うが開発用で配布物ではない。公開時に package.json 等を足すなら LICENSES.md に記載。
- 対応案: 公開時にリポジトリ LICENSE（コード／脚本の扱い）を決め、decisions.md に記録。

### 2. 名称リスク — YELLOW

- 「汐見ホテル」: 同名のイマーシブ公演は検索で見つからず。「汐見」は一般的な地名・姓で、実在の宿泊施設・温浴施設名（汐見の湯 等）が存在しうる。架空である旨は README に記載済み。リスク低〜中。対応: 公開時に「実在の施設・団体・人物とは無関係」の一文を足す。
- 止めるのは私: 同名の作品は見つからず。リスク低。
- 四十一通目: 同名作品は見つからず（近接は井上ひさし『四十一番の少年』だが別題）。リスク低。

### 3. 「イマーシブシアター」の使用 — GREEN（一部留意）
- 検索では報道等で一般名詞として広く使われており、商標登録の情報は確認できなかった（未登録の証明ではない）。
- README は説明的・記述的な使用（「イマーシブシアター形式のブラウザゲーム」）で、特定公演との関連をほのめかしていない。
- 留意: 「イマーシブ・フォート」「HOTEL ALBERT」等の個別名称・ロゴを公開文言に出さない。タイトル/ロゴに「イマーシブシアター」を含めて商標的に使う場合は J-PlatPat で確認。

### 4. 個人情報・認証情報・外部送信 — GREEN
- 外部送信なし。fetch は同一オリジンの `scenarios/*.json` のみ。sendBeacon / XHR / WebSocket なし。
- localStorage は端末内のみ（try/catch 付き）。考察メモは端末内保存。
- 共有（app.js:468-476）は「進み具合を共有」ボタンのクリック時のみ `navigator.share` / `clipboard.writeText` を呼ぶ。利用者操作起点で、内容は周回数・手がかり名のみ（個人情報なし）。
- 認証情報・トークンの混入は、対象ディレクトリのファイルと git 履歴の簡易grepでは検出されず。
- 共有文末のハッシュタグ `#最後の一時間` は実在タグと衝突しうるが、権利上の問題は軽微（タイトル確定時に見直し）。
