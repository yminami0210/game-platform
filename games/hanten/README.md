# 反転一行

一分で読める超短編を、毎週一本。**最後の一行で、物語全体の意味が変わる。**

先行作（七分の叙述トリックノベル）のレビューで「拡散するのは答え合わせではなく、ラストの一行」と分かったので、それを形式にした。

- 依存なしの静的サイト（HTML / CSS / JS）。GitHub Pages にそのまま置けば動く。スマホ縦優先、ダーク／ライトは OS に追従。
- 一覧（`./`）→ 各話（`./?id=001`）。各話はタップ（またはスペース／Enter）で一段落ずつ進み、最後の一行だけ間をあけて出る。
- 読了した話には一覧で「読了」の印がつく（`localStorage`。使えない環境でも読める）。
- 外部画像・外部フォント・アクセス解析・外部通信なし。共有ボタンを押したときだけ、端末の共有機能（または X の投稿画面）に共有文と URL が渡る。
- 音は使わない（スマホは無音で読まれるため）。

## 共有の方針

**ラストの一行は、共有カードにも共有文にも載せない。** 載せると本編を開く理由がなくなる。
かわりに「最初の一行」と「最後の一行で、この意味が変わる。」を載せる。

- 共有 URL は `w/NNN.html`（作品ごとの OGP メタ入りページ。開くとすぐ `?id=NNN` に移る）。
- OGP 画像は `og/NNN.png`（1200x630、文字だけ）。
- 共有文の例:
  > 『八本』
  > 最初の一行：「ケーキに、ろうそくを八本立てる。」
  > 最後の一行で、この意味が変わる。（一分）
  > #反転一行

## 新作の足し方（ファイル1つ）

1. `stories/005.json` を足す（001 から連番。番号が飛ぶとそこで読み込みが止まる）。

   ```json
   {
     "id": "005",
     "title": "題",
     "date": "2026-12-18",
     "twist": "反転の種類（毎回変える。過去作と並べて確認）",
     "premise": "最初に読んだときに読者が置く前提（1行）",
     "paras": ["一段落目（＝最初の一行。共有カードに載る）", "…"],
     "last": "最後の一行（共有には一切出ない）"
   }
   ```

   任意: `"special": "特別回　…"`（一覧に特別回の印）、`"monologue": true`（独白の組版）。
2. `node games/hanten/tools/build.mjs` で共有ページ・OGP 画像・下の「収録作」節を生成。
3. `node games/hanten/tests/check.mjs` が PASS すれば完了。

`date` が未来の話は一覧に出ない（公開日になると自動で並ぶ）。URL を直接開けば読める。

本文の決まり: 1話 400〜700 字。台詞は口語で短く。整いすぎた決め台詞・説明台詞は書かない。反転の種類は毎回変える（「どうせ最後でひっくり返る」と読まれないように）。

公開先の URL が決まったら `site.json` の `baseUrl` を書き換えて build を再実行する（OGP 画像は絶対 URL が要るため）。

## 確認

```
node games/hanten/tests/check.mjs
```

静的チェック（字数・反転の種類の重複なし・共有物にラストの一行が入っていない・OGP 1200x630・生成物が最新）と、Playwright での通し確認（一覧 → 4話読了 → 読了印 → 共有ボタン → localStorage 不可でも読める、ライト／ダーク）。スクリーンショットは `tests/screenshots/`。
