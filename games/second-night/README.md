# 二度目の夜（仮題）

七分の短編ブラウザノベル。核はひとつだけ——**二度目に、同じ文章の意味が反転する。**

- 依存なしの静的サイト（HTML / CSS / JS）。GitHub Pages にそのまま置けば動く。PWA（オフライン可）。
- 画像・外部フォント・外部通信なし（共有ボタンを押したときの X 遷移だけ）。演出は CSS と文字だけ。
- ダーク / ライト（OS 設定に追従、右上の ◐ で切替）。スマホ縦優先。
- 途中保存（`localStorage`。使えない環境でも最後まで遊べる）。
- **プライバシー**: 進行状況はこの端末の `localStorage` にのみ保存される。アクセス解析・Cookie・外部送信はない。共有ボタンを押したときだけ、X（または端末の共有機能）に結果テキストとURLが渡る。
- **内容について**: 認知症の家族の介護と、死別を扱う（ネタバレを避けるため、画面上は「喪失を扱う物語です」とだけ表示）。暴力・性的表現なし、全年齢。

## 遊び方（約6〜7分）

1. **一度目の夜**（約4〜5分）: 画面をタップすると一段落ずつ進む。冒頭3タップで「おかえり、なさい」。結末で、視点人物の正体が反転する。
2. **答え合わせ**（約1〜2分）: 一度目の文章から**一字一句そのまま**三行ずつ抜き出した5問。「この中に、二度目には意味が変わる一文がある」——選ぶと、正解の一文の下に咲の一言が出る。
3. **終章「咲」**: 答え合わせのあとにだけ読める、咲の日記。
4. **結果**: 「二度目に気づけた一文 n / 5」を大きく出し、共有文を見せてから共有（Web Share API／非対応なら X の投稿画面）。共有文はネタバレなしで n を含む:
   > 『二度目の夜』、二度目の答え合わせで 5つのうち 3つ気づけた。同じ文章が、二度目に違う意味になる。七分。一度目は何も調べずにどうぞ。 #二度目の夜

   （0〜2問は「5つ中 n つしか気づけなかった」、3〜4問は「5つのうち n つ気づけた」、5問は「全部気づけた」）

途中で閉じても、タイトルの「つづきから」で同じ段落・同じ問題に戻る。

## タイトル候補（決定はオーナー）

「二度目の夜」は仮題（説明的で弱い）。**一度目と二度目で意味が反転する**短い候補:

| 案 | 一度目の読み | 二度目の読み |
|---|---|---|
| **おかえりなさい** | 宿の洒落た挨拶 | 娘が毎晩、家族にだけ言う言葉 |
| **明日の朝には** | 求婚の朝が待ち遠しい | 毎晩つく同じ嘘。その朝は来ない |
| **一度目の夜** | ただの初日 | 父にとっては毎晩が一度目。娘には何度目かわからない |
| **ちゃんと書けてる** | 妙なほめ方 | 名前が書けなくなる夜が来るのが、いちばん怖い |
| **浜昼顔の宿** | 海辺の宿の名前らしい題 | 父が娘に名前をくれた花。毎晩、初めて |

PM の推しは「おかえりなさい」（冒頭3タップの台詞そのもので、二度目に一番重く反転する）。採用時は `story.js` の `title`、`index.html` の `<title>`・og/twitter、`manifest.webmanifest`、`tests/make-og.mjs` を差し替えて `node tests/make-og.mjs` で OGP を作り直す。

## 物語（ネタバレ）

> 海辺の古い宿「潮見荘」に、ひとりの客「僕」がたどり着く。明日の朝、宿の娘ミチに結婚を申し込むために。
> 宿の女性サキは親切だが、どこか様子がおかしい。夜、ポケットの指輪が消え、サキの首元に鎖が光る。

真相: 「僕」は七十八歳の透。認知症で、毎晩、求婚前夜の青年に戻る。宿は十年前に閉めた自宅、ミチは三年前に亡くなった妻、サキは娘の咲。
咲は毎晩坂の下まで父を迎えにいき、「宿の人」を演じ、同じ嘘をつき、名前を呼ばれない夜を重ねている。父は毎晩、生まれてくる娘の名前「咲」を初めて思いつき、目の前の咲にそれを話す。

## 設計意図

### 感情の筋を最優先する
場面は咲の感情が動くところだけに絞った（迎え・宿帳・電話・指輪・名前・朝の6場面）。v1 にあった番茶・手紙・風呂の独立場面は、トリックのための場面だったので削った。
答え合わせの「真相側の読み」は解説ではなく、すべて**咲のひとこと**（一〜二行）。正解するたびに、謎が解けるのと同時に咲が飲み込んできたものを一つ受け取る。

### 説明しすぎない、全部は見せない
- 答え合わせに出す伏線は5つだけ。本文には**あえて答え合わせしない伏線**を残している（腕を痛いほど握る／好みを言っていないのにぬるい番茶／鞄を持ってきていない／首元の鎖／薬指に食い込む指輪／「宿の経営が苦しい」という誤読）。二度目に自分で気づく余地。
- 咲の一言は理由を全部言わない（例: 「慣れてなんか、いない。」）。
- 終章は決め台詞を置かない。「潮かぶっても平気な顔して、って。」「平気な顔、できてたかな。……できてないか。」と言い淀んで止める。結末の決め台詞は「おはよう、お父さん」ひとつだけ。

### 台詞は口語で、言い淀む
「——おかえり、なさい」（息が切れて途切れる）、「明日の朝には戻るから。……戻りますから」（家族の口調から客向けに言い直す。この言い直し自体が伏線）、「あ、あなたと同じ名前だ。偶然だな」など。

### 叙述トリック（一度目でもフェア）
本文は一字一句、真相と矛盾しないように書いた。「僕」は年齢を名乗らず、鏡は布で覆われ、指輪はすり減り、彫り文字は「道」の一字しか読めない（僕は自分が昨日彫ったと思っている）。
ミスリードは二本: 恋人に会いに来た若者の旅情と、「指輪泥棒」「経営難の宿」という小さなミステリー。

## 答え合わせ（5問）

正解が一つに決まる問いだけを残した。外れの二行は、物・場所・動作だけの中立な描写（二度目に読んでも反転しない行）にしている。
読後すぐ分かる「おかえり、なさい」「父です」の二問は、答え合わせから外した（簡単すぎて、正しく読んだ人の差が出ないため）。

| # | 本文（一度目の読み） | 咲のひとこと |
|---|---|---|
| 1 | 「……うん。ちゃんと書けてる」（妙なほめ方） | 書けなくなる夜が来るのが、いちばん怖い。 |
| 2 | 「明日の朝には戻るから。……戻りますから」 | 嘘をつくときだけ、敬語になる。 |
| 3 | 鏡に白い布（古い宿の習わし） | かけたのは私。家じゅう、全部。 |
| 4 | 電話「平気です。もう慣れたし」（宿の経営の話？） | 慣れてなんか、いない。 |
| 5 | 「たった一晩で、こんなふうになるものだろうか。」（彫り文字は「道」） | 五十年。母の指で。 |

## 自己点検: 「AIが楽しいもの」になっていないか

| 観点 | v1 の問題 | v2 で直したこと |
|---|---|---|
| 仕掛けを説明しすぎない | 伏線38箇所すべてに解説が付き、全部ハイライトしていた | 5問だけ。残りは本文に置いたまま。注記は一〜二行に削った |
| ネタを全部見せない | 二周目で全伏線が光る＝読者が自分で気づく余地がない | 三択で「選ばせる」。外れても正解行と一言だけ見せる |
| 台詞が整いすぎない | 「ミ……ミチさんは、今夜は出ています」など丁寧すぎる文語 | 口語・言い直し・むせる・言いかけてやめる |
| 脇役の感情が最優先 | 番茶・手紙・風呂などトリックのための場面があった | 咲の感情が動く6場面だけに。終章は咲の声だけ |

### 人間が読んで引っかかりそうな箇所（PM の自己申告）
1. **三場面目の電話を「僕」が立ち聞きする都合のよさ**。階段の途中でちょうど電話が鳴る。段取りが透けて見える可能性がある（プレイテストで「真相が見えすぎる」と指摘があり台詞は弱めたが、立ち聞きという段取り自体は残っている）。
2. **答え合わせで「ほかの行も伏線に見える」問**。本文が伏線だらけなので、外れの行にも二度目には悲しく読める行が混ざりうる（例: 第5問「受話器を置いても、サキさんはしばらく動かなかった。」）。正解が一つに決まらないと感じる人がいるかもしれない。
3. **認知症という題材の扱い**。徘徊・鏡・名前を呼ばれない、という典型的なモチーフを「どんでん返しの道具」として使っていると受け取られる恐れ。終章で咲の側の時間（毎晩の記録、明日も迎えにいく）を置いて、驚きで終わらせないようにしているが、当事者の家族がどう読むかは未確認。
