# 二度目の夜

スマホで約15分の短編ブラウザノベル。核はひとつだけ——**二周目で、同じ文章の意味が反転する。**

- 依存なしの静的サイト（HTML / CSS / JS）。GitHub Pages にそのまま置けば動く。PWA（オフライン可）。
- 画像・外部フォント・外部通信なし。演出は CSS と文字だけ。
- ダーク / ライト（OS 設定に追従、右上の ◐ で切替）。スマホ縦優先。

## 遊び方

1. **一度目の夜**: 画面をタップすると一段落ずつ進む。普通の物語として読む（約7分）。結末で、視点人物の正体が反転する。
2. **二度目の夜**: 一度目とまったく同じ本文が表示されるが、伏線の箇所が淡く光る。タップすると、下から **「真相側の読み」** が出る（約8分）。
3. 二周目にだけ、終章「咲の夜」が追加される。結末で伏線の発見数と共有ボタン（Web Share API／非対応なら X の投稿画面）。

進行と発見した伏線は `localStorage` に保存（使えない環境でも遊べる）。

## 物語（ネタバレ）

> 海辺の古い宿「潮見荘」に、ひとりの客「僕」がたどり着く。明日の朝、宿の娘ミチに結婚を申し込むために。
> 宿の女性サキは親切だが、どこか悲しげだ。夜、ポケットの指輪が消え、サキの首元に鎖が光る——。

真相: 「僕」は七十八歳の **透**。認知症で、毎晩夕暮れになると二十代の自分に戻り、五十年以上前に初めて泊まった夜を生き直している。
宿は十年前に閉めた自宅、ミチ（道）は三年前に亡くなった妻、サキは彼の娘 **咲**。咲は毎晩、坂の下まで父を探しに行き、「宿の者」を演じ、同じ嘘をつき、名前を呼ばれない夜を千九十六回重ねている。

タイトルの「二度目の夜」は三重の意味を持つ:
1. 一周目は「宿に着いた二晩目」くらいにしか見えない。
2. 父にとって毎晩は「一度目の夜」、咲にとっては「千九十六度目の夜」。
3. プレイヤーにとっては、文字どおり二周目の夜。

## 設計意図

### 仕掛けを感情から切り離さない
二周目の「真相側の読み」は、作者の解説ではなく **すべて咲の一人称** で書いた。
伏線をタップするほど、プレイヤーは「謎が解ける快感」と同時に「咲が毎晩何を飲み込んできたか」を一つずつ受け取ることになる。
最後に二周目だけの終章（咲の日記と、父の手紙の追伸）で、それまでに積み上がった咲の嘆きを一行で回収する。

### 叙述トリック（一周目でもフェア）
本文は一字一句、真相と矛盾しないように書いた。「僕」は年齢を一度も名乗らず、鏡は布で覆われ、老眼鏡は「誰かの忘れ物」、新聞の字は「疲れで読めない」。
ミスリードは二本: (1) 恋人に会いに来た若者の旅情、(2) 「指輪泥棒」と「経営難の宿」という小さなミステリー。

### 伏線回収（細部どうしが繋がる）
単発の伏線だけでなく、離れた場面どうしが噛み合うように置いた:
- 三「ぬるい番茶」→ 五「手紙のやけど」: 咲の注記が「理由は知らなかった」→「今夜はじめて知った」と繋がる。
- 三「老眼鏡」→ 八「指輪の刻印が暗くて読めない」→ 注記「老眼鏡があれば、読めた」。
- 四「鏡の布」→ 十「布が床に落ちている」: 一周目の結末の引き金。
- 九「娘の名前は咲」「あなたの名前は誰が？」「父です」→ 終章「追伸　僕らの娘も、あんなふうに育つといい」→「育ったよ、お父さん。」
