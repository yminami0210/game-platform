# brief（全員の入口・60行以内）

## 一行ピッチ
七分の短編ノベル。読み終えたあと「答え合わせ」で、同じ文章の一文一文が別の意味に反転する。

## 新規性の一点
二周目は本文を読み直させない。一度目の文章を一字一句そのまま三行ずつ抜き出し、
「この中で意味が変わる一文は？」と選ばせる。気づけた数 n/5 がそのまま共有文になる。

## コアループ（約7分）
1. 一度目（約4〜5分）: タップで一段落ずつ。6場面・約1,500字。冒頭3タップで「おかえり、なさい」。
2. 結末: 鏡の老人と「おはよう、お父さん」で視点人物が反転。
3. 答え合わせ（約1〜2分）: 5問（正解が一意に決まる問いだけ）。選ぶ → 正解行に咲の一言（一〜二行、説明しすぎない）。
4. 終章「咲」: 咲の日記。嘆きの回収。
5. 結果: 「n / 5」を主役に→ 共有（ネタバレなし、n を含む）。

## 物語の要点（ネタバレ）
- 僕＝透、七十八歳。認知症で、毎晩ミチ（道）に求婚する前夜の青年に戻る。
- 宿「潮見荘」は十年前に閉めた自宅。ミチは三年前に亡くなった妻。サキは娘の咲（四十六）。
- 咲は毎晩迎えにいき、「宿の人」を演じる。名前は呼ばれない。
- 名前「咲」は、父が浜昼顔にちなんで付けた。父は毎晩それを初めて思いつく。

## トーン・文体
- 地の文は平易。台詞は口語、言い淀み・言い直し（「戻るから。……戻りますから」）を入れる。
- 仕掛けを説明しない。答え合わせで扱う伏線は5つだけ、残りは本文に置いたまま。
- 感情の筋（咲）が最優先。トリックだけのための場面は置かない。

## 用語
潮見荘 / 帳場 / 宿帳 / 浜昼顔 / ミチ（道） / サキ（咲） / 透

明朝系・余白多め・スマホ縦。ダーク/ライト。色は墨・生成り・朱の3つ。画像は使わない（OGPも文字のみ）。音なし。
