- 2026-11-18 Gate 1 は親セッション経由で承認済みとして扱う（当初指示書＋レビュー会議の仕様変更）。人間への質問はしない。
- 2026-11-18 `game/` 雛形には移さず、既存の `games/second-night/` をそのまま活かす。理由: 雛形はアクションゲーム向け（core/simulate/bot 前提）でノベルに合わず、移すと差分が膨らむ。リポジトリは複数ゲームを置く構成なので、ルートに game/ や studio/ を作らない。
- 2026-11-18 studio/ は `games/second-night/studio/` に置く。`.claude/agents/` へのエージェント設置と Pages ワークフロー追加はしない（Gate 2 前に公開経路を作らないため）。gs-* はスキル同梱の定義をプロンプトとして汎用エージェントに渡して呼ぶ。
- 2026-11-18 gate_check.mjs はシミュレーション（初心者/上達者ボット）前提でノベルに適用できないため、`tests/playthrough.mjs` を本作の自動ゲートに置き換える。基準: 7分前後（5〜9分の見積り）、冒頭3タップで引き、答え合わせ7問が本文と一字一句一致、途中保存・再開、localStorage 不可でも動く、OGP 1200x630、ページエラー0。
- 2026-11-18 品質基準のうち「上達の余地」「1ランの長さ」「失敗→リトライ」「一時停止・ミュート」はノベルに当てはまらないため対象外。代わりに「答え合わせの正答数 n/7」を積み上げ要素とする。
- 2026-11-18 二周目は全文読み直し＋全伏線ハイライト（v1）をやめ、三択の答え合わせ7問に変更。伏線の残り（腕の強さ・ぬるい番茶・鞄・鎖・薬指・宿の経営）は答え合わせに出さず、気づく余地として残す。
- 2026-11-18 本文を10場面3,000字 → 6場面1,500字に削減。番茶・手紙・風呂の独立場面を削り、咲の感情が動く場面（迎え・宿帳・電話・指輪・名前・朝）だけ残す。
- 2026-11-18 タイトルは仮題のまま。候補5案を README に記載し、決定はオーナー。
