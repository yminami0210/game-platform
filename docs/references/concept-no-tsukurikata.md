# 『コンセプトのつくりかた』要点（オーナー提供のメモより）

- コンセプトは「何を用いて、何をしたいか」を、数字を除く母国語20字程度で表したもの。素直な想い（ビジョン）の集合から生まれ、手段（アイテム）の集合で伝えられる。「良い」を入れない（例：ゲーム人口の拡大）。
- 起点はモノではなく体験（例：Wii。家族がリビングに集まって笑っている光景。「お母さんに嫌われないゲーム機」）。
- 強いコンセプト ＝ 誰にどんな体験を届けるかの定義 ×「やらないこと」を切り捨てる基準（Wii：小さく白い筐体、低消費電力、ボタンの少ないリモコン。HD競争はやらない）。
- 「好き」を因数分解し、「当たり前」を疑うことから問いを立てる。会議室のデータからは見つからない。
- 企画書（市場規模・収支・機能一覧）とコンセプトを混同しない。
- 4人の仲間と原理：生きるあなた（すきになる）／コンセプトワークするあなた（かわる）／プレゼンするあなた（わかる）／プロジェクトを行うあなた（できる）。最後の要は「信じる心」。
- 5ステップ：悪口を言う → ズラす質問 → 言葉の星座 → 物語 → 影を乗り越える。
- ズラす9つの質問、6つの力（ファイブフォース＋政府）は skill `concept-work` に収録。
- リーダーの役割は答えを見つけることではなく、ズラすことだけ。
