# 「48個目の都道府県」ARG のリスクと対策

- 作成: 2026-10-11 AI相棒（PM・法務の視点。弁護士の確認ではない。公開や課金を始める前に、必要なら専門家に確認する）
- 前提: 構想書 `docs/product/nanashi/business-plan.md`。会社のルール（CLAUDE.md §2）では、外への投稿・課金・公開はオーナーが一言確認してから行う

## 要判断（オーナーに決めてほしいこと）

| # | 論点 | リスク | 提案 |
|---|---|---|---|
| 1 | **人間が「部外者・発見者」を装って広める** | 運営が無関係な第三者のふりをして宣伝すると、ステルスマーケティング（2023年10月から景品表示法の規制対象）になりうる。課金の導線（グッズ・寄附）があると「事業者の広告」と見られやすい。X でも、複数アカウントで人気を水増しする行為は禁止されている | 発見者アカウントは「運営の中の人」と分かる形にする（例：プロフィールに「ナナシ県 運営」）。あるいは運営とは関係のない本当のファンの発見を待ち、運営は引用で応えるだけにする |
| 2 | **高校生（西村ハル・17）を SNS に出す** | 未成年のキャラクターを AI が運用すると、性的な絡みや、居場所の詮索を招きやすい。炎上したとき、守る手段が少ない | 年齢は「高校生」のままにして、自撮り・制服写真・リアルタイムの居場所は出さず、DM も閉じる。正本の4アカウントにハル本人のアカウントはないので、いまは出していない。ハルを SNS に出すときは、この安全策を入れる |
| 3 | **「ふるさと納税」という言葉を使う** | ふるさと納税は法律（地方税法）で決まった制度の通称。架空の県で使うと、税金の控除があると誤解される。総務省の指定もない | 呼び名を「ナナシ県 応援寄附（ネタ寄附・税控除なし）」にして、クラウドファンディングや投げ銭で集める。「ふるさと納税」の言葉は使わない |
| 4 | **AI が自動で返信する** | X の自動化ルールでは、自動化したアカウントは自動化のラベルと運営者の表示が要る。頼まれていない相手への自動返信・自動メンションは禁止されている。勝手な返信で炎上する恐れもある | 自動にするのは「自分の投稿」だけ。返信は AI が下書きし、人が確認してから出す。4つのアカウントに「自動化」のラベルを付ける |

## そのほかの対策（仮置きで進める）

| 論点 | 対策 |
|---|---|
| 実在の地名・企業・人と重なる | 固有名詞はすべて架空（`world-bible.md` の固有名詞表）。郵便番号・電話番号・市外局番は実在するものを使わない。県番号は「48」 |
| 本物と誤解される | プロフィールに「フィクションです」「AI が運用しています」と書く（`server/personas.js` のプロフィール文）。公的な書類に似せない |
| 住民票（④） | 本物の住民票に似た書式・用語（交付番号・公印など）は使わない。「ナナシ県 住民証（記念品）」と呼ぶ |
| 有料の物語（①） | 実在の事件・災害・人物をネタにしない |
| グッズ（②） | 素材は自作か、ライセンスを確かめたものだけ。フォントの商用利用の条件を確かめる |
| ARG の「違和感」がこわすぎる | 不安をあおる内容（実在の失踪・心霊スポット・災害の予言など）は書かない。違和感は「ちょっと変だけど、ほほえましい」まで |
| 個人情報 | 参加者の本名・住所は集めない。住民限定 Discord では、運営が個人情報を求めない |
| アカウントの凍結 | 同じ端末・同じ時刻にそろって投稿しない。投稿の時刻は、町の住人の暮らしの時刻に合わせてばらす |
