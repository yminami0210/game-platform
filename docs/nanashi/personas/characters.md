# 4人の設定（SNS の投稿者）

- 状態: v1（2026-10-11 AI相棒の案。オーナー確認待ち）。OmniRoute・Gemini が使えなかったため Claude が代筆
- 町の中の住人に配役してある（`server/personas.js` の `CAST`）。住所・家族・暮らしの時刻は、町の住民台帳と同じ
- 確かめ方: `node tools/nanashi_pastlog.mjs --cast`（台帳の上での住所・家族・勤め先・見た目を表示する）。行きつけの店も町の暮らしに入れてある（さくらはふじや・ポプラ・名無湯・まるなな、七瀬のお昼はふじや、澪のおつかいはマルヤ）
- 番地は町の初期配置（seed 7）のもの。管理者モードで家を壊すと変わる
- **「裏設定」は投稿で直接書かない。** 投稿の言葉選びの理由としてだけ使う。考察する人がいつか気づくかもしれない、くらいに置いておく

## 4人のつながり（交差点）

```
          ナナシ駅（伝言板）── 毎朝ここを通る ── 澪（6:57 家を出る） ／ さくら（7:36）
               │
  浜町 ── 菜種家（澪）        東町22番地のアパート ── 3号室 さくら ／ 4号室 七瀬（隣どうし）
       └ 藤谷家（修）
               │
  商店街 ── 大衆食堂ふじや（修）← さくらの晩ごはん ／ 七瀬のお昼 ／ 澪は貼り紙を見て帰る
           ├ 青果マルヤ ← 澪のおつかい（母の洋子に頼まれる）
           ├ 純喫茶ポプラ ← さくらの帰り道
           └ 七星堂書店 ← 澪の立ち読み
```

- 澪とさくらは同じ駅を使うが、時刻がずれていて、話したことはない。伝言板の同じ書き込みを、別々に投稿することがある
- さくらと七瀬はアパートの隣どうし。廊下であいさつするくらい
- 修の娘の千夏（小6）は、澪の小学校の後輩。澪は「ふじやの千夏ちゃん」と呼ぶ
