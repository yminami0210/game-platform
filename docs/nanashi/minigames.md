# 店を利用する（ミニゲームの入口）

ナナシ県の店や施設は「利用する」と、その店のミニゲームが始まる。町はゲームの入口と結果の記録だけを持ち、ゲーム本体は別に作る（ミニゲーム工場など）。

## どこから遊べるか

- 店をタップ → 詳細カードの「利用する」
- 店の中の全景（「中を見る」）→ 上の「利用する」

いまは全部「準備中」（`url: null`）。ゲームができたら、その行の `url` にゲームの HTML の場所を入れるだけで遊べる。

## ゲームとの約束ごと

1. 町はゲームを iframe で開く。URL に次を付ける
   - `shop`: 店の id（例 `kissa1`）
   - `name`: 店名（例 `純喫茶ポプラ`）
   - `player`: 遊ぶ人の名前（アバター登録していればその名前。なければ空）
2. ゲームが終わったら、親の画面へ結果を送る

   ```js
   window.parent.postMessage({ type: 'nanashi:minigame', result: { score: 120, text: '「ナポリタンを運べ」で遊んだ' } }, '*');
   ```

3. 町は結果を受け取ると画面を閉じ、町のログに「〇〇さんが純喫茶ポプラで「ナポリタンを運べ」で遊んだ（120点）」と残す。店の「きょうのお客」も 1 増える
   - API: `POST /api/place/<店のid>/use` `{ player, text, score }`（この端末で動かす版では同じ処理をブラウザの中で行う）
   - 名前と文は 20 文字まで、記号の `<` `>` は取り除く。LLM は使わない（トークン 0）

## ゲームを作る人へ

- 1 つの HTML で完結させる（外のサーバーにデータを送らない）。スマホの縦画面で遊べること
- 遊ぶ時間は 30 秒〜2 分くらい。店に寄ったついでに遊べる長さ
- 世界観は「昭和の空気が少し残る町」。実在の店名・商品名・キャラクターは使わない
- 置き場所は町と相談して決める（`arcade/` の作品を使う場合は、遊び場 `player/` と同じく読むだけにする）
