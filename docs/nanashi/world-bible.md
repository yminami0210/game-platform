# ナナシ県 世界設定（町の実装との対応）

**正本は Claude Docs の「ナナシ県 世界観バイブル」**: https://claude.ai/artifact/STEnzTzLxtiCPCds5ynLfy
- リポジトリの写し: `canon/world-bible.md`（2026-10-11 rev 28）。正本とこのリポジトリが食い違ったら、正本が優先
- 新しい設定はエージェントが提案し、人間が承認したものだけを正本に足す。町や SNS のために作った、正本にない細かい設定は `proposals.md` に「未承認の提案」として並べている
- 2026-10-11 まで、このリポジトリは正本を見ずに作っていた（海のある町、ナナシ線、ナナミ市、ななっしー、昭和の小物など）。オーナーの指摘で、正本に合わせて作り直した

## 守る前提（正本より）
1. **生身の日常。** 大事件は起きない
2. **風変わりなのは物と言葉だけ。** 魔法や超常の仕組みはない
3. **驚くのは外から来た人だけ。** 県民にとっては全部当たり前
- 文体: 数字は算用数字、値段・時刻・地名・名字を入れる。絵文字なし。感想・教訓・まとめで終えない。「どこか」「なぜか」「不思議と」に頼らない

## 町（3DCG・地図）は、正本のどこか
町の画面は **中ノ町市（県庁所在地）の中ノ町駅のまわり**。

| 正本 | 町の中 |

| 四方を山に囲まれた盆地。北に大岳（2,210m） | 町をぐるりと山が囲み、北にいちばん大きな山（大岳） |
| ヨコネ川が東から西へ流れる | 町の南を流れる川。両岸に河川敷と土手、向こう岸は田んぼ。橋が2本 |

| 県庁所在地の中ノ町市。駅前商店街、県庁、ナナシ放送、スーパーまるやす本店 | ナナシ県庁、中ノ町駅、駅前商店街、NNSナナシ放送（電波塔と中継車）、スーパーまるやす本店 |
| 中ノ町郵便局（駅前） | 駅の北の中ノ町郵便局 |
| ナカノモール（1998年開業、2階の半分は空きテナント） | ナカノモール |
| 県立中ノ町商業高校 | 町の外（ヨコデンで通う）。ハルの通学先 |
| 下川原市（西・下流・工場と団地）、深田市（米とかぶら、県立大学） | 町の外の通勤先。西のトンネルの先が下川原、東の先が深田 |
