# 住人のしくみ（住民台帳と一日の動き）

## 前の版で足りなかったこと（2026-10-11 オーナーの指摘どおり）
- 住まいは家をランダムに 1 軒割り当てるだけ。1 軒に何人でも入り、家族（世帯）という考えがなかった
- 勤め先があるのは県庁職員と店の従業員だけ。ほかの住人は時間帯ごとに行き先をランダムに選んで歩き回るだけだった
- 一人ひとりの「その人らしい予定」がなく、町の外との行き来もなかった

## 今のしくみ

### 1. 住民台帳（だれが・どこに住み・どこで働くか）
| 項目 | 内容 |
|---|---|
| 世帯 | 名字を共有する家族。家の種類で構成が変わる（平屋＝高齢の夫婦か家族、二階建て＝家族、木造アパート＝単身か若い夫婦、店舗つき住宅＝店を営む家族） |
| 住まい | 世帯ごとに 1 軒（アパートは 4 部屋）。住所は「駅前12番地」「浜町64番地 2号室」のように付く。部屋数より多くは住まない。空き部屋は台帳に出る |
| 役割 | 県庁職員／町で勤務（店・駅・学校など）／県外へ通勤／児童（町の小学校）／高校生（県外へ通学）／家事／隠居 |
| 勤め先 | 県庁の机、町の店、自宅の店、または下川原市・深田市の会社、県立中ノ町商業高校 |
| 予定 | 起きる・寝る時刻、駅へ向かう時刻と帰りの電車、休みの曜日、行きつけの店・銭湯・喫茶店。一度決めたら毎日同じ（その人らしさ） |

画面の「台帳」タブで、世帯ごとに一覧と検索ができる。CP をタップすると、世帯・住所・勤め先・きょうの予定が出る。

### 2. 一日の動き（LLM は使わない）
1. 起きる時刻まで家で寝ている
2. 県外へ通う人は、決まった時刻に駅へ歩き、ホームで待って電車に乗る。乗ったら町からいなくなる（県外にいる）
3. 町で働く人は、勤め先の営業時間に出勤する（12時台は行きつけの店で昼ごはん）。児童は 8〜15 時に小学校
4. 家にいる人・隠居の人は、時間帯に合わせて行きつけの店・喫茶店・公園・銭湯へ行く
5. 夕方、帰りの電車で県外から帰ってくる。途中で銭湯やスーパーに寄ることもある
6. 週末は、若い人の一部が電車で県外へ出かける

### 3. 駅（町の真ん中）と、ほかの町との行き来
- ヨコデンは時刻表どおりに走る（正本のバイブル: 単線・2両・30分に1本。5:40〜23:10）。上りと下りが中ノ町駅ですれ違う。西のトンネルの先が下川原市、東の先が深田市
- **ベッドタウンにした**: 働く人の 85% が県外へ通う（`nanashi.config.json` の `commuteShare`）。高校生も県外へ通う。平日の昼は住民の半数以上（試算で 51%）が町の外にいるので、町なかが人であふれない
- 県外から通ってくる人もいる: 町の働き口のうち住民で埋まらない分は、下川原市・深田市から朝のヨコデンで来て、夕方に帰る
- 昼間は日帰りの来訪者が電車で来て、喫茶店や銭湯を2〜3軒回って帰る
- 空き部屋があると、ときどき県外から引っ越してくる（住民課が転入届を受け付け、新しい世帯が駅に着く）

### 4. 管理者が町を変えたとき
| 操作 | 住人への影響 |
|---|---|
| 家を建てる | 空き部屋が増え、そのうち引っ越してくる人が来る |
| 家を取り壊す | 住んでいた世帯は空き家へ引っ越す。空きがなければ電車で町を出る（転出） |
| 店や施設を建てる | 働き口が増え、まずは県外から通ってくる人で埋まる |
| 店や施設を取り壊す | そこで働いていた住人は県外へ通勤に変わる。県外から来ていた人はもう来ない |
| 移す | 住む人・通う人は、次の行動から新しい場所へ行く |

県庁・執務フロア・駅は町の中心なので、動かしたり壊したりできない。道路と線路の上には建てられない。
