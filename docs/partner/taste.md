# オーナーが「面白い」と思う考え方（相棒の判断基準）

構想を出すときと、レビューするときに必ず参照する。真似する対象ではなく、物差しとして持つ。

## 例：指標を比べるカードゲーム（2026-11-20 オーナー提示）
- 手札のカードには、人口・面積などの指標が複数書いてある。毎ターン、親がお題（どの指標で比べるか）をめくり、勝てると思うカードを出す。使ったカードは戻らない。

## そこから抜き出した考え方
1. **面白さは、毎ターン迫られる判断にある。** テーマや見た目ではない。「強いカードを今切るか、取っておくか」のように、手持ちが減っていく中で選ぶ重さが駆け引きを生む。
2. **偶然は外から、判断は内に。** お題はランダムで先が読めない。でも、どう応じるかは自分で決められる。運だけでも、読み切りだけでもない。
3. **ルールは数行、深さは遊ぶ人の側に。** 誰でもすぐ遊べるのに、相手の残りの手札を読み始めると深くなる。
4. **中身は世の中にある事実で作る。** 尽きず、権利の心配もなく、遊ぶうちに知識が増える。知識がなくても遊べて、あると有利になる。
5. **テーブルでもオンラインでも、同じ体験が成り立つ。** 同時に出して比べるだけなので、場所を選ばない。

## 相棒が陥りやすい間違い
- 見た目やテーマの新しさで評価してしまう。仕組み（遊ぶ人が何を判断するか）を先に見ること。
- 例を見たら「どう真似るか」に飛ぶ。抜き出すべきは考え方であって、形ではない。
