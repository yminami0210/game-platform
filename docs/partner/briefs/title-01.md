## 目的
オーナー（yminami0210）の会社「AI社員だけで回るインディーゲームスタジオ」の**大型タイトル第1作**を作る。会社の方針は `docs/company.md`（特に §2本立て の規模の定義）。
オーナーが「大型」と言っているのは、ゼルダやマリオのような**壮大な冒険**のこと。前回の「トモシムレ」（1画面・1回2分）は規模が足りずに不採用になった。**今回はミニゲームを作らない。**
オーナーの好み: 仕事を忘れて遊べる純粋な娯楽。見た目は「AIが作った感」の無い、人の手を感じるもの。オーナーは基本的に放置で、区切りで遊んで判断する。

## 作るもの
**横スクロールアクション**（スーパーマリオワールドのような、ワールドとステージで進む型）。
最初のマイルストーン = **ワールド1を完成品質で**（30分〜1時間遊べる体験版）:
- ワールドマップ（ステージを選んで進む。クリアで道が開く）
- 通常ステージ 4つ＋ボスのいる砦ステージ 1つ。各ステージに隠し要素（例: 隠しメダル3枚、隠し出口）
- 各ステージに**新しい仕掛けを1つ**入れ、「見せる → 試させる → ひねる → 決めさせる」の順に1ステージ内で育てる
- 敵は6種類以上（動きがはっきり違うもの）。ボスは攻撃の型が3段階で変わる
- パワーアップ（変身・能力）を1系統。取ると遊び方が変わるもの
- 中間地点、残機かリトライ、進行のセーブ、ワールド1のエンディングと「続く」
- 短い物語（世界の導入とワールド1の締め）。実在作品のキャラクター・名前・見た目（配管、キノコ、ヒゲの主人公、カメ等）は使わず、完全にオリジナルの世界にする

## 手触り（これが一番大事）
- 走りの加速・減速、ジャンプの高さを押す長さで調整、コヨーテタイム、先行入力、着地の手応え、カメラの先読み、ヒットストップ、軽い画面揺れ
- 操作: PC はキーボード＋ゲームパッド、スマホは横持ちで画面上の仮想ボタン
- 横画面 16:9。ドット絵（例: 内部 384x216 を整数倍で拡大）か、game-art-direction に沿った描き方
- 60fps を保つ

## 進め方
1. `.claude/skills/frontend-design/SKILL.md` と `.claude/skills/game-art-direction/SKILL.md` を必ず読む（デザインの規定。gs-design-manager と gs-reviewer にも読ませる）。
2. `game-studio` スキル（無ければ `.claude/game-studio/` の参照資料と `.claude/agents/gs-*.md`）のフェーズとゲートを使う。ただしテンプレートは短時間ゲーム向けなので、**大型向けに読み替える**:
   - Phase 1: コンセプト（Gate 1 はオーナーから委任済み。3案から自分で選び、理由を `studio/decisions.md` に残す）。世界観・主人公・ワールド全体の構想（ワールド1〜8の一覧）と、ワールド1の詳細を書く
   - 垂直スライス = **ステージ1-1 を完成品質で**。手触りを playtester と reviewer で確かめる。ここで手応えが無ければ作り直す
   - プロダクション = ワールド1の残り（ワールドマップ、ステージ1-2〜1-4、砦とボス、エンディング）
   - `studio/gates.json` の基準は大型向けに書き換える（1ランの長さではなく、ステージごとのクリア時間・死亡回数・隠し要素の発見率など）
3. **全ステージがクリアできることを機械で確かめる**: ステージのデータを読んでゴールまで進むボット（または経路探索）を作り、gate_check に組み込む
4. ステージはコードではなくデータ（JSON など）で作り、ワールド2以降を足しやすい形にする
5. ゲームエンジン: テンプレートの構成（`game/src/core` `render` `input` など、外部依存なし）を広げて作るのを基本にする。ライブラリを入れる場合は gs-legal でライセンスを確認し、同梱する（外部 CDN は使わない）
6. **ステージ1-1 ができた時点で**（止まらずに）、スクショと遊び方を `studio/progress-1-1.md` に書いて push し、AI相棒（親セッション）に send_message で3行報告する
7. フェーズごとに `studio/STATUS.md` を更新し、commit して push する

## 使い方の上限（トークン）
- mode=eco のモデル割当を使う。エージェントの呼び出しはマイルストーン全体で **40回まで**（STATUS.md で数える）
- 7日間の利用上限が近いという警告が出ている。上限に当たったら、きりの良いところで STATUS.md を更新して push し、状況を親セッションに報告して止まる

## 完了条件
- ワールド1（マップ＋5ステージ＋ボス＋エンディング）が通しで遊べる
- `node .claude/game-studio/scripts/gate_check.mjs --gate release`（大型向けに直した基準）が PASS し、全ステージのクリア確認ボットが通る
- reviewer の判定で、楽しさ・手触りにブロッカーが無く、「AIが作った感」スコア 7/10 以上
- `studio/milestone-1-pack.md` に、一行ピッチ、スクショ（各ステージ）、ローカルでの遊び方、各判定の要約、既知の問題、ワールド2以降の計画を書く
- すべて作業ブランチ `studio/title-01` に push 済み（PR は作らない。main にはマージしない。公開しない）
