# プロダクトキャンバス: ミニゲーム・アーケード（arcade）

- 状態: Core は会社の Core に従う（仮置き）／Why 以下は PM 案（オーナー確認待ち）
- 最終更新: 2026-10-04 / 担当 PM: ミニゲーム工場の進行役（/arcade-make）

## Core
- ミッション: すき間時間に、仕事を忘れて1〜3分没頭できる遊びを届ける
- ビジョン: 毎朝1本増える小さな遊び場が、スタジオの入口になる
- 企業への貢献: 当たる遊びを速く安く見つけ、大型タイトルの仕掛けの種と集客の入口にする（事業戦略2）

## Why
- ターゲットユーザー: 通勤・休憩・寝る前に、スマホで少しだけ遊びたい大人
- ペイン: 広告や課金に追われる、覚えることが多い、仕事を思い出す
- ゲイン: 説明なしで5秒で始められ、1回で気持ちいい瞬間がある。また明日も新しいのがある
- 市場分析: ブラウザで動く短いゲームは手軽だが、似た見た目・似た遊びが多い（要調査）
- 競合分析: 量産型ハイパーカジュアル。自社は「題材から借りた手仕事の見た目」と「毎日1本の新作」で違いを出す
- Fit: ミッション（すき間時間・仕事を忘れる）に答える

## What
- メンタルモデル: 「駅の伝言板に今日の1本が書き足される」。開けばすぐ遊べ、終わればもう一回
- カスタマージャーニー: 遊び場を開く → 新しい1本 → 30秒で分かる → 気持ちいい瞬間 → ベスト更新 → また明日
- コスト構造: 1本ごとのトークン代（企画・開発・QA・監査）。1日1本に抑えている
- 収益モデル: 当面なし（公開前）。公開後に広告などをオーナーと検討
- 指標: 監査の楽しさ・デザインスコア、公開後は1本あたりのプレイ数・もう一回率
- マイルストーン: 30本たまったら公開の判断をオーナーに仰ぐ（案）
- Fit: Why のゲイン（5秒で始まる・気持ちいい瞬間・毎日）に答える

## How
- ユーザーインターフェース: 1ファイルの HTML、スマホ縦・PC 両対応、game-art-direction のデザイン規定
- 設計と実装: /arcade-make（企画 → 開発 → 自動QA → 監査）
- Go To Market: 未定（GitHub Pages で公開、note・X で告知はオーナー承認後）
- Fit: What の体験（すぐ遊べる・毎日）に答える
