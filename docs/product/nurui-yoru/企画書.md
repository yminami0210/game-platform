# 企画書：『ぬるい夜』— 蚊になって飛ぶスマホゲーム（案 v0.1／2026-10-25）

> 状態：企画案。ナナシ県の新しい設定（後述「設定提案」）を含むので、制作に入る前に承認シートで ◯／✕ をもらう。
> 制作の分担は Artifact「OmniRoute 運用設定」（考える＝Claude、実行＝OmniRoute、最終チェック＝Claude）に合わせる。

## 1. ひとことで
ナナシ県の蒸し暑い夏の夜、1匹の蚊になって家の中を飛び、人の血を吸って朝までに外へ帰る。
操作はフライトシミュレーター。計器を見ながら、寝ている人の耳もとをかすめ、腕に着陸して吸う。叩かれたら OUT。

## 2. 遊びの核
- **緊張と欲**：血を吸うほど重くなって鈍くなる。「もうひと口」で叩かれる
- **フライトシムの手ごたえ**：慣性があり、急には止まれない。着陸は速度と角度を合わせる
- **人を読む**：人は寝返り・かゆがる・起きる、の段階で警戒が上がる。叩く前に必ず予兆がある（理不尽な即死はなし）

## 3. 操作（縦持ち／横持ち両対応、既定は横持ち）
| 入力 | 動き |
|---|---|
| 左スティック 上下 | 上昇・下降（スロットル） |
| 左スティック 左右 | その場で向きを変える（ヨー） |
| 右スティック 上下 | 前進・後退（ピッチ） |
| 右スティック 左右 | 横に平行移動（ロール） |
| 右下ボタン（長押し） | 吸う（着陸中のみ） |
| 左下ボタン | 羽を止める（滑空。音が消えるが落ちる） |

- ドローンの「モード2」と同じ配置。設定で「傾きセンサー操作」「スティック左右入れ替え」を選べる
- 初心者向けに「自動水平」（スティックを離すと空中で止まる）を既定ON、上級者はOFFで慣性そのまま

## 4. 画面（HUD）
コックピット風。視点は蚊の頭の後ろ（三人称）と一人称を切り替え。
- 姿勢指示器（人工水平儀）：中央
- 高度計：床からの高さを cm で
- 速度計：cm/秒
- **血液計**：燃料計の位置。満タンに近いほど機体が重い
- **羽音メーター**：自分の音の大きさ。速く飛ぶほど・人の頭に近いほど大きい
- **警戒レーダー**：人ごとの警戒度（目のアイコン）。0 寝ている → 1 寝返り → 2 かゆい → 3 起きた → 4 叩く
- ミニマップ：部屋の見取り図と出口

## 5. ルール
### 1回のプレイ＝ひと晩
- 23:00 に窓から入り、5:00（夜明け）までに出口から出ればクリア。ゲーム内6時間＝実時間で約4分
- 出口で持ち帰った血の量がスコア。途中で叩かれたら OUT（その夜の血はゼロ）

### 吸血
1. 肌の出ているところに着陸（速度が速すぎると跳ねて、警戒＋1）
2. 吸うボタン長押し。吸っている間は人が少しずつ「むず」とする。ゲージが赤に入る前に離れる
3. 刺す場所で量と危険が違う：足首（少ない・安全）／腕（ふつう）／首・顔（多い・危険）

### 叩かれる
- 警戒4 で人が手を振り上げる。**手の影が落ちてから0.6秒**で叩く。その間に影の外へ逃げれば助かる
- 手の速さは人によって違う（お年寄りはゆっくり、高校生は速い）
- 寝ぼけて叩くときは狙いが甘い。起きて部屋の電気がついたら本気

### 邪魔なもの
| もの | 効果 |
|---|---|
| 扇風機 | 風で流される。首振りに合わせて抜ける |
| 蚊取り線香 | 煙の中は体力が減る。煙は風で流れる |
| 網戸 | 破れ目を探して通る |
| 電気をつける | 白い壁の前だと見つかりやすい |
| 電撃ラケット（後半） | 起きた人が持っていると、叩く範囲が広い |

## 6. ナナシ県らしさ（既存の設定とつなげる）
バイブルの「家」と「気候」をそのまま遊びに使う。新しい魔法や超常は入れない。
- **ことづけ窓**：鍵をかけない小窓なので、蚊にとっての正面玄関。ここが基本の入口と出口
- **二段玄関**：上だけ開いている家は、出入りのチャンス
- **風見間**：何も置いていない三角の部屋。人がいないので休憩場所（血の消化で少し軽くなる）。ただし夏は風の通り道で流されやすい
- **夏は蒸し暑い**：暑い夜ほど人は布団から手足を出す＝吸いやすい。県内カレンダーの夏の気温を使って、夜ごとの難しさを変える
- **ぬる〜い自販機**：外のステージの明かり。虫が集まる場所で、仲間の蚊がいる
- 季節は夏のみ。冬の「ヨコネおろし」と風袋は使わない（夏の話なので）

## 7. ステージ（1つ＝ひと晩）
| # | 場所 | 人 | 特徴 |
|---|---|---|---|
| 1 | 中ノ町の一軒家（練習） | おじいさん1人 | 寝相がよく、手が遅い。操作に慣れる |
| 2 | 下川原の団地 | 家族4人の川の字 | 子どもの寝返りが多い。扇風機1台 |
| 3 | 鳴沢温泉の旅館 | 修学旅行の中学生8人 | 夜ふかしで起きている子がいる。浴衣で肌が多い |
| 4 | 夏の甲子園を見ている居間 | テレビの前の3人 | 起きているが画面に夢中。試合が盛り上がる場面で動ける |
| 5 | 上ヨコネ村の古い家 | 年配の夫婦 | 蚊帳つき。蚊帳のすき間を探す。蚊取り線香が強い |

- 登場人物（西村ハル、三浦勝など）は、最初は**出さない**。叩かれる役に主要人物を使うかは人間の判断にする
- 実在の地名・企業は出さない

## 8. 続けて遊ぶしくみ
- **毎日の夜**：その日の県内カレンダー（気温・湿度）でステージ条件が変わる日替わり。全員同じ条件でスコアを競う
- **蚊の成長**：持ち帰った血で羽・口・体を強くする（静かな羽、早く吸える口、軽い体）。強くしすぎると目立つ、などの取引にする
- **かゆみ図鑑**：刺した人の朝の様子（「なんか足首かゆい」）を1行ずつ集める。ナナシ県の暮らしのちょっとした文章がここに溜まる
- 課金・広告は v1 では入れない

## 9. 技術
- 既存の game-platform と同じく、HTML5／PWA を GitHub Pages で公開（公開は承認後）
- 3D は three.js。部屋は箱と簡単な家具、人は低ポリゴン。蚊の視点で物が大きく見えるのが見どころ
- 操作は画面のバーチャルスティック（タッチ）、傾きセンサーは任意
- 目標：iPhone で 60fps、読み込み 3MB 以内

## 11. 設定提案（承認が必要なもの）
1. ナナシ県の夏の夜には蚊が出る（県民にとって普通のこと）。ゲームはその視点の話
2. ことづけ窓は夏の夜も開いていることが多い（鍵をかけないので）
3. 蚊取り線香・扇風機・蚊帳は県内でも普通に使う（特別な県の道具は足さない）
4. 主要人物を叩く役で出すか：**今は出さない**を推す
