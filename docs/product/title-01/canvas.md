## Core（オーナーが決める・会社の Core は 2026-10-04 確定）
- 会社のミッション: **忙しい毎日から離れて、時間を忘れて没頭できる遊びを届ける**
- 会社のビジョン: **多くの人に愛される作品を生み続ける**
- このタイトルのミッション（会社のミッションの言い換え）: 区切りよく遊べて、気づけば時間を忘れている冒険を届ける
- このタイトルのビジョン: ツギと「布と裁縫の世界」を、多くの人に愛され、手元に置きたくなる（ぬいぐるみ・グッズ）作品とキャラクターに育てる
- 企業への貢献: 事業戦略1（看板となる世界とキャラクター）。ミニゲームで当たった遊びを仕掛けの種にする（事業戦略2）。将来のグッズ収益の土台（事業戦略3、事業戦略は下書きのまま）

## Why（PM 案 → オーナー確認）
- ターゲットユーザー（**確定 2026-10-04**）: **10代〜40代**。「**5分でも始められて、じっくり遊びたくなる**」冒険を求める人。アクションが少し苦手な人も含む
- ペイン: 大作は時間も気力も要る／スマホのゲームは課金や通知で落ち着かない／手触りの悪いアクションは疲れる
- ゲイン: 5分のステージを1つ遊んで「気持ちよかった」で終われる／続けると壮大な冒険になっている／キャラクターに愛着がわく
- 物語の目的（**確定 2026-10-04**）: 最後に縫われた人形ツギが、ほどかれて連れ去られた作り手ヌイばあを助けに行く。結び玉を取り戻すたびにヌイばあが少しずつ縫い戻り、最後に「最後に縫われた人形が、作り手を縫い直す」
- 市場分析（案）: 2D 横スクロールは定番で需要が安定。ブラウザ/PWA で無料で遊べる完成度の高い横スクロールは少ない
- 競合分析: マリオ（王道）、毛糸のカービィ・ヨッシーウール（布素材）、リトルビッグプラネット（布人形）。差別化は「和の端切れと裁縫道具だけで作った世界」「1ステージ1仕掛け」「キャラのぬいぐるみ化前提の造形」（`studio/characters/similarity.md`）
- Fit: ミッション「忙しい毎日から離れて、時間を忘れて没頭」→ 忙しい大人が短い区切りで遊べて、続けると没頭できる冒険。ビジョン「多くの人に愛される作品」→ アクションが苦手な人も続けられる難易度（中間地点・即リトライ）と、愛着のわくキャラクターと物語（ヌイばあを助ける）

## What（PM が決めて記録）
- メンタルモデル: 「右へ進んで杭の結び目を結ぶ」「ステージごとに新しい裁縫道具の仕掛けが1つ」「金ボタン3枚は寄り道のご褒美」「結び玉を取り戻すとヌイばあが戻ってくる」
- カスタマージャーニー: タイトル → 物語（ヌイばあがほどかれる）→ 地図 → 1ステージ（3〜6分）→ 結果 → 地図の道が縫われて伸びる → … → 砦のボス → 結び玉でヌイばあの手が戻る → 「つづく」→ 金ボタン集め
- コスト構造: AI 社員のトークン（エージェント呼び出し上限を STATUS で管理）。外部素材・ライブラリなし。配信は GitHub Pages（無料）
- 収益モデル（**確定 2026-10-04**）: **ワールド3までは完全無料**。ワールド4以降は「有料（買い切り or サブスク）」または「無料（広告）」を軸に検討。課金・広告の実装と契約はまだしない。地図・進行・セーブは「ワールド3まで無料／4以降は解放が必要」の区切りに対応できる設計にする（`world.access` の考え方、下の How）。10代を含むため年齢配慮の注意点は gs-legal のメモ（studio/legal/2026-10-04-monetization-minors.md、YELLOW）。解放の判定は core/world.js の worldUnlocked 1か所。ゲーム内通貨・ガチャは作らない。外への表示で「完全無料」とは書かず「ワールド1〜3は無料」と範囲を書く
- 指標: 「AIが作った感」レビュー **9/10 以上**（オーナー基準、届くまで直す）、ステージ別のクリア率・死亡数・時間（初心者ボット・playtester）、金ボタン発見率、オーナーが遊んで続きを作りたいと思うか
- マイルストーン: M1 = ワールド1（いまここ、体験版 30〜60分）→ M2 = キャラ決定版でワールド1を差し替え → M3 = ワールド2〜4 → M4 = ワールド5〜8・エンディング
- Fit: 「5分で気持ちよく終われる」= ステージ制と中間地点・即リトライ。「壮大な冒険」= 8ワールドの地図と物語。「キャラに愛着」= 立ち絵・表情・ヌイばあが戻っていく過程

## How（PM と担当）
- ユーザーインターフェース: 横画面 16:9（内部 256x144、ツギは画面の約1/6）、キーボード・パッド・スマホ仮想ボタン。HUD は洋服の織りネーム風。タイトル・物語・ステージ開始・ボス登場で大きな立ち絵
- キャラクター: ツギは C案「振袖の継ぎはぎ童子」（2026-10-04 オーナー決定。理由: 主人公らしさと 3DCG への拡張性）。全キャラを同じ画風で揃える（studio/characters/）
- 設計と実装: 自作エンジン（決定的な core、ステージは JSON の文字タイル図）、クリア確認ボット・初心者ボット・実ブラウザ確認の自動ゲート（`studio/gates.json`）
- Go To Market: 公開はオーナー承認後に GitHub Pages。ミニゲームのポータルと note の開発日記から誘導（未定）
- Fit: 手触り（What の「気持ちよく終われる」）は playtester の数値で、世界の一貫性（「キャラに愛着」）は design-system と reviewer で確認
