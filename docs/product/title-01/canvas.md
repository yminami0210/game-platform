## Core（オーナーが決める）
- ミッション: 仕事を忘れて没頭できる、手触りの良い冒険を届ける（会社のミッションの大型タイトル版）
- ビジョン: 「布と裁縫の世界」とツギを、ゲームを越えて手元に置きたくなる（ぬいぐるみ・グッズ）キャラクターに育てる。スタジオの看板作品にする
- 企業への貢献: 事業戦略1（看板となる世界とキャラクター）。ミニゲームで当たった遊びを仕掛けの種にする（事業戦略2）。将来のグッズ収益の土台（事業戦略3）

## Why（PM 案 → オーナー確認）
- ターゲットユーザー（案）: 仕事の合間・寝る前に、短い区切りで遊べる冒険をしたい大人（20〜40代）。かつてマリオやゼルダを遊び、今はまとまった時間が取れない人。アクションが少し苦手な人も含む
- ペイン: 大作は時間も気力も要る／スマホのゲームは課金や通知で落ち着かない／手触りの悪いアクションは疲れる
- ゲイン: 5分のステージを1つ遊んで「気持ちよかった」で終われる／続けると壮大な冒険になっている／キャラクターに愛着がわく
- 物語の目的（**確定 2026-10-04**）: 最後に縫われた人形ツギが、ほどかれて連れ去られた作り手ヌイばあを助けに行く。結び玉を取り戻すたびにヌイばあが少しずつ縫い戻り、最後に「最後に縫われた人形が、作り手を縫い直す」
- 市場分析（案）: 2D 横スクロールは定番で需要が安定。ブラウザ/PWA で無料で遊べる完成度の高い横スクロールは少ない
- 競合分析: マリオ（王道）、毛糸のカービィ・ヨッシーウール（布素材）、リトルビッグプラネット（布人形）。差別化は「和の端切れと裁縫道具だけで作った世界」「1ステージ1仕掛け」「キャラのぬいぐるみ化前提の造形」（`studio/characters/similarity.md`）
- Fit: ミッション（没頭できる冒険）と、ビジョン（キャラクターを育てる）に答える

## What（PM が決めて記録）
- メンタルモデル: 「右へ進んで杭の結び目を結ぶ」「ステージごとに新しい裁縫道具の仕掛けが1つ」「金ボタン3枚は寄り道のご褒美」「結び玉を取り戻すとヌイばあが戻ってくる」
- カスタマージャーニー: タイトル → 物語（ヌイばあがほどかれる）→ 地図 → 1ステージ（3〜6分）→ 結果 → 地図の道が縫われて伸びる → … → 砦のボス → 結び玉でヌイばあの手が戻る → 「つづく」→ 金ボタン集め
- コスト構造: AI 社員のトークン（エージェント呼び出し上限を STATUS で管理）。外部素材・ライブラリなし。配信は GitHub Pages（無料）
- 収益モデル（**未定・オーナー確認**）: 案は「ワールド1は無料体験版、続きは販売」「広告なし」「グッズ（ぬいぐるみ）」。今は決めない
- 指標: ステージ別のクリア率・死亡数・時間（初心者ボット・playtester）、金ボタン発見率、「AIが作った感」レビュー 7/10 以上、オーナーが遊んで続きを作りたいと思うか
- マイルストーン: M1 = ワールド1（いまここ、体験版 30〜60分）→ M2 = キャラ決定版でワールド1を差し替え → M3 = ワールド2〜4 → M4 = ワールド5〜8・エンディング
- Fit: 「5分で気持ちよく終われる」= ステージ制と中間地点・即リトライ。「壮大な冒険」= 8ワールドの地図と物語。「キャラに愛着」= 立ち絵・表情・ヌイばあが戻っていく過程

## How（PM と担当）
- ユーザーインターフェース: 横画面 16:9、キーボード・パッド・スマホ仮想ボタン。HUD は洋服の織りネーム風
- 設計と実装: 自作エンジン（決定的な core、ステージは JSON の文字タイル図）、クリア確認ボット・初心者ボット・実ブラウザ確認の自動ゲート（`studio/gates.json`）

- Fit: 手触り（What の「気持ちよく終われる」）は playtester の数値で、世界の一貫性（「キャラに愛着」）は design-system と reviewer で確認
