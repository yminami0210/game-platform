# コンセプト（2026-11-22 分身）

## 顔を上げて、自分の判断で負ける遊び

### 光景
夕食のあと、母がスマホを一台、食卓の真ん中に置く。今夜の一局は20分。
お題が出るたびに、全員が顔を上げて相手の顔を読む。負けた人は「なんでそれ出したの」と突っ込まれ、自分の判断を語らされる。
祖父が孫を読み切って勝ち、孫が本気で悔しがる。終わったら何も残らない。その夜で完結する。

### 体験の流れ
1. 真ん中に置いた一台が親になって、お題を出す
2. 各自が手札から、勝てると思うものを同時に出す（使ったものは戻らない）
3. 画面が判定し、全員の手を同時に見せる。外れた人の判断がみんなの前に出る
4. 数回ごとに「感想戦」：一番悔しい判断をした人を、画面が名指しする
5. 20分で千秋楽。名場面を一行だけ表示して終わる。翌日に持ち越すものはない

### やらないこと
1. 一人で遊べるモードは作らない
2. ガチャ・課金・スタミナ・ログインボーナスは入れない
3. 各自のスマホは使わせない。画面は卓の真ん中に一枚だけ
4. 偶然はお題だけ。勝ち負けは運ではなく判断で決まるようにする
5. 育成・記録・ランキングで翌日に引き留めない

### 素材になった声（段階1・2より）
- 「同じ食卓にいるのに、全員が別々の画面。『いただきます』を言ったのは私だけ」（母）
- 「ガチャは負けても誰のせいでもないから虚しい。麻雀は自分の判断のせいだから、悔しくてまた打つ」（隣の世界）
- 「半年貢いだゲームがサ終。何も残らない」→「終わりがある前提なら、それはもう公演。千秋楽」
- 「本音は、悔しい顔を誰かに見られたい」「相手に笑われるのが楽しい」
