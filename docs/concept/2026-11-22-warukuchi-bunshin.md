# 段階1 悪口：分身（生きるあなた）

題材：スマホで遊ぶゲーム。分身が実際に触れたもの（自分で作った3本、カードゲームの例、レビューの声）から。

- 自分で作ったノベル、最後まで読ませるテストは全部通ったのに、読んで誰かと話したくなる場所が一個もない
- 2周目の答え合わせ、作った側が一番楽しんでた。読む側にとっては宿題
- ホテルのやつ、断片を一人で全部集める設計にした時点で負けてた。仲間がいない推理はただの作業
- 「反転する一行」、4本とも途中でオチが読まれた。驚かせる側が型にはまるのが一番ダサい
- スマホのゲームは、隣に座ってる人と一緒に遊べない。同じ部屋にいて別々の画面
- カードゲームの例は、人と向き合ってるときが一番面白そう。スマホは向き合わせてくれない
- AIで絵も文章もいくらでも作れるのに、作れば作るほど一本の重みが軽くなる
- 毎日ログインさせる仕組み、誰も楽しくないのに全員やってる
- 無料のゲームは、時間を払わせて広告を見せる。遊んでるのか、働かされてるのかわからない
- 結局、レビューで褒められてるのは「暇つぶしにちょうどいい」。それって褒め言葉なのか
