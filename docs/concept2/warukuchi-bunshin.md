# 悪口：分身（生きるあなた）
- 分身：無料の娯楽は「時間を埋める」ようにできていて、終わったあと何も手元に残らない
- 分身：動画のおすすめは、昨日の自分が好きだったものしか出してこない。昨日の延長で一日が終わる
- 分身：お金をかけない過ごし方は、だいたい一人用。誰かを誘うとお金がかかる
- 分身：公園も図書館もタダなのに、「行く理由」が用意されていない。行っても誰とも関係が生まれない
- 分身：ショッピングモールは無料で居られるけど、「買わない人」として居心地が悪い
- 分身：暇な時間の過ごし方を聞かれて「特に何も」と答えるのが恥ずかしい
- 分身：何もしない休日は回復したはずなのに、日曜の夜に損した気分になる
- 分身：お金をかけた休日は話せる。かけない休日は話すことがない
- 分身：無料のものほど、こっちの時間と注意を取り立てに来る（広告、通知）
- 分身：暇があるのに、平日の昼に人と会う場所がない
