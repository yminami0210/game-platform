# コンセプト（2026-11-23 やり直し）

軸：お金が増えない中で、持て余した時間をどう使うか

## 客ではなく、手として呼ばれる

## 星座（どの付箋の関係からこうなったか）
1. g7 暇なのに金がない → g6 「時間あるでしょ」と誘われても、飲み代3千円で断る理由を考える → g1 断った夜は結局スマホ → g8 「週末何してた？」に答えられない ＝ g9 何もない自分がバレそうで怖い
   - 今の誘いは「客としてお金を払う」誘いばかり。だから暇な人ほど断り、一人になる。
2. g16 建前「悠々自適」本音「誰かに呼ばれたい」／「誰か今日の予定を命令してくれ」
   ＝ g15 料理本を借りても、作って食べさせる相手がもういない
   ＝ g17 月曜と弁当が消えて、起きる理由も消えた
   ⇔ g6 呼ばれたいのに、誘われると断る（3千円がかかるから）
   - 欲しいのは遊びの誘いではなく「あなたが要る」という呼ばれ方。
3. g3 11時半に妻の顔をじっと見る夫 ⇔ g15 40年食べる専門だった俺が、作る側に回る
   - 受け取る側から、手を出す側に回ると、家の中の関係も変わる。
4. g10 「暇すぎてYouTube見てた」が殴りたいほど羨ましい（共働きの親）／「暇なら手伝ってよ、と暇そうな親戚に何度思ったか」
   - 時間が余る人と、手が足りない人が、同じ町にいるのに出会っていない。
5. g4 平日昼の図書館は無職っぽくて落ち着かない → g5 閉館まで粘る、g12 常連の指定席で新しい人が来なくなる、g13 無料イベントに人は来るが何も動かない
   - タダの場所はあるが、「行く理由」がない。居るだけの場所は、常連の居間になる。

→ 誘いの通貨を「お金」から「手」に変える。客として誘われると3千円かかるが、手として呼ばれれば0円で、しかも行く理由と役割と、帰ってから話せることが手に入る。

## 光景
平日の10時、定年した男性のスマホに一通。「土曜の午前、2時間だけ草むしりを手伝ってもらえませんか。お昼は一緒に」。送り主は、近所の共働きの家。
子離れした主婦は、同じ通りの家の作り置きを一緒に作りに行く。大学生は、公民館の講座の準備係として呼ばれ、80代にスマホの設定を教える。
月曜、「週末何してた？」に「隣の庭を手伝ってた」と答えられる。

## やらないこと
1. 参加費を取らない。客として誘う形にしない
2. 時給や報酬を主役にしない（稼ぐ話にすると、すきまバイトと同じになる。お礼は一食まで）
3. 常連の指定席を作らない。呼ぶ相手と呼ばれる相手を入れ替える
4. 画面の中で完結させない。必ず誰かの家や場所に行く
5. 「何もしない休日」を否定しない。呼ばれたい人だけが手を挙げる

## 残る疑い
- 似た仕組みはある（シルバー人材センター、家事代行、助け合いアプリ、ボランティア）。どれも「有償の労働」か「奉仕」になっていて、「呼ばれること」そのものを目的にしていない、というのが新しさの一点。これが本当に違いになるかは、試して確かめる。
- 知らない人の家に行く・招くことの怖さと安全。
