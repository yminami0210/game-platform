## 1. 楽しさ — 5/10
- **30秒で分かるか: 分かる。** タイトルの説明が「押す＝巻いて上がる／離す＝下がる／赤く震えたら離す」の3点だけで、遊び始めにも同じヒントが出る。操作がボタン1つなので迷わない。
- **気持ちいい瞬間: 実装されている。** 糸の形が「たるむ↔ピン」と変わり、張りすぎると丹色に震えてきしむ音が鳴る。強い風の帯に入ると「ひゅう＋ピン」の音、尾がばたつき、高度が一気に伸びる。企画どおりで手ざわりは良い。
- **もう一回の仕掛け: ある。** 自己ベストの保存、高さに応じた称号（屋根の上〜雲の上）、強い風の秒数ボーナス。
- **重大な問題: 終わらない（開発担当の申告を再現した）。** `update()` をそのまま Node で動かし、自動プレイを1本あたり最大600秒、30本ずつ回した。

  | 方針（ボット） | 画面 | 600秒たっても終わらない本数 | 最高高度（中央値付近） |
  |---|---|---|---|
  | 張り0.78未満なら押す（ふつうの慎重プレイ） | 390x844 | 25/30 | 約180m |
  | 同上 | 844x390 | 24/30 | 約114m |
  | 強い風の中だけ0.84まで押す | 390x844 | 19/30 | 約188m |
  | 同上 | 844x390 | 28/30 | 約112m |
  | 張り0.9まで押す（雑なプレイ） | 両方 | 0/30（2〜4秒で切れる） | 約65m |

  原因:
  1. **高度が釣り合う所で止まり、それ以上もそれ以下も動かない。** 「押す」の上昇と張りの増え方、「離す」の下降と張りの減り方が高度だけで決まっていて、時間では一切きつくならない。慎重に押し離しするだけで 100〜200m に張りつき、何分でも浮いていられる。
  2. **鳥・電線に当たっても終わらない。** 1回 -30m と無敵1.6秒だけなので、釣り合い高度から地面まで落ちることがほぼない。
  3. **時間で厳しくなるのが「揺さぶり（jolt）」の間隔だけ**で、それも最短1.8秒で頭打ち。張りの閾値で離すだけのプレイには効かない。
  
  結果として、上手い人ほど同じ高さで同じ操作をくり返す時間が長くなり、スコアも伸びない（企画の「1回60〜120秒」と逆）。逆に「張り0.9まで押す」だけで2〜4秒で終わるので、終わり方が「すぐ切れる」か「終わらない」の両極端になっている。

## 開発担当への差し戻し指示（この順で直す）
1. **時間で必ず厳しくなるようにする（最重要）。** `update()` に経過時間の係数を入れる。例:
   - 基本の風を時間でも弱める: `wind = Math.max(.08, .32 - G.alt / 2000 - G.t / 400)`
   - 押しているときの張りの増え方に時間係数: `hard = 1 + G.alt / 400 + G.t / 60`
   - 離したときの落ち方も時間で速める: `target = -6.5 - G.alt / 150 - G.t / 20 + 8 * wind`
   - 目安: 下の検証で「張り0.78未満なら押す」ボットの終了時間の中央値が **60〜150秒**、600秒たっても終わらない本数が **0** になるまで係数を調整する。
2. **強い風の帯を「生き残る手段」にする。** 時間がたつと帯の外では高度を保てず、帯に乗りに行かないと落ちる、という形にする（1. の調整でそうなるはず）。強い帯の出現率は高度だけでなく時間でも減らす（`hard` に `G.t / 120` を足すなど）。
3. **鳥・電線の当たりを重くする。** どちらか片方でよい: (a) 当たるたびに下がる量を増やす（-30m → -30m − 経過秒×0.3 など）、(b) 当たると凧の骨が1本折れ、3回で落ちる（凧に墨のひびを描いて見せる）。
4. **出だしの理不尽な即死をやわらげる。** 張り0.9まで押すだけで2〜4秒で切れる。最初の10秒だけ `G.red` の上限を 1.2 → 2.0 にする、または最初の1回目の赤では切れずに「ぷつっ」と小さく鳴って張りが0.5に戻る、など。
5. **横画面のヒントの位置を直す。** `drawHUD()` のヒントは凧の y 座標を見て、凧と重ならない側（凧が下半分なら H*.25、上半分なら H*.7）に出す。
6. （任意・デザイン）強い風の帯は画面に同時に見えるのを最大2本までにするか、遠い帯は藍鼠に寄せて薄くし、丹は「凧に近い帯」だけにする。HUD の高度は和紙の短冊に書いた形にすると絵になじむ。

検証方法: `index.html` の `<script>` から IIFE を外して Node で読み込み、`newGame(); state='play'` の後に `holding = G.tension < .78; update(1/60)` を600秒分くり返すと、終了時間を30本まとめて測れる（縦 390x844 と横 844x390 の両方で）。直したら `node arcade/bin/qa.mjs` と `python3 arcade/bin/arcade.py check` を再実行する。
