- 合格ライン: ミニゲーム 8/10（「AIが作った感」スコア）

## 1. どの Core・Why に答える見た目か（product-layers）
- Why「覚えることが多い・仕事を思い出す」へは、仕事と無縁な**イギリスの家庭菜園の一角を1枚の刺繍布にしたもの**で答える。開いた瞬間に「豆の支柱・生垣・畑・伏せた鉢」と、支柱のあいだの銀の糸が見え、説明より先に「ここに糸を渡す」と分かる。
- Why「1回で気持ちいい瞬間」へは、**銀糸だけを画面でいちばん明るい線**にして答える。糸に縫い付けた露のビーズが増えていき、虫がかかると糸がしなって露が片側へはじける（plan の「いちばん印象に残す1点」を引き継ぐ）。

## 2. 借りてくる物（実在の物・場所・技法）
- 主に借りる物（2つで1組）

## 3. 形の言葉（シェイプランゲージ）
- **木の物＝細長い棒**（支柱・木札・糸巻き）。長さ方向のサテンで、皮目の短い横針を不揃いに。支柱は3本組み＋右に1本で、上を麻ひもの結び玉で縛る。
- **植物＝丸いこんもりとハート形**。生垣は大きさの違うこんもりを奥から重ね、上の縁ほど明るい。豆の葉は大きさ・向きをそろえず、茎から支柱へ1針でつなぐ。
- **糸＝わずかにたるむ曲線**。長い糸ほどたるむ。虫がかかった糸は弓なり（たるみを大きく）。交わった所に銀の結び玉（＝新しいかけ所）。
- **かけ所＝まち針**（青灰の頭）。選んだかけ所は頭が銀に大きくなり、糸が1本垂れる（汎用の丸や光の輪にしない）。
- **生き物＝刺繍のワッペンの大きさと形**（全部、写実にしない）
  - 庭蜘蛛: 丸い腹（茶のサテン）に白い結び玉5つの十字、脚8本は明るい麻色の**短く太い2針ずつ**（ほぼまっすぐで膝を作らない。脚の届く範囲は胴の長さの1.3倍以内）。毛・爪・目・牙は描かない。画面では全高の約3%（1x で直径約25px）までの大きさ。
  - ハエ: 濃灰の小さな楕円＋線だけの羽。ガ: 丸い4枚の羽（淡い麻色）に目玉模様の結び玉。カナブン: 緑の楕円に銀の光の針2本。テントウムシ: 赤いサテンに濃灰の結び玉。
  - **ミツバチ＝丸い1つの胴**（琥珀のサテンに焦げ茶の太い帯2本、大きめの線の羽2枚。粒の群れにしない。等倍で胴の直径 15px 以上。レモンを使わない）。**スズメバチ＝細い腰ととがった腹**（レモンと濃灰の帯3本、帯の幅はそろえない）、針は描かない。形と色の両方で見分ける。
- シルエットの約束: 黒塗りでも 蜘蛛（丸＋8本の短い脚）・ガ（丸い4枚羽）・カナブン（楕円＋6本の脚）・ミツバチ（丸）・スズメバチ（くびれ＋とがり）が見分けられる。

## 6. 質感と「人の手の跡」
1. **毛糸の1針ごとのふくらみ**: 下に濃灰の影（0.7,1.1px ずらし）→ 本体 → 上に細い光。針の長さ・向き・色の揺れ（±9%）は1針ずつ違う（等倍で見える 1.6〜2.8px 幅）。
2. **とめ縫い**: 銀糸の上に濃灰の小さな留めを 13〜24px の不揃いな間隔で。糸の下に 0.9,1.5px ずらした影（等倍で見える）。
3. **ビーズの露**: 大きさ 1.5〜3.2px、間隔不揃い。透けた胴＋下の濃い縁＋小さな白い点（グロー無し）。
4. **しつけ糸**: `setLineDash` を使わず1針ずつ描く。長さ 5〜14px・間隔 3〜9px・傾き ±4°、両端を細く（針穴に入る）、下に濃灰の影 0.8px、通り道はゆるい S 字。ふつうの虫は銀灰の1本どり、スズメバチは**レモンと濃灰の2本どり（撚り糸）**。
5. **輪郭**: 葉・虫・鉢は少し暗い色の短い破線（返し縫い）で縁取る。
6. 麻布の織り目（縦横の節とスラブ）は刺していない所にだけ見える。生垣・土・葉には布の目を重ねない。
7. **刺しかけと布の端**: 輪郭だけの株2つ（返し縫いの輪郭＋数針）、こんもりの上半分の返し縫いの輪郭、雲のステムステッチの輪郭、下の端の折り返しとまつり縫い。

## 7. 動き
- 操作への返事: 糸を渡すと、始点から終点へ銀糸が伸び、張り終わりで1回だけ小さく震える（弦の「ぴん」）。虫がかかると糸が弓なりにしなり（0.25秒）、露のビーズが**片側へ3粒まで**はじける。巻くと虫が銀のサテンの繭に変わる。スズメバチが通ると糸がほどけて端が丸まる（sheet の「食い破られた糸の端」）。糸を切ると両端がゆっくり垂れる。
- まち針を押すと頭がふくらんで銀になる。
- 何もしていないときの動き: **露のビーズが時間とともに1粒ずつ増える**ことだけ（点滅・グロー・光の輪なし。雲・生垣は動かさない。風のときだけ葉が傾くのは遊びの予告なので別扱い）。

## 8. 使わないもの（この作品で避ける定番）
- game-art-direction §2 のうち陥りやすいもの: 夜空に光る粒（露をきらめかせすぎると近づく → グロー・光の輪・十字の光は使わない）、クリーム地＋テラコッタ（鉢は小さく脇だけ）、角丸カード（UI は名前テープ）、あおり文句
- 過去の事前審査の指摘を最初から避ける:
  - 背景1色が大半 → 生垣はこんもり15個の重なり（大きさ・明暗が違う）、芝の小道は斜め、畑は小道で2枚に割る。水平の帯4段にしない（scene の最大の単色面は無い）
  - アイコンが汎用的 → 点数＝名前テープ、糸の残り＝糸巻き、時間＝縫い進む針、かけ所＝まち針、一時停止・音＝テープの字。‖・歯車・ハート・時計の絵は使わない
  - 小さい文字・判のコントラスト不足 → 小さい字は白いテープ（#f5f4ee）に濃灰（#2a2f33）、コントラスト 約13:1
  - 同心円の弧が Wi-Fi（蜘蛛の巣は特に） → **同心円・渦巻きの「蜘蛛の巣の絵」を一度も描かない**。網はプレイヤーが張った直線に近い糸の重なりだけ。ガの目玉も小さな結び玉1つ
  - 規則的な縞・記号の点線 → 空は雲1つの輪郭だけ。しつけ糸は1針ずつ（setLineDash 不使用）。畝の筋は2本で間隔・傾きを変える。スズメバチの帯は幅をそろえない
  - 同じ形のスタンプ → 生垣のこんもりは15個で半径 20〜92px（4倍以上の幅）。葉・ビーズは1つずつ大きさと向きをシード固定の乱数で変える
  - 均一塗りで素材っぽい → 面はすべて針目で埋める（塗りは針目の隙間の下地だけ）
  - 輪郭や版ずれが等倍で見えない → 影 0.7〜1.5px ずらし＋濃灰 0.3〜0.45、留め 1.1px、縁取り 1.1〜1.3px（390px 幅の等倍で見える）
  - 光が黄色い塊 → 太陽を描かない。露は白い点つきのビーズ。レモンは危ない物だけ
  - 波線が記号 → 風は「〜」で描かず、葉の傾きで予告する。羽音は線で描かない
  - 全面に同じ密度のノイズ粒 → 生垣はこんもりごと、土はゆっくり変わるまだらで密度・向き・色を変える。麻の節は空だけ
  - 白が灰色に濁る → 名前テープと銀糸の光は #f5f4ee／#ffffff、灰色を乗算しない
  - 物が別の物に見える → 雲は1つ・底も起伏させる（食パンに見えた）、輪郭は鎖の輪にしない（金属の鎖・有刺鉄線に見えた）、ミツバチを粒の群れにしない、生垣を横一列の帯にしない（山並みに見えた）、土を楕円の固まりにしない（芋・石に見えた）、豆の花の赤い結び玉はやめた（実・ベリーに見えた）、物置の屋根は山に見えたので外した
  - ストック顔 → 虫にも蜘蛛にも顔を付けない
- 蜘蛛・スズメバチが苦手な人への配慮: 小さい粒の群れ（集合体）を作らない（ミツバチは1つの胴、露のビーズは糸の上に間を空けて並ぶ）。蜘蛛は丸い腹と短く太い2針の脚だけ（毛・爪・複眼・牙なし、脚は明るい麻色で細かい関節を描かない）、大きくしない。スズメバチは針・顎を描かず、羽は線だけ。捕まえた虫は銀の繭にくるむだけで、食べる・体液などは描かない。
- 似てしまいそうな既存作品と違い方: 002（凧の糸1本）は和紙の泥絵具で張りの強さを見せる遊び、本作は毛糸の刺繍で糸の「本数と交わり」を見せる。004（水みち）は線が水色に染まる、本作は糸にビーズが増える。英国の菜園の絵本（水彩・パステル）とは、技法（刺繍）・地（灰緑の麻）・登場物（服を着た動物がいない）で違う。

- 1枚絵の見本（修正版で撮り直し。代表場面: 昼前。支柱のあいだに5本、ガがかかって糸がしなり露がはじけた瞬間。右からスズメバチの通り道がレモンと濃灰の2本どりのしつけ糸で予告され、上の糸がその上にかかっている。390×844 の2倍）: `design/scene.png`（元 `design/scene.html`）
- 色と形の見本帳（毛糸のかせ6色、糸と露の見本、生き物7種、画面の部品、文字）: `design/sheet.png`（元 `design/sheet.html`）
- 描画道具: `design/stitch.js`（針目・とめ縫い・ビーズ・しつけ糸・支柱・葉・生垣・生き物・名前テープ・糸巻き・針。実装でも同じ考え方を canvas で使う）
- 撮影: Playwright（/opt/pw-browsers の Chromium）で Google Fonts（RocknRoll One・Yomogi）を読み込ませた状態で撮影。フォントファイルはリポジトリに置いていない。
- 結果画面（実装で作る。見本は未作成）: その日の網を、まわりを刺していない麻布の上に糸とビーズだけで残し、下の名前テープに日付・捕まえた虫の数・点数・自己ベストを1行ずつ書く（「A · B · C」の区切りは使わない）。
- 実装で守る条件
  - 動かない物（麻の地・雲・生垣・小道・畑・支柱・葉・鉢・木札・布の端）は**起動時に offscreen canvas へ1回だけ**描き、毎フレームは `drawImage` だけ。**`ctx.filter`・`shadowBlur`・毎フレームの乱数・`createPattern` は使わない。** 影は「濃灰をずらして先に描く」で作る。
  - **`setLineDash` で予告のしつけ糸・糸を描かない**（1針ずつ、張った時／予告が出た時にシード固定で針目を作って持たせる）。縁取りの返し縫いの `setLineDash` は静止物の offscreen 描画だけ可。
  - 糸は毎フレーム描く（点列＋`lineTo` を3回: 影・本体・光）。太さは等倍 2.5px、生垣の明るい縁より明るく保つ。とめ縫いの位置とビーズの位置・大きさは**糸を張った時にシード固定で1回だけ**決めて糸に持たせる（毎フレーム揺らさない）。
  - 生き物は大きさ別に1回だけ offscreen に描いたスプライトを `drawImage`＋`rotate` で動かす。羽ばたきは2コマの差し替えだけ。
  - devicePixelRatio は最大2。影・留め・縁取りの幅は CSS ピクセル（390px 幅の等倍）で見える幅を守る。
