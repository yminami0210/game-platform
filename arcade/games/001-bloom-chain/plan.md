# Bloom Chain（ブルームチェイン）

## 一行ピッチ
夜の池をただよう光の種に、ワンタップで花をひとつ咲かせる。触れた種が次々に咲いて、画面いっぱいの連鎖になる。

## 30秒のコアループ
1. 画面には光る種が30〜60個、ゆっくり漂っている（ラウンドごとに数と速さが変わる）。
2. プレイヤーは **1ラウンドに1回だけ** タップする。タップした地点に花が咲き、円がふわっと広がって約1.5秒で閉じる。
3. 広がった花に触れた種も同じように咲き、さらに周りを巻き込む。連鎖は勝手に進むので、プレイヤーは見守るだけ。
4. 連鎖が止まったら結果表示（咲いた数／目標数）。目標に届けば次のラウンドへ。1ラウンドはおよそ5〜10秒。
5. 「どこに置けば一番つながるか」を一瞬で見極めて、置いて、眺める。これを繰り返す。

## 操作
- スマホ: 画面のどこでもタップ（タッチ開始で即反応。長押し・スワイプは不要）。
- PC: マウスクリック。キーボードは矢印キー／WASDで照準カーソルを動かし、スペースまたはEnterで咲かせる。
- 結果画面・ゲームオーバー画面は、タップ／クリック／スペースで次へ進む。
- 縦画面・横画面どちらでも、キャンバスが画面に合わせて広がる（種の配置は画面比率に合わせて生成）。

## 気持ちいい瞬間
- 連鎖が5個、10個、20個…と増えるたびに、音の高さが一段ずつ上がっていく（ドレミの音階で上昇）。
- 連鎖数がしきい値（10・25・40）を超えると、画面がわずかに明るくなり「×10 BLOOM!」のような大きな文字が弾ける。
- 最後の一輪が咲き終わる瞬間に、全部の花が同時にきらっと光る締めの演出。
- 全部の種を一つ残らず咲かせると「ALL BLOOM」ボーナス（スコア2倍、花びらが降る演出）。

## 終わり方とスコア
- 全8ラウンド。各ラウンドに目標数（例: 1R 5個 → 8R 45個）がある。
- 目標に届かなかったらその時点で終了。ただし **ライフ1回分の「おかわり」** があり、1度だけ同じラウンドをやり直せる（初心者でも3〜4ラウンドは遊べる）。
- スコア = 各ラウンドの（咲いた数 × 連鎖の深さボーナス）の合計。連鎖の深さ＝「何段目まで伝わったか」で、深いほど1輪あたりの点が上がる。
- 8ラウンド全部で約1.5〜2.5分。最高スコアは localStorage に保存して、タイトル画面に表示（読み書きは try/catch で囲む）。
- 終了画面で「もう一回」がすぐ押せる（1タップで再開）。

## 既存作との違い
- 工場の1本目なので既存作はなし。
- 操作は「1ラウンド1タップ」だけ。反射神経も連打もいらず、置く場所を選ぶ判断と、その後の連鎖を眺める爽快感だけに絞る。
- 一般的な「連鎖反応」の遊びをベースに、連鎖の深さでスコアが伸びる仕組みと、音階が上がっていく演出で、端の種まで届かせたくなる工夫を入れる。

## 見た目と音
- 背景は濃紺の夜の池（縦方向のグラデーション＋かすかな波紋）。種は小さな光の点で、色はラウンドごとに変わる（水色・桃色・黄緑・すみれ色…）。
- 花は半透明の円＋6枚の花びらの簡単な図形。広がるときに少し回転し、閉じるときは光の粒になって散る。すべて Canvas で描く（画像ファイルなし）。
- 音は Web Audio API で生成。咲くたびに短いベル音（サイン波＋短い減衰）を鳴らし、連鎖の段ごとにペンタトニック音階で上がる。同時に鳴りすぎないよう、同時発音数は制限する。
- 最初のタップで AudioContext を開始（ブラウザの自動再生制限に対応）。画面の隅にミュートボタン（キーは M）。
- 実在のゲーム・キャラクター・商標の名前や見た目は使わない。オリジナルの図形と配色のみ。
