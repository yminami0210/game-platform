# 蓮ひらく（はすひらく）

## 一行ピッチ
夜の池をただよう光の種に、ワンタップで花をひとつ咲かせる。触れた種が次々に咲いて、画面いっぱいの連鎖になる。

## 30秒のコアループ
1. 画面には光る種が30〜60個、ゆっくり漂っている（ラウンドごとに数と速さが変わる）。
2. プレイヤーは **1ラウンドに1回だけ** タップする。タップした地点に花が咲き、円がふわっと広がって約1.5秒で閉じる。
3. 広がった花に触れた種も同じように咲き、さらに周りを巻き込む。連鎖は勝手に進むので、プレイヤーは見守るだけ。
4. 連鎖が止まったら結果表示（咲いた数／目標数）。目標に届けば次のラウンドへ。1ラウンドはおよそ5〜10秒。
5. 「どこに置けば一番つながるか」を一瞬で見極めて、置いて、眺める。これを繰り返す。

## 操作
- スマホ: 画面のどこでもタップ（タッチ開始で即反応。長押し・スワイプは不要）。
- PC: マウスクリック。キーボードは矢印キー／WASDで照準カーソルを動かし、スペースまたはEnterで咲かせる。
- 結果画面・ゲームオーバー画面は、タップ／クリック／スペースで次へ進む。
- 縦画面・横画面どちらでも、キャンバスが画面に合わせて広がる（種の配置は画面比率に合わせて生成）。

## 気持ちいい瞬間
- 連鎖が5個、10個、20個…と増えるたびに、音の高さが一段ずつ上がっていく（ドレミの音階で上昇）。
- 連鎖数がしきい値（10・25・40）を超えると、画面がわずかに明るくなり「×10 BLOOM!」のような大きな文字が弾ける。
- 最後の一輪が咲き終わる瞬間に、全部の花が同時にきらっと光る締めの演出。
- 全部の種を一つ残らず咲かせると「ALL BLOOM」ボーナス（スコア2倍、花びらが降る演出）。

## 終わり方とスコア
- 全8ラウンド。各ラウンドに目標数（例: 1R 5個 → 8R 45個）がある。
- 目標に届かなかったらその時点で終了。ただし **ライフ1回分の「おかわり」** があり、1度だけ同じラウンドをやり直せる（初心者でも3〜4ラウンドは遊べる）。
- スコア = 各ラウンドの（咲いた数 × 連鎖の深さボーナス）の合計。連鎖の深さ＝「何段目まで伝わったか」で、深いほど1輪あたりの点が上がる。
- 8ラウンド全部で約1.5〜2.5分。最高スコアは localStorage に保存して、タイトル画面に表示（読み書きは try/catch で囲む）。
- 終了画面で「もう一回」がすぐ押せる（1タップで再開）。

## 既存作との違い
- 工場の1本目なので既存作はなし。
- 操作は「1ラウンド1タップ」だけ。反射神経も連打もいらず、置く場所を選ぶ判断と、その後の連鎖を眺める爽快感だけに絞る。
- 一般的な「連鎖反応」の遊びをベースに、連鎖の深さでスコアが伸びる仕組みと、音階が上がっていく演出で、端の種まで届かせたくなる工夫を入れる。

## 見た目と音
- **借りてくる物**: 蓮池を描いた近代の日本画（岩絵具の緑青で塗った水面に、胡粉の白い蓮を置き、墨の線でくくる画面）。水面は岩絵具の粒のむらと絹目のざらつき、花は花びらの先にだけ紅を差す「隈取り」。結果の札は画面の端に添える和紙の短冊、印は画家の落款。
- **パレット**: 緑青 `#4a7a68`（池の地）／白緑 `#a9c7ae`（浮き葉）／胡粉 `#f0ede4`（花びら・札・文字）／臙脂 `#a3344a`（花の先・落款）／金泥 `#c2a05a`（蓮の実・締めの輪）／墨 `#26302b`（線・札の文字）。主役の色は臙脂で、花の先と印の2か所だけに使う。
- **フォント**: Yuji Syuku（筆の明朝。題・池の名前・得点・十輪などの大きな文字・印の字）＋ Zen Kaku Gothic New 500/700（遊び方・数字の説明・ボタン）。Google Fonts から読み、届かないときはヒラギノ明朝／游明朝・ヒラギノ角ゴ／Noto に落ちる。文字は横画面でも 12.5px を下回らない（倍率の下限 0.85）。
- **いちばん印象に残す1点**: 画賛のような縦書きの題「蓮ひらく」と、結果が出るたびにぽんと押される朱の落款（満・咲・散・了の白文印、朱肉のかすれつき）。
- **人の手の跡**: 花びらと浮き葉の墨線を塗りから 1〜2px ずらして刷る（版ずれ）。花びらの膨らみ・浮き葉の縁・花の届く輪・短冊の角に少しずつ揺れ。背景は岩絵具のむら＋ざらつきを画面サイズが変わったときに1回だけ描いて使い回す。
- **形**: 種は切れこみのある小さな浮き葉。花は上から見た蓮（外8枚・内6枚＋蓮の実）で、池ごとに紅蓮・薄紅・白蓮・深い臙脂を変える。花の届く範囲は水面に広がる胡粉の輪で見せる。咲き終わると花びらになって散り、連鎖の締めでは咲いた場所に金泥の輪が広がる。満開では胡粉と薄紅の花びらが降る。
- **動き**: 何もしていないときの動きは水の輪1種類だけ（点滅する文字は使わない）。操作への返事として、蓮がひらく・印が押される・十輪/二十五輪/四十輪の筆文字が出る。
- **文言**: 「〇の池」「咲いた n / 目標 m」「n 点」「おかわり 一回」、結果は「満開」「咲きそろった」「あと n 輪」。あおり文句は使わない。
- 音は Web Audio API で生成。咲くたびに短いベル音（サイン波＋短い減衰）を鳴らし、連鎖の段ごとにペンタトニック音階で上がる。同時発音数は8までに制限。最初のタップで AudioContext を開始し、右上にミュート（キーは M）。
- 実在のゲーム・キャラクター・商標の名前や見た目は使わない。特定の画家の作品を写さず、日本画一般の画材と画面の作りだけを借りる。画像ファイルは使わず、すべて Canvas で描く。
