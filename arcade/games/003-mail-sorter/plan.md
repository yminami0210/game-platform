# 003 最終便まで（mail-sorter）

ジャンル: 仕分け・瞬間判断（スワイプ）

## 一行ピッチ
机にすべり込む封筒の切手を見て、上下左右の4つの郵便袋へ指ではじいて仕分ける。外国の小さな郵便局の夜勤、最終便の飛行機が来るまでの2分間。

## 30秒のコアループ
1. 画面の中央が仕分け台。上下左右の縁に郵便袋が4つ下がり、それぞれに行き先の札（灯台・山・麦・魚の4つの架空の町の印）が付いている。
2. 封筒が1通ずつ台にすべり込む。封筒の切手に町の印が描いてある。
3. 切手と同じ印の袋の方向へ封筒をはじく。正しい袋に入ると「ボスッ」と袋がふくらみ、封筒には消印が押されて飛んでいく。
4. 間違えると封筒が戻ってきて机の上に「返送」の付箋が付き、時計が3秒進む（残り時間が減る）。
5. 連続で正しく仕分けると「手さばき」が上がり、封筒の流れが速くなるかわりに1通の点が増える。30秒ごとに局長が袋の札を掛け替える（2つの袋の行き先が入れ替わる）ので、毎回切手と札を見直す。

## 操作
- スマホ: 封筒を上下左右にスワイプ（フリック）してはじく。ゆっくりドラッグして袋の上で離しても入る。
- PC: 矢印キー または WASD で、その方向の袋へはじく。マウスで封筒をドラッグ／フリックしても同じ。
- M で音を消す。P または Esc で一時停止。
- 縦画面・横画面どちらでも、袋は画面の4辺に付くので判断は同じ。

## 気持ちいい瞬間
- 手さばきが乗っているとき、親指を弾くたびに「シュッ・ボスッ・トン（消印）」が一定のリズムで鳴り、封筒が机から次々消えていく。
- 中盤から「束」（同じ町宛ての封筒が紐でくくられた3〜5通）が来る。1回のスワイプで束ごと飛ばすと、袋が大きくふくらみ、消印が連続でトトトンと押される。
- 終盤20秒は「最終便」。窓の外にプロペラ機が降り、全得点が2倍、束が続けて流れてくる。最後の1通を投げ込んだ瞬間に扉が閉まり、機体が飛び立つ。

## 終わり方とスコア
- 1勤務 = 時計で120秒の固定（誤配で3秒ずつ減るので、実際は90〜120秒）。必ず2分以内で終わる。
- 得点 = 1通ごとの基本点 × 手さばき（連続正解で1.0→最大3.0、誤配で1.0に戻る）。束は通数ぶん、最終便の20秒間は2倍。
- 難しさは「経過時間」で上がる（learnings 002 の学び）: 封筒の来る間隔が時間で短くなり、60秒以降は札の掛け替えと束が加わる。報酬も時間で増える（束・最終便）ので、最高得点のペースは中盤〜終盤（80〜120秒）に来る。
- 実装後に自動プレイで「終了時間の中央値が60〜150秒」「1秒あたり得点の最大が後半」に入るかを確かめる。
- 結果画面: 消印を重ねた1通の封筒（仕分けた通数・最高手さばき・得点）と、ベスト記録。

## 既存作との違い
- 001 蓮ひらく（連鎖パズル×タップで位置を選ぶ）・002 雀凧（ワンボタン×長押しの時間調整）に対し、今回は **方向を選ぶスワイプ** と **一瞬で見て判断する** 遊び。狙いも溜めも無く、1通ごとに0.5秒で決める反射と記憶の勝負。
- 盤面は1つの封筒だけで、画面の情報は「切手1枚と札4枚」に絞る。札の掛け替えで、慣れた指の癖を一度崩させるのが山場。
- 舞台・見た目は和風から離れ、外国の郵便局（航空便の封筒・切手・消印）。

## 見た目と音
- 借りてくる物: 1950年代ごろの航空郵便の封筒（縁に赤と青の斜めストライプ）、目打ちのある切手、紫インクのゴム印の消印、郵便局の麻の郵便袋と木の仕分け台。特定の国の郵便や実在の切手・ロゴは描かない（町の印も架空）。
- パレット（名前つき）:
  - 封筒紙 #e9dcc0（地の色。机の上の封筒）
  - 航空便の赤 #b8322a（主役。封筒の縁ストライプと最終便だけに強く使う）
  - 航空便の青 #2f4f8f（縁ストライプの片割れ・袋の札の文字）
  - 消印インク #5b3f6e（紫寄りのゴム印インク。消印・返送の付箋）
  - 麻袋 #a4885a（郵便袋と台の木目）
  - 夜勤の墨 #2a2622（背景の机の暗がり・本文の文字。真っ黒ではない）
- フォント:
  - 見出し・スコア・消印の文字: Dela Gothic One（ゴム印のつぶれた太字。数字は tabular-nums）
  - 本文・説明・札の町名: Kaisei Opti（郵便の書式の端正さ）
  - フォールバック: "Hiragino Sans", "Noto Sans JP", sans-serif
- いちばん印象に残す1点: 封筒を袋に入れるたびに押される **紫の消印**（中に勤務時計の時刻。1〜2pxの版ずれとかすれ、毎回少し傾く）。結果画面では、その勤務で押したすべての消印が1通の封筒に重なって押される。
- 人の手の跡: 封筒・切手の目打ちの線に±1pxの揺れ、紙のざらつきを canvas で1回描いて使い回す、縁ストライプのわずかな版ずれ。何もしていないときの飾りの動きは「天井の裸電球がゆっくり揺れて影が動く」1種類だけ。
- 避けるもの: 紺黒＋ネオン、クリーム＋テラコッタ（封筒紙は黄みの強い茶封筒寄り、赤は朱でなく深い郵便の赤）、角丸カード、和風の要素。
- 音（WebAudio で合成、外部音源なし）: はじく「シュッ」（ノイズの短いスイープ）、袋に入る「ボスッ」（低いこもった音）、消印の「トン」（短い木の打音）、誤配の「ブー」ではなく紙がくしゃっと戻る音、手さばきが上がるごとに打音が少し高くなる、最終便でプロペラの低いうなりが近づき、最後に局の呼び鈴「チン」で勤務終了。
