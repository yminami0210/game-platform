## 1. 楽しさ
- **30秒で分かるか**: 分かる。画面の情報は切手1枚と札4枚だけ。開始時に「切手の印と同じ札の袋へはじく」の一言が出る。
- **気持ちいい瞬間**: 実装されている。袋のふくらみ・消印・「シュッ/ボスッ/トン」・手さばきで打音が上がる・束でトトトン・最終便の帯とプロペラ音・扉が閉まって機体が飛ぶ演出。
- **もう一回**: ベスト記録、手さばき最大×3、札の掛け替え（3回）で「次はもっと」となる。結果画面で消印が1通に重なるのは良い記念品。
- **問題（REVISE の理由）**: 封筒の待ち行列が6通を超えると、**画面に何も出ないまま1通が消え、手さばきが×1.0に戻る**（音は誤配と同じ「くしゃっ」だけ）。待ちの山は画面に描かれていないので、プレイヤーには「何もしていないのに誤配の音が鳴って倍率が落ちた」としか見えない。自動プレイでは普通の腕前でも1回あたり約7回、新人は約26回起きる。しかも間隔が最短になる **最終便（山場）で集中して起きる**ので、いちばん気持ちいいはずの時間に理由の分からない倍率リセットが入る。

## 開発担当への指摘（このまま直せる単位）
1. **【必須】待ちの山を見せ、取りこぼしを見える出来事にする**（index.html）
   - `draw()` で、封筒がすべり込んでくる側（左の袋の上、または台の左下）に `S.queue.length` 通ぶんの封筒の端を少しずつずらして重ねて描く（最大6通）。山が高くなるのが見えると「急がないと」が伝わる。
   - CORE の `update()` の取りこぼし（`s.queue.length >= 6`）で、`s.streak = 0` をやめるか、`s.streak = Math.floor(s.streak / 2)` に弱める。倍率を落とすなら必ず目に見える理由を付ける。
   - `step()` の `e.type === "drop"` で、山のいちばん上の封筒が机の外へすべり落ちる演出と「取りこぼし」の付箋（返送と同じ作り）を0.6秒出し、手さばき表示を一瞬だけ赤（#f0c9b4）で点滅させる。音は誤配の `crumple` ではなく、紙がすべり落ちる別の音（例: `noise(t, 0.25, 1200, 300, 0.7, 0.2)`）にする。
   - 直したら自動プレイで、普通の腕前（反応0.7秒・誤配8%）の最終便20秒間の得点が、その前の20秒より高いことを確かめる。
2. **【必須】得点の小札を読めるようにする**: `popups` の文字色を、封筒の上に重なる場合でも読めるよう、夜勤の墨 #2a2622 の縁取り（`strokeText`、lineWidth 4）＋封筒紙色の塗りにするか、出す位置を袋の札のすぐ内側（封筒と重ならない所）にする。
3. **【推奨】縦画面の左右の札**: `tw < 84` のとき、印を上・町名を下の縦並びにし（印 `ss` を `th*0.5` に縮める）、文字と絵が重ならないようにする。
4. **【推奨】1分を切らない保証**: 誤配の時計の減りを、累計で最大30秒までにする（例: `s.penalty` を数えて30秒を超えたら減らさない）か、2秒に下げる。新人でも60秒以上遊べるようにする。

## 判定の理由
1〜3分で必ず終わり、最高の時間帯は中盤〜終盤（learnings 001・002 は守られている）。完成度・デザイン・権利は基準を満たす。ただし、待ちの山が見えないまま取りこぼしで倍率が戻る仕組みが、普通の腕前でも山場の最終便に集中して起き、「30秒で分かる」「気持ちいい瞬間」を両方崩している。修正は小さいので差し戻す。
