## 1. どの Core・Why に答える見た目か（product-layers）
- Why「覚えることが多い・仕事を思い出す」へは、仕事と無縁な**年の瀬の町内の餅つきの会場**そのものを1画面に置いて答える。開いた瞬間に「ブルーシートの上の臼と杵、塀の前の見物人と太鼓」が見え、説明より先に何をする遊びか分かる。
- Why「5秒で始められ、1回で気持ちいい瞬間」へは、**餅の白**だけをいちばん明るい面にして答える。ゲージは出さず、つくたびに米粒が消え、つやの切れ端が増え、最後にぷるんとはねる餅の面そのものが出来の表示（plan の「いちばん印象に残す1点」を引き継ぐ）。

## 2. 借りてくる物（実在の物・場所・技法）
- 主に借りる物（2つで1組）

## 3. 形の言葉（シェイプランゲージ）
- **木の物＝はさみで切った滑らかな曲線**（臼・杵・のし台）。ちぎらない。臼は「低く・腰でくびれる・縁が厚い楕円」の形で、切り株や丸太に見えないよう、高さは幅の約0.8、側面に明るい帯（左寄り）と暗い帯（右端）を1枚ずつ貼って円筒に見せる。年輪は描かない（同心円が Wi-Fi に見えるため）。
- **柔らかい物・軽い物＝ちぎった辺**（湯気・取り粉・布巾・吹き出し・札）。湯気は波線や渦にせず、縦に長いちぎった薄紙2枚。
- **餅＝輪郭の滑らかな白い楕円**。つや＝白い紙の細い切れ端（黄色の光の塊にしない）、くぼみ＝青みの白の三日月。残った米粒は大きさ・向きがばらばらの小さな楕円で、**縁ほど多く中央ほど少ない**（つかれた所から消える）。
- **手＝白い軍手**（素手を描かない）。指4本と親指が別々の紙片、手首に青い縁かがり。命の札も同じ軍手（汎用のハート・アイコンを使わない）。失うと点線の輪郭だけ残る。
- **拍＝臼の前の縄の8つの結び目**。いまの拍の結び目にだけ橙の札が立つ（光らせない）。
- 見物人は1人ずつ形を変える（帽子・フード・ハンチング・マフラー、背の高さ、表情）。同じ顔を繰り返さない。
- 一時停止・音の切り替えも札の形（軍手を留めた札など）で作り、‖ や歯車の汎用アイコンは置かない。
- シルエットの約束: 黒塗りでも 臼（くびれた器）・杵（円柱＋柄）・軍手・ビールケース（手かけの穴）・蒸籠・ボウル が見分けられる。

## 5. 文字
- 見出し・掛け声・点数: **Stick**（細い帯を切って貼ったような角ばった字。切り抜き文字は1字ずつ ±5〜7° 傾け、茶黒の影を3〜4pxずらして落とす）。点数は `font-variant-numeric: tabular-nums`。
- 説明・小さな札: **Zen Kurenaido**（掲示板の手書きの案内文の字）。
- フォールバック: `Stick, "Zen Kurenaido", sans-serif` ／ `"Zen Kurenaido", sans-serif`。読めなくても遊べる。
- 掛け声の吹き出しの中で、いまの打の語の下に橙の短い帯を1本だけ貼る（文字は塗り分けない）。

## 6. 質感と「人の手の跡」
1. **紙の重なりの影**: どの紙片も、同じ形を茶黒で 3〜4px ずらして先に置く（不透明度 0.3 前後）。等倍で見える幅。ぼかさない。
2. **ちぎった辺**: 4px ごとに刻んで ±1.5px 揺らし（ときどき大きく）、色紙の辺には白い芯を約1.5px 出す。はさみの物（臼・杵・餅）とちぎる物（湯気・粉・布巾・吹き出し）を混ぜない。
3. **紙の目と木の筋**: 短い繊維（3〜10px、白と茶黒の混ざり）は**塀・服・のし台だけ**。シートと餅には入れない（全面に同じ密度の粒を敷かない）。欅の筋は縦に長く、間隔をそろえない。
4. **マジックの描き足し**: 顔・縄の撚り・塀の目地・ケースの筋だけ。線幅 1.2〜2.6px、座標に ±0.7px の揺れ、目地は所々で途切れる（規則的な格子や縞にしない）。

## 7. 動き
- 操作への返事
  - 杵（右）: 振り下ろし 80ms → 当たった瞬間に餅が縦に 6% つぶれて 120ms で戻る。ぴったりなら「ぺったん」の切り抜き文字が杵の右上に1字ずつ跳ねて出て（各字 40ms ずらし）、餅の切れ端が**片側に3つ**だけ飛ぶ（全周の放射にしない＝太陽に見せない）。米粒が数粒消える。
  - 返し（左）: 軍手が臼の上へすべり込み、餅の端を折り返して（白い紙片が半回転）すぐ引く。
  - 水: 軍手がボウルに入り、ボウルの水面の白い切れ端が1回ずれる。
  - コンボ8: 見物人の吹き出し「よいしょー！」が2〜3枚重なって出る。太鼓の人の撥が大きく振れる。
  - ひと臼つき上がり: 餅が 1.08 倍にぷるんとはね、のし台へ落ちて取り粉が少し舞う（ちぎった白い紙片3〜4枚）。
- 何もしていないときの飾りの動き: **湯気だけ**（ちぎった薄紙2枚がゆっくり上下し、時々入れ替わる）。
- **手が臼にある拍に杵を下ろしたとき（痛そうにしない）**: 
  1. 危ない拍は、臼の上の軍手を橙＋茶黒の縁で囲む（赤くしない）。
  2. それでも杵を下ろすと、**杵が軍手の上の空中でぴたっと止まる**（止まった杵の左右に短い横線2本、橙の切り抜き文字「ぴたっ」）。餅がぷにっとはねる。杵は軍手に触れない。
  3. 見物人の吹き出し「あぶない！」、上の軍手の札が1枚裏返って点線になる。掛け声の吹き出しの文字が1拍だけばらばらに傾く（掛け声が乱れる）。
  - 流血・ケガ・赤い手・涙・「いてっ」は描かない。plan の「いてっ！」は「ぴたっ」に、効果音の「ごつっ」は**杵が止まる短い木のきしみ＋見物人の息をのむ音**に替える。
- 実装の前提（④）: 紙片はロード時に1回だけ offscreen canvas に「影 → 白い芯 → 塗り → 紙の目」の順で描いて、毎フレームは `drawImage` と `translate/scale/rotate` だけで描く。**`ctx.filter` と `shadowBlur` は使わない**（影はずらした紙片、ぼかしは無し）。餅のつぶれは scale、米粒は位置を固定した小さな楕円の配列から数を減らすだけ、つやの切れ端は不透明度を上げるだけ。紙の目は pattern を1回作って使い回す。

## 8. 使わないもの（この作品で避ける定番）
- game-art-direction §2 のうち陥りやすいもの: 和風の「紙の地＋墨＋朱」（001〜005 と同じ）、夜の画面と光る粒、角丸カードの UI、定型のあおり文句
- 過去の事前審査の指摘を最初から避ける:
  - 背景1色が大半 → 塀・地面・シート（折り目の明暗）・のし台で面を割る
  - アイコンが汎用的 → 命は軍手、拍は縄の結び目と橙の札、一時停止も札
  - 小さい文字・判のコントラスト不足 → 小さい文字は白い札の上だけ、「上」は茶黒×橙 5.0
  - 同心円の弧が Wi-Fi → 音の波・年輪・波紋を描かない。打った音は切り抜き文字
  - 規則的な縞 → シートの織り目・ブロックの全目地・縄の等間隔の撚りを描かない
  - 同じ形のスタンプ → 見物人・米粒・切れ端は1つずつ形を変える
  - 全周の炎が太陽 → 打った瞬間の切れ端は片側3つだけ
  - 均一塗りで素材っぽい → 紙の影・白い芯・塀や服の紙の目・折り目の明暗
  - 輪郭や版ずれが等倍で見えない → 影 3〜4px、芯 1.5px、マジック 1.2〜2.6px（すべて 390px 幅の等倍で見える幅）
  - 光が黄色い塊 → つやは白い紙の切れ端。黄色・橙の光やグローは使わない
  - 波線が記号 → 湯気はちぎった薄紙、「〜」の線を使わない
  - 全面に同じ密度のノイズ粒 → 紙の目は塀・服・のし台だけ
  - 白が灰色に濁る → 餅の陰は青みの白 #dfe8f2、灰色を乗算しない
  - 物が別の物に見える → 臼を低く・くびれさせ・縁を厚く（切り株・丸太に見せない）、太鼓は横向きの胴で臼の楕円と見分ける
- 似てしまいそうな既存作品と違い方: 001〜007 の和風はどれも「古い紙・刷り物・墨と朱」の地。本作は**いまの町内会のビニールとプラスチックの道具**（ブルーシート・ビールケース・軍手）を子どもの貼り絵で描くので、和風の画面に寄らない。008 の「切り紙のような平版刷り」とは、紙片の重なりの影・ちぎった辺の白い芯がある点（刷り物ではなく貼り物）で違う。

## 10. 事前審査
- 審査者（作った本人以外）: ミニゲーム工場の美術監査（2026-10-09。scene.png・sheet.png を Read で確認）
- 予想スコアと理由（作者の自己見積もり）: 7.5〜8/10。題材の道具（ブルーシート・ビールケース・軍手）がほかのゲームと入れ替えられない見た目で、紙片の影とちぎり辺の芯は等倍で見える。一方で、のし台の欅の面が広く平らに見えること、見物人の顔がまだ単純な図形であることは減点の候補。
- 合格ラインに届かない理由と直したこと（作者の自己点検の途中経過）:
  - 1枚目の臼が「切り株」に見えた → 高さを下げ、腰のくびれと厚い縁を付け、側面の帯をちぎり辺から曲線の2枚に替えた
  - 返しの軍手が臼の縁に重なり「手が臼の上（危ない状態）」に見えた → 代表場面では臼の外の左下へ引いた位置に移した
  - 湯気がおじいさんのたばこの煙に見えた → 小さくして蒸籠の真上に寄せた
  - 飾りを1つ取った: のし台の取り粉に描いた指の跡（線が糸くずに見えた）

### 美術監査の判定（2026-10-09）
- **予想スコア: 7/10（合格ライン 8 に届かない）**
- 良い点（崩さない）: 借りてくる物（ブルーシート・ビールケース・軍手・手水ボウル・蒸籠・ブロック塀）が餅つき以外に入れ替えられない。正月の定番（紅白・金・松竹梅・朱の落款・法被）は scene・sheet のどこにも無い。命の札＝軍手と点線、拍＝縄の結び目と橙の札、「上」＝橙の紙の丸札は汎用アイコンを避けられている。失敗を「杵がぴたっと止まる」にした方針は安全で正しい。design-log 001〜008 とは組み合わせが被らない（地が紙色でない、赤・朱・金なし、フォントは未使用）。
- 届かない理由（見本で実際に見えたこと。上ほど重い）:
