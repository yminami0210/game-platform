## 3. 形の言葉（シェイプランゲージ）
- **ガラス＝柔らかい回転体**。左右はほぼ対称だが、輪郭は ±0.6px 揺らし、底は少し丸く垂れる。**竿は右上から斜め（約11°）に下りてくる**（真上から垂直に吊ると電灯のコードに見えたので変えた）。ガラスの軸は竿と同じ向き。
- **熱いガラスの中の明るさ＝いちばん厚い所の不揃いな斑**（大きさも位置も違う横長の2〜3枚。各斑を大きさ3段で重ねて縁ほど薄い。大きな淡い楕円の面を作らない）。ガラスの輪郭の外へは1pxも出さない。電球のフィラメントのような中央の縦長の芯にしない。
- **竿に近い首は暗い**（鉄に熱を取られる）。上から下へ薄れる。
- **窓の映り込み＝十字の桟のある弓なりの四角を1つ**（白墨色 50%、紙の目で抜く）。いちばん太い所の少し上・窓のある左側。2本の平行線・白い楕円にしない。**高さ 120px 未満の小さいガラス（棚の器・見本帳）には描かない**。
- **注文の輪郭とガラスのずれ**: 合っていない区間は、白墨の線を**注文の位置にそのまま**引く（ガラスが太い所は線がガラスの上＝内側を通り、細い所は線とガラスの間に紙が見える）。合った区間（ずれ 3px 以内）は山吹にかすれ、**ガラスの縁から 4px 外**に残す（縁取りに見せない）。
- **作業中の高さ**: その高さのガラスの両脇に、白墨の「く」の字の刻みを左右1本ずつ（ゲージにしない）。
- **器に見せる合図**: 竿の付け根の首にジャックの押し跡の細い溝1本。ふた瘤は下の瘤を明確に大きく（瓢箪に寄せない）。
- **炉＝角の丸い煉瓦の塊にアーチの開口**。開口は鉄の扉を下ろしていて、**下のすき間（高さ約26px）だけが熱い平らな面**。上の辺は扉で真っすぐに切れる。丸い口・全周の炎・光の輪にしない。温め直しのときだけ扉が上がる（sheet）。
- **木の物・鉄の物＝木炭の2本線＋方向のあるストローク**。煉瓦の目地は段ごとに高さ（13〜27px）と継ぎ目の位置を変え、所々かすれさせる（格子模様にしない）。
- **砂袋（命）＝横に寝かせた角の丸い麻袋**。上辺は重みでたわみ、右端だけ紐で縛り、左端は折り込み。下半分が暗く、床に擦筆の影。輪郭は床に接する下側だけ。崩れた袋は平たく裂け目があり、砂の小山がこぼれる。（丸い袋は玉ねぎ、両端の耳は飴の包み紙に見えたのでやめた）
- **ガラスの状態（sheet）**: 熱い／冷めかけ（暗赤）／筋が出始め（暗赤に髪の毛ほどの白い擦れが少し＝もう危ない）／冷えた（鈍い灰に擦れが多い）／割れた（木炭の太い折れ線＋片側に白墨・欠けたかけら）／薄すぎ（淡い朱橙を擦筆で薄く、壁の紙が透け、縁だけ細く明るい）／気泡（ゆがんだ白墨の弧2本・閉じない＋周りだけ色が薄い）／仕上がり（透けた青緑）。
- **時間＝向こう岸の鐘楼の時計**。過ぎた時間を暗赤で塗る。点数＝積んだ銀貨と数字。一時停止・音＝石盤の下の白墨の字「とめる」「音」。‖・歯車・ハートの汎用アイコンは使わない。
- シルエットの約束: 黒塗りでも 竿＋ガラス（斜めの棒の先の瘤）・炉（アーチの開口のある塊）・桶・砂袋（耳の2つある枕）・器（瓶とコップ）が見分けられる。

## 5. 文字
- 見出し（題・注文の名前・銀貨の数）: **Zen Antique**。古い看板の筆書きを活字にしたような、少し不揃いな太さが石盤の白墨の字・工房の札に合う。数字は `font-variant-numeric: tabular-nums`。
- 本文（操作説明・結果の内訳・石盤の「とめる」「音」）: **BIZ UDPGothic**。手の動きの説明を、小さい画面でも読み違えずに読めるように。紙片か石盤の上だけに置く。
- どちらも design-log 直近10本で未使用。読み込みは Google Fonts の `<link>` だけ。フォールバックは `"Zen Antique", "Hiragino Mincho ProN", serif`／`"BIZ UDPGothic", "Hiragino Sans", sans-serif`。
- 全大文字の英字の飾り題は置かない。

## 6. 質感と「人の手の跡」
1. **パステルのストローク（物ごとに組を変える。`pastel.js` の `ST`）**: 白壁＝長く寝かせた幅広の擦り（26〜60px・太さ 5〜10・粒少なめ）／煉瓦＝短い横中心に縦が混ざる濃い塗り（6〜14px）＋明るい目地／板・棚＝長手方向に長い木目（30〜70px・細い）／鉄＝長さ方向／ガラス＝丸みに沿った弧（縁ほど強く曲がる）／麻袋・布＝短く向きのばらけた目／窓の空＝擦筆の面＋少数の幅広ストローク。どの面も筆圧のむら（`mottle`）で密度を場所ごとに変える。色は1本ずつ ±7% 揺らす。
0. **輪郭は前景だけ**: 木炭の輪郭はガラス・竿・炉の開口・道具・桶・銀貨だけ。壁・窓枠・棚・板・床・家並み・炉の外形には引かない（窓枠は木の色の太いパステルの線）。塗りは形を `loose()` で 1〜3px ずらし、はみ出す所・届かない所を作る。
2. **紙の目**: パステルを乗せた所は、紙の凹みで色が抜けて地の鳩羽色が点々と見える。抜ける強さは物ごとに変える（熱いガラス 0.16・石盤 0.12・壁 0.25）。素の紙の地にも、パステルが掠った跡をごく弱く・場所でまだらに置く（`paperGraze`。全面に同じ密度の粒にしない）。
3. **木炭の線**: 筆圧で太さが変わり、2度引きで 1px ほどずれ、ときどきかすれる。ガラスは窓に向いた側を細く、反対側と底を太く。
4. **白墨の線**: 実線を引いてから紙の目で強く抜く（粉っぽくかすれる）。**`setLineDash` の点線にしない**。合った所は山吹にかすれて細くなり、線から少し離れた所に短い粉の欠片が数個だけ残る。
5. **指でこすった面（擦筆）**: 石灰の白壁、石盤の前の注文を消した跡、炉の肩の煤、すき間の下の照り返し。境目が柔らかく粒が少ない。
- 等倍（390px 幅）で見える強さ: 木炭は 1.1〜2.6px、白墨は 2.2〜3px、紙の目の抜けは 1.4〜4px の点。

## 7. 動き
- 操作への返事
  - 指を広げる: その高さの胴が「ふわっ」とふくらみ、内側の芯の斑が 0.2 秒だけ明るくなる（輪郭の外は光らせない）。
  - つまむ: その高さが細くなり、輪郭の木炭がその所だけ太くなる（よれ）。
  - 合った所: 白墨の線がその区間から山吹にかすれて消え、全部消えた瞬間に器が青緑の透けた色に変わる（「チン」）。
  - 冷え: 本体の色が朱橙→暗赤→鈍い灰へ。灰に近づくと表面に短く枝分かれする白い筋が増える（規則的な縞にしない）。
  - 炉: タップで鉄の扉が上がり、開口が熱い面になる。戻すと下りる。
  - 切り離し: 竿が下へ振れ、器が棚へ移る。割れたら砂袋が1つ崩れる。
- 何もしていないときの動き: **ガラスがゆっくり回ること**だけ（ストロークの層と窓の映り込みを横に少しずらす）。炉のすき間は揺らさない・点滅させない。窓の外も動かさない。

## 8. 使わないもの（この作品で避ける定番）
- game-art-direction §2 のうち陥りやすいもの: 暗い背景に光る点（火の粉）、黒背景＋1色のアクセント（夜の工房＋オレンジ）、グラデーションの飾り、角丸カード（UI は石盤・紙片・銀貨）、あおり文句
- 過去の事前審査の指摘を最初から避ける:
  - 背景1色が大半 → 白壁・窓・炉・棚・床・作業台で面を割る。紙がそのまま見えるのは一部だけ
  - アイコンが汎用的 → 命＝砂袋、時間＝鐘楼の時計、点数＝銀貨、とめる・音＝石盤の白墨の字
  - 小さい文字のコントラスト不足 → §4 のとおり、15px 未満は石盤（10.3:1）か紙片（11.9:1）の上だけ
  - 同心円の弧が Wi-Fi → 炉の口を丸くしない・光の輪を描かない。時計は扇形の塗り1つ
  - 規則的な縞 → 煉瓦の目地は段の高さ・継ぎ目をそろえず所々かすれさせる。運河の水は横のストロークをまばらに（波線を描かない）。冷えの筋は短く枝分かれ
  - 同じ形のスタンプ → 煉瓦は1個ずつ描かず目地の線で。砂袋は形・大きさを1つずつ変える。器は形の違う3つ
  - 均一塗りで素材っぽい → 面はすべてストロークで塗り、紙の目で抜く
  - 輪郭や版ずれが等倍で見えない → §6 の太さ。木炭の2度引きは 1px ずらし
  - 光が黄色い塊 → 熱は「ガラスの内側の厚い所の斑」と「扉の下の細いすき間」だけ。芯の淡橙は単独で面にしない。窓の光も白っぽい灰で黄色くしない。太陽を描かない
  - 波線が記号 → 水・湯気・熱を「〜」で描かない
  - 全面に同じ密度のノイズ粒 → 紙の目はパステルを乗せた所だけ、濃さはまだら
  - 白が灰色に濁る → 白墨 #f6f3ea を乗算しない。小さい字の紙片は #ebe6dc
  - 物が別の物に見える → **吊り下げ電灯**（垂直の竿＋しずく形＋中央の芯）を避けて竿を斜めにし、芯を不揃いな斑に、首を暗くした。**炉の口が顔**（すき間の中の坩堝の弧が口、取っ手が鼻に見えた）→ 坩堝の弧を外し、掛け金を扉の横へ。**丸い砂袋が玉ねぎ**→ 枕形。**壁に落ちる窓の光が2つ目の窓**に見えた → 外した
  - ストック顔 → 人を描かない（職人の手も描かない）
  - setLineDash の点線 → 白墨・縫い目・目地はすべて1本ずつ／紙の目で抜く
