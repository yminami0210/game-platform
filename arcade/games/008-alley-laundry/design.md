# デザインコンセプト: せんたく日和（008 alley-laundry）

- 合格ライン: ミニゲーム 8/10（「AIが作った感」スコア）
- 状態: **審査中（再審査待ち）**。1回目の事前審査は REVISE 6.5/10。指摘1〜9と実装条件を反映した版（§10 末尾「修正内容」）

## 1. どの Core・Why に答える見た目か（product-layers）
- Why「仕事を思い出さない、家の手仕事ののんびり」「5秒で始められ、1回で気持ちいい瞬間」→ 開いた瞬間に「路地の2本の物干し綱と、濡れた洗濯物」だと分かる絵にする。説明より先に、綱・洗濯物・たらい・かごが1画面に並ぶ。
- 「乾きゲージを出さない」（plan）→ 濡れ具合は**布にかかる群青の薄刷りと、裾にたまる少し濃い帯の高さ**、日なたかどうかは**影の版が乗っているか**、だけで見せる。数字やメーターで時間を急かさない（時間は太陽の位置だけ）。

## 2. 借りてくる物（実在の物・場所・技法）
- 主に借りる物（2つで1組）
  1. **港町の雑貨屋で売っていた固形の洗濯石鹸の包み紙**（1950〜60年代ごろの、特色4〜5版の平版刷り）。色数を絞ったベタ、石版にクレヨンで描いた粒の濃淡、版ずれ、版と版のすき間に残る紙の白、二重の枠線。商品名やマークは借りない（架空・無地）。
  2. **その町の裏路地の物干しの道具**: 窓の脇の鉄の腕金と滑車、横桟2本の板戸の鎧戸、塗り直しの継ぎはぎがある黄土の漆喰（剥げて煉瓦がのぞく所）、木のばね式洗濯ばさみ、亜鉛のたらい、籐のかご、窓台の素焼きの鉢のトマト。
- **plan.md からの変更**: plan の「地中海の観光ポスター風リトグラフ」は、刷り方（リトグラフ）だけを残し、借りる元を「観光ポスター」から「洗濯石鹸の包み紙」に替えた。観光ポスターは「白壁・青い扉・ブーゲンビリア・海の見晴らし・光線つきの太陽」の定番に寄るため。洗濯の遊びなので、洗濯の道具と石鹸の紙から借りる方が題材とつながる。
- 南の港町の定番から外すために決めたこと（**描かない物**）
  - 白壁の四角い家・青い扉や青いドーム・ブーゲンビリアの紫紅・レモン・海の見晴らし・港の船・錨や浮き輪・かもめの「V」の記号・パステルの家並み（ピンク・水色・黄色の並んだ家）
  - 壁は**白ではなく黄土**（塗り直しの継ぎはぎ・剥げ付き）、扉や窓は**青ではなく鎧戸の緑**、花の代わりに**窓台のトマトの鉢**。海は見せず、港町らしさは音（遠いかもめ・アコーディオンの2音）にだけ任せる
  - 「黄土の壁＋緑の鎧戸＋路地の洗濯物＋窓台の鉢」は題材上避けられない絵はがきの組み合わせなので、**色で外す**: 家ごとに色を変えない（手前は左右とも同じ黄土、奥は黄土の薄刷りと紙の白の2つだけ）、薄紅・水色などのパステルは使わない
  - **画面全体を1枚の包み紙の刷り物にする**: 四辺に紙の白の余白（約10px）とトマトの細い二重枠を刷り、空・壁の版は枠の内側で少し不揃いに止まる。開始画面・結果画面（たたんだ山）は、この枠の中に題字を入れた包み紙の体裁
  - 太陽は光線・光の輪を描かず、**空の版を丸く抜いた紙の白**（黄土の版が片側に細くずれて出る）
- そこから借りるもの
  - 色: 漆喰の黄土・昼の空の群青・鎧戸の緑・トマトの赤・洗濯の青み付けの白・影のすみれ茶（包み紙の特色の数に合わせて6版）
  - 形: 切り絵のような直線の辺の布（角ごとに少しずれる）、L字の腕金と滑車、横桟の板戸
  - 質感: 石版のクレヨンの粒（濃淡は粒の密度で。グラデーションを使わない）、紙の繊維
  - 線: すみれ茶の輪郭（筆圧の切れ目つき）、綱は撚りの明るい短い筋が不揃いに入る1本線
  - 文字: 包み紙の二重枠の札（トマトの版で枠、すみれ茶で文字）
  - 音: plan.md「見た目と音」のとおり
- 参考にする人の手の作品の種類: 戦後の日用品（石鹸・マッチ・缶詰）の平版刷りのラベル、石版画のクレヨン描き、切り紙の挿絵

## 3. 形の言葉（シェイプランゲージ）
- **洗濯物＝切り絵の多角形**。辺は直線、角は少しずつずれ、裾だけ不揃いに波打つ（シーツ・タオル）。種類はシルエットで分かる: 靴下（L字）・シャツ（袖が下がる・襟のV）・タオル（縦長＋縞）・ジーンズ（2本脚）・シーツ（1枚の大きな布。綱に掛けた上端の細い二重の折り返し、重みで裾の中央が下がる不揃いな下端、濡れて貼りつく縦の短いしわ 2〜3本。2枚重ねの段差線は描かない）
- **重さはたわみの形で見せる**: 綱は「綱の重み（放物線）＋掛けた物ごとの折れ線」。重い物の所で角ばって下がる（`print.js` の `ropeY`。実装も同じ式）。重すぎると**腕金が下を向き、漆喰が欠ける**（効果線・波線・「!」は描かない）
- **危ない物（鳩）＝ずんぐりした丸＋小さい頭＋短い扇の尾**。羽の2本の黒い帯と首の緑の光沢で「カワラバト」と分かる形。姿勢（首の縮め方・向き・大きさ）を1羽ごとに変える
- **建物＝見上げて上ほど内へ傾く縦長の面**。手前の家は左右の細い帯、奥は版を減らした薄い家。奥の窓は3つだけで1つずつ違う物（半開きの緑の鎧戸／窓台と鉢／外に垂れた白いカーテン）、それぞれにまぐさと窓台がある。窓の中は真っ黒にせず影版の平網＋上側だけ濃い擦れ。石段は黄土の2度刷り＋輪郭の不揃いな3段、戸口は緑の板戸を少し開けた形
- **UI＝石鹸の包み紙の札を洗濯ばさみで留めたもの**。角丸カードは使わない。一時停止は「ひと休み」と書いた札（汎用の ‖ アイコンや歯車を置かない）
- シルエットの約束: 黒塗りでも 靴下・シャツ・タオル・ジーンズ・シーツ・鳩・洗濯ばさみ が見分けられる

## 6. 質感と「人の手の跡」
1. **版ずれ（強・等倍で見える量）**: 色版を輪郭から 1.5〜2.2px ずらす。赤い靴下は輪郭の外に赤がはみ出し、反対側に紙の白が細く残る。3倍拡大を sheet に載せた
2. **石版のクレヨンの擦れ（中）**: 丸い点ではなく、**同じ向き（右上がり約24°）に寝た 2.5〜6px の短い筋**が少し固まる。**暗い擦れ（すみれ茶）は3か所だけ**: 影の縁の内側 20〜40px の帯・空の屋根ぎわ・たらい。日なたの漆喰は**明るい擦れ（紙の白が抜ける）**と黄土の2度刷りの擦れで出し、洗濯物には暗い擦れを乗せない。**1回だけ offscreen canvas に描いて pattern で使い回す**
3. **引き直しのある輪郭（中）**: すみれ茶 1.6〜2px。切れ目は**1本に1〜2か所だけ**（短い線は1か所、長い線は2か所）、位置は不揃い。等間隔の破線の繰り返しにしない。長い線（建物の縁・路地の底）は細い2本目を少しずらして一部だけ重ねる（引き直した跡）。揺れは1個ごとに固定し、フレームごとに変えない
4. **切り絵の不揃い（中）**: 布の角は1つずつずれる、洗濯ばさみは1本ずつ角度と長さが違う、漆喰の継ぎはぎは形と大きさがばらばら
5. **包み紙の縁（中）**: 画面の四辺の紙の白の余白とトマトの二重枠（版ずれ 1px）。版の端は枠の内側で少し不揃いに止まる
6. **紙の目（弱）**: 最後に全体へ紙の繊維を multiply で1回
- 濡れの見せ方: 全体に群青の薄刷り＋**裾にたまる少し濃い群青の帯**（境目はゆるい起伏のしみの縁。山並みに見えるギザギザにしない）。乾くほど帯が下がって消え、乾いた物は明るい擦れで紙の白が出る。影は「屋根の形の段のある面（茶紫）」、濡れは「下ほど青い」で見分ける。しずくは濡れた物のいちばん低い所から落ちる

## 7. 動き
- 操作への返事
  - つまむ: 布が 6〜9° 傾いて持ち上がり、**平らな影版**（ぼかし無し）が 12px ずれて下に落ちる
  - 留める: 洗濯ばさみが 2px 沈んで戻り、綱が置いた所で折れ線にたわむ（0.25 秒でゆっくり）
  - 取り込む: 綱が「びよん」とはね上がって 2〜3 回減衰して揺れ、残りの洗濯物が綱の傾きに合わせて小さく振れる
  - 重すぎ: 腕金が少しずつ下を向き、漆喰の欠けが1つ出る（震えや波線は出さない）。切れると両端が垂れ、布が路地に落ちる
  - 色移り: しずくが当たるたびに白い布に桃色のしみが少し広がる
- 何もしていないときの飾りの動き: **乾いた物が風で揺れる1種類だけ**（乾いた合図を兼ねる）。雲・光・鳥の飾りの動きは足さない（鳩は遊びの中身なので飾りではない）

## 8. 使わないもの（この作品で避ける定番）
- §2 の定番: 夜空に光る粒・ネオン・クリーム×テラコッタ・角丸カード＋影・全大文字・「→」・あおり文句
- 南の港町の観光ポスターの定番: §2 に書いた「描かない物」すべて
- 過去の事前審査で指摘された点を最初から避ける
  - 背景1色が画面の大半 → 面を5つに割り、最大のかたまり 19%（紙の白。余白・奥の家・白い布に分かれる。§4）
  - アイコンが汎用的 → 一時停止は「ひと休み」の札、音は M キーと同じ札。歯車・スピーカー・‖ を置かない
  - 小さい文字・判のコントラスト不足 → §4 の実測値。赤で文字を書かない。12.5px 未満を使わない
  - 同心円の弧が Wi-Fi に見える → 滑車は小さな歪んだ丸1つ。風・音・きしみを弧で描かない
  - 規則的な縞 → タオルの縞は幅も間隔もばらばらで少し波打つ。鎧戸はルーバーをやめ、幅の違う3枚板＋横桟2本。籐かごは編み目を描かず、高さ不揃いの帯2本だけ。石段は段の高さも長さも揃えない。輪郭の切れ目も等間隔にしない
  - 同じ顔や形のスタンプ繰り返し → 洗濯物・洗濯ばさみ・鳩・窓・継ぎはぎは1つずつ形が違う（seed で毎回変える）。同じ種類の洗濯物でも傾き・濡れの帯・しわを変える
  - 全周の炎が太陽に見える → 太陽は版を抜いた紙の白だけ。光線・光の輪・グロー無し
  - 均一塗りで素材っぽい → 面の質感は明るい擦れ（紙の白抜き）と2度刷りの擦れ。ただし「フラット図形＋全面ノイズ」にならないよう、暗い擦れは影の縁・屋根ぎわ・たらいだけ
  - 輪郭や版ずれが等倍で見えない → 輪郭 1.6〜2px・不透明度 0.92、版ずれ 1.5〜2.2px（等倍の切り出しで確認）
  - 光が黄色い塊・光の柱に見える → 日なたは「影版が乗っていない所」。影の境目は屋根の輪郭（軒の出・腕金・鉢）をなぞった段のある形で、奥の壁の付け根で角度を折る。画面の端まで一直線の2本にしない
  - 波線が記号に見える → 風・湯気・におい・きしみの波線を描かない。しわは曲がった短い線を1〜3本、向きと長さ不揃い
- 似てしまいそうな既存作品との違い: 物干しのゲームの多くは「青空に白い雲、白いシーツ、緑の芝生」の明るいベクター。本作は**見上げた路地**で、色は版で刷った6色だけ、日なたと影の境目がそのまま遊びの情報になる

### 実装で守ること（毎フレーム `ctx.filter` を使わない描き方）
