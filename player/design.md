# デザインコンセプト: あそびば（ミニゲームの遊び場 player）

- 合格ライン: ミニゲーム・遊び場 8/10（「AIが作った感」スコア）
- 状態: **再審査待ち**（1回目の事前審査 REVISE 6.5/10 → 指摘5点を反映して見本を撮り直した）

## 1. どの Core・Why に答える見た目か（product-layers）
- Core「忙しい毎日から離れて、時間を忘れて没頭できる遊び」→ 開いた瞬間に「今日は何がかかっているか」が一目で分かり、押せばその場で幕が開く
- Why「毎回ページを移るのが面倒／終わったら次が分からない／毎日増える楽しみ」→ 舞台にいちばん新しい1本、横に「これまでの演目」の束。遊び終えたら扉の外の束から次を選ぶ
- 将来（M2〜M3）「街で住人に話しかけるとゲームが始まる」→ 紙芝居屋はもともと**街角に自転車で来て、子どもを集めて幕を開ける住人**。M1 の一覧はその舞台の正面、M2 では同じ舞台が街の一角に置かれ、紙芝居屋（と他の住人）に話しかけると同じ扉が開く

## 2. 借りてくる物（実在の物・場所・技法）
- 主に借りる物: **昭和20〜30年代の街頭紙芝居**。自転車の荷台に載せる木の舞台（観音開きの扉と上の梁）と、泥絵具で描いて上からニスを引いたボール紙の絵札。舞台の後ろは空き地の板塀
- そこから借りるもの:
  - 色: 栗皮色に焼けた舞台の木、雨ざらしの板塀の灰茶、ボール紙の生成り、泥絵具の群青と朱、絵の輪郭の墨
  - 形: 舞台の「窓」に絵札がぴったり収まる比率、観音開きの扉、絵札の厚み（紙の層が見える縁）、絵の上に重ねて描く題字の札
  - 質感: ボール紙のざらつき、木目、塗りと墨線のはみ出し
  - 文字: 筆で塗った太い看板文字（題字）と、演じ手の台本のような柔らかな手書き風の本文
  - 動き: 紙芝居の「抜き」（絵札を横へ引き抜いて次の場面を見せる）と、扉を開けて始める所作
- 参考にする人の手の作品: 街頭紙芝居の手描き絵札（泥絵具・ニス仕上げ）、昭和の木工の屋台・舞台、空き地の板塀

## 3. 形の言葉（シェイプランゲージ）
- 基本の形は**横長の四角（絵札）と、それを囲む厚い木の枠（舞台）**。丸は使わない
- 絵札: 角は少しだけ欠けた多角形（clip-path で四隅の欠け方を札ごとにずらす）。影はぼかさず、ボール紙の「厚み」として下に3pxのべた
- 舞台: 厚い梁（スマホ 58px 以上）に、釘で打ち付けた板の看板「あそびば」。左右に観音扉と蝶番。**スマホでも扉を残す**: 一覧では窓に半分かかった畳みかけ、押すと開く。遊ぶ画面では畳んだ扉の縁（18px・蝶番つき）が窓の左右に残る。PC は開いた扉が箱の外に立つ
- 題字の札: 絵の左下に少し傾けて重ねる。ボール紙＋墨の太い縁＋墨のべたのずらし影（舞台の新作も束の札も同じ作り）
- 束の札: スマホ2列・PC3列。**絵札の面だけ**（ゲームの絵＋小さな題字の札＋隅に手書き風の点数）。説明は出さない。傾きは ±1.5°、欠けは 4〜8px で目に見える大きさ。角丸・ぼかし影は使わず、下に2枚の紙の層（ずらしたボール紙のべた）で厚み
- 台本: 新作の説明は窓の下の「札の裏の台本」（罫の入ったボール紙）に地の文で2〜3文。ラベル行は作らない。未プレイは墨の判子「はじめて」、遊んだ後は判子の位置に点数
- ボタン: 「遊ぶ」は朱に墨の縁、べたのずらし影、角の欠けた板。押すと影ごと沈む
- 戻る: 梁に紐で掛けた、角の欠けた木札（栗皮の明るい色＋木目＋墨の縁）。角丸ピルにしない
- シルエットの約束: 舞台（梁＋窓＋扉）の輪郭だけで「紙芝居」と分かること。将来の街の画面でも同じ輪郭で置く

## 5. 文字
- 見出し・題字・点数: **Potta One**（筆で塗ったような太い看板文字。紙芝居の題字・駄菓子の看板と同じ匂い）
- 看板「あそびば」: 梁に打ち付けた板に白ペンキで書いた文字。字間を詰め（-0.04em）、1字ずつ大きさ（0.9〜1.08倍）・基線・傾きを揺らす。色付きのずらし影は使わない
- 本文・説明・操作: **Kiwi Maru**（少し古風で柔らかい丸文字。演じ手の台本の手書きに近い）
- フォールバック: "Hiragino Maru Gothic ProN", "Yu Gothic", sans-serif。点数は `font-variant-numeric: tabular-nums`
- これまでのミニゲーム（design-log 001〜005）と既存の伝言板ページ（Klee One／Zen Kaku Gothic New）のどれとも重ならない

## 6. 質感と「人の手の跡」
1. **墨のべたのずらし影**: 題字の札・「遊ぶ」・戻るの木札は、ぼかさない墨の影（強さ: はっきり）
2. **札ごとに違う傾きと欠け、紙の層**: 束の札は ±1.5° の範囲で1枚ずつ違う傾き、四隅の欠けは 4〜8px、下に2枚の紙の層（強さ: 目で分かる）
2'. **看板文字の揺れ**: 「あそびば」の1字ずつの大きさ・基線・傾き
3. **紙と木の質感**: ボール紙にざらつき（SVG のノイズを1枚、背景画像として使い回す）、舞台に横に流れる木目（強さ: 控えめ）
4. 板塀の縦板は幅をそろえない

## 7. 動き
- 操作への返事（これが「印象に残す1点」）: **札を押すと、窓に半分かかっていた扉が観音開きに開き、絵札が横へ「抜かれて」その奥でゲームが始まる**（扉 0.35秒、抜き 0.25秒を0.3秒遅れで、合わせて0.6秒以内。`prefers-reduced-motion` では即切り替え）。スマホでも同じ（途中のコマ: `player/design/open-390.png`）。束の札を押したときは、その札がまず舞台の窓へ入ってから同じ動き
- 遊んでいる間: 抜いた札は窓の脇に見えたまま（スマホは梁の上端から下の端がのぞく、PC は右の扉の前に立てかけ）
- 戻るとき: 戻るの木札を押すと、抜いた札が窓へ戻り扉が畳みかけまで閉じる（ベストが更新されていれば判子の位置の点数だけ一度弾む）
- 「遊ぶ」と戻るの木札は押すと影ごと沈む
- 何もしていないときの飾りの動き: **なし**（舞台は静かに待つ）

## 8. 使わないもの（この作品で避ける定番）
- §2 で特に陥りやすいもの:
  - 「全部同じ角丸カード＋薄い灰色の影」→ 束は「リスト行」にせず絵札の面だけ。角丸なし、欠けと傾きは目で分かる強さ、厚みは紙の層のべた
  - 「ラベル＋値」の仕様表（ジャンル／操作）→ やめて、札の裏の台本の地の文に入れる
  - クリーム色の背景＋テラコッタ → 地は灰茶の板塀、紙は札にだけ使う。朱は鮮やかな朱（#d2402a）で「遊ぶ」と貼り紙1枚だけ
  - レトロ見出しの定番（字間を空けたかな＋色付きずらし影）→ 打ち付けた板の白ペンキ文字、字間を詰めて1字ずつ揺らす
  - 全大文字の見出し・「A · B · C」・末尾の「→」・等幅の小ラベル → 使わない。戻るは先頭に「‹」の印だけ
  - 「さあ、〜の世界へ」の類 → 梁の一言は「毎朝ひとつ、新しい演目がかかります。」（事実だけ）
- 似てしまいそうな既存のもの: 既存の `arcade/index.html`（駅の伝言板・黒板・駅名標）→ 駅・黒板・チョーク・路線色を一切使わない。木の舞台と紙の札で、手触りを「黒板の緑」から「木と紙と泥絵具」に変える
- 和柄（市松・麻の葉・波）の背景や、提灯・暖簾の「縁日」記号は使わない（和風の定番に寄るため）

### 実装への申し送り（デザインに関わるもの）
- 台本の文は catalog の `pitch` をそのまま地の文で使うのが基本（ラベル行は作らない）。操作は `controls` の最初の「（」か「。」の前までを、文として足してよい（見本の文は手で整えたもの）
- ベストスコアは各ゲームの localStorage のキー名がゲームごとに違う（`lk_best`・`wl-best` など）。player 側でキー名の対応表を持つ（catalog はバッチの持ち物なので触らない）
- 絵は `qa/play.png` を object-fit: cover。画面の真ん中に見せ場が無いゲームのため、表示位置の上書き（対応表に `thumb_pos`）を持てるようにしておく
- 戻る: 遊ぶ画面へ入るとき `history.pushState`、`popstate` で一覧へ（扉が閉じる動き）

## 10. 事前審査
- 審査者（作った本人以外）: **未実施**。実装前に別の審査者（監査役など）が見本と本書を §2 と照らして審査すること
- 自己審査の予想スコア: 7.5〜8/10
  - 良い所: 題字の札を重ねた絵札が舞台の窓に収まる姿と、PC で開いた扉が「紙芝居」とすぐ分かる。色・書体が既存の伝言板ページともミニゲーム5本とも重ならない
  - 届かない恐れ: (1) スマホでは扉が見えず「木の枠＋カード」に寄る。扉が開く動きでしか紙芝居らしさが出ない (2) 束の札は横並びの情報が同じ形で繰り返すので、構成としては一覧の定番に近い
- 自己批評で直したこと:
  1. 初版は絵札の「絵」を群青の四角＋大きな漢字1字にしていた → アプリのアイコン並べ（定番）に見え、紙芝居でもなかった。**各ゲームの実際の画面を絵にして、題字の札を重ねる**形に変えた
  2. 束の札の絵を鉛筆の下絵風（白黒・高コントラスト）にしたら、空が多いゲームで真っ白・郵便は真っ黒になり読めなかった → 色のまま、ニスの黄ばみ程度（sepia 0.18）に戻した
  3. 札の右上に貼った新作の印が、札の欠けで切れて点数とぶつかった → 絵の左上に移した
  4. 飾りを1つ取った: 一覧ページの下の「戻り方」の案内文（一覧には不要で、遊ぶ画面の戻るボタンと重複）。自転車の車輪を描く案も見送った

### 事前審査 1回目（美術監査・作った本人以外） 2026-10-05
- 見たもの: 本書 §1〜§9、`player/design/` の list-390 / list-390-dark / list-1280 / list-1280-dark / play-390 / play-1280 / play-1280-dark / swatches（すべて Read で確認）。基準は game-art-direction §0・§2・監査役の観点、frontend-design
- **判定: REVISE（このまま実装した場合の予想 6.5/10。PC 7/10、スマホ 6/10）**。合格ライン 8/10 に届かない
- 良い所（残す）: 題材の選び方（街頭紙芝居＝将来「街角に来る住人」へ自然につながる）、§2 の配色の定番を避けた板塀の灰茶＋栗皮＋ボール紙、Potta One／Kiwi Maru の役割分け、そして**ゲームの実画面に傾いた題字の札を重ねた新作の絵札**（これがいちばん人の手を感じる）。PC の開いた扉は輪郭だけで「舞台」と読める
- AIっぽく見える所（具体的に）:
  1. **スマホで紙芝居が消える**。list-390 は「茶色い角丸の箱の中に画像＋説明＋ボタンのカード」、play-390 は「戻るの丸ボタン＋題名のヘッダー＋細い茶枠＋iframe」で、どちらもアプリの定番構成。扉が無いので、§7 の「扉が観音開き」という印象に残す1点がスマホでは起こりようがない（主な利用者はスマホ）
  2. **束（これまでの演目）は「左にサムネ、右に題・点数・説明2行・ラベル行」のリスト行の繰り返し**。§3 の欠けた多角形・±0.5°の傾きは見本では知覚できず、むしろ角が丸くぼかした影が付いたカードに見える（§2「全部同じ角丸カード＋薄い影」に該当）。紙芝居の札束にも見えない
  3. **「ジャンル 回転／操作 〜」の群青ラベル＋値の行**は、どの題材でも出てくる仕様表の作り（frontend-design の「不要なラベル」）。「まだ遊んでいない」の灰色小文字も同様
  4. **朱が主役1か所になっていない**。新作の貼り紙が2枚（舞台と束の先頭）、「遊ぶ」、梁の「あそびば」と遊ぶ画面の題名の朱っぽいずらし影で、朱が4〜5か所に散る。字間を空けたかな＋色付きずらし影の「あそびば」は、レトロ風見出しの定番の効果に見える
  5. 遊ぶ画面（PC も）は窓の中がゲーム自身のクリーム色の紙と別書体で埋まり、舞台側が「額縁」以上の役をしていない。戻るの木札も角丸ピル＋ぼかし影で、木札に見えない
- 修正指示（デザイン担当がそのまま直せる5つ）:
  1. **スマホにも扉と梁を残す**: 390 幅でも舞台の左右に畳んだ扉（各 14〜18px、木目と蝶番の線）と厚い梁を描く。一覧を開いた時点では新作の窓に扉が半分かかっていて、押すと扉が開き絵札が横に抜かれる（§7 の動きをスマホで成立させる）。遊ぶ画面のスマホも、上の梁（太さ 44px 以上）と左右の畳んだ扉の縁を残し、窓は 6px 枠だけにしない。見本 list-390 / play-390 を撮り直して確認
