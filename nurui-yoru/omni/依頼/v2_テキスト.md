## 地理と市町村

四方を山に囲まれた盆地の県。県の真ん中をヨコネ川が東から西へ流れ、人の暮らしはその沿いに集まっている。北にある大岳（おおだけ、2,210m）から、冬には乾いた強い風「ヨコネおろし」が吹き下ろす。夏は蒸し暑く、冬は雪より風が厳しい。この風が、家の形や道具の多くに影響している（次の章）。

| 市町村 | 人口 | どんな町か |
| --- | --- | --- |
| 中ノ町市 | 約14万人 | 県庁所在地。駅前商店街、県庁、ナナシ放送、スーパーまるやす本店 |
| 下川原市（しもがわら） | 約7万人 | 川の下流。部品工場と団地の町。中ノ町とはなんとなく対抗意識がある |
| 深田市 | 約5万人 | 米とかぶら（大きなかぶ）の産地。田んぼの真ん中に県立大学 |

| 上ヨコネ村 | 約320人 | 大岳の麓の山村。県でいちばん言葉が濃い |

**交通**

- ヨコネ電鉄：下川原から上ヨコネまでの単線。2両編成で、30分に1本。県民は「ヨコデン」と呼ぶ
- 県営バス：ヨコデンが通らない深田・鳴沢方面をカバー
- 県道7号線：中ノ町と鳴沢を結ぶ幹線。いつもどこかを工事している
- 空港はない

**主な施設**

- 県立中ノ町商業高校：ハルが通う高校。野球は毎年そこそこ強い

- 県立歴史博物館：県名が決まらなかったときの会議記録が展示されている
- 県立美術館：毎年11月に県展を開く
- 中ノ町郵便局：駅前。三浦さんの職場

### 新しい風変わりを足すときの基準

1. 生活の中で現実的な使い道がある
2. 超常現象に頼らない
3. 県民にとっては退屈なほど普通
4. 既存の設定（ヨコネおろし、升、屋根酢など）のどれかとつながっている

## 県民の当たり前

県民にとって日本は48都道府県で、その前提で世の中が回っている。作中では強調せず、背景に混ぜて使う。

- 社会の授業で「48都道府県」と習う。県庁所在地の小テストは48問
- 家の壁に貼ってある日本地図にも、ナナシ県が載っている
- 夏の甲子園の代表校は49校だと思っている
- 「全国47都道府県制覇」と言う人を見ると、数え間違いだと思う
- 全国チェーンの店は普通にある。ただしメニューには必ずますめし風の限定品がある
- 県民性は「のんびり、言いたいことはかざみる」と自分たちで言っている
- 隣の県とは、試合や物産展でゆるくライバル関係にある（どの県かは曖昧にしておく）

書かないこと：県民が「うちの県って実は……」と自分たちの存在を疑う場面。


外の人が驚くポイントは、「暮らしの風変わりさ」の表から1〜2個に絞る。全部出すと観光案内になってしまう。

## トーンのルール

基準は「実在する地方の、少し退屈な日常を隣で見ている感じ」。感動させようとしない。

| やる | やらない |
| --- | --- |
| 値段、時刻、地名、人の名字を入れる | 「温かい」「優しい世界」など、感情を言葉で説明する |
| 誰か1人は少し不機嫌だったり、面倒くさがっていたりする | 最後に教訓やまとめを入れる |
| オチを説明せずに終わる。尻切れでもよい | 大事件、秘密の解明、壮大な由来 |
| 会話は中途半端で、話題が途中でずれる | 登場人物が説明的な台詞を話す |
| 季節の行事、ゴミの日、回覧板など生活の具体物 | 比喩を重ねる、形容詞を三つ並べる |

**文体のルール（手本v1のレビューから）**

- 数字は算用数字で書く。日付、値段、個数、時刻とも「11月4日」「3枚で398円」
- 日付と曜日は実際のカレンダーと合わせる
- 倒置法を使わない。「ひよこか、みかんか。」のような断片文も続けない
- 台詞を地の文で分割しない。台詞の中に余計な句点を入れない
- 絵文字は使わない（SNSも含む）
- 丁寧語は、実際の店や役所が使う言い方にする。「お手に取ってみてください」「、〜ますように」は使わない
- 文語的な結びや情緒的なまとめを書かない
- 風変わりにしてよいのは物と言葉だけ。人の好みや行動は現実どおりにし、高校生は今の高校生として描く
- 天気予報は信頼が第一。日付、天気、最高／最低気温、降水確率、風速、時刻を入れる
- 発信する側と受け取る側で、情報の細かさを分ける。放送やSNSは正確で詳しくする。小説や漫画の登場人物は、生活者が実際に覚えている程度にしか受け取らない（例：「戸田さんが何か数字を言っていたが、覚えたのは明日は止むということだけ」）
