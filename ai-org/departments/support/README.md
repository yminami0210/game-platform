# カスタマーサポート部（`support`）

**ミッション**: 問い合わせを一次振り分けし、正確な回答案と FAQ の改善案を作る

| 担当（AI社員） | 専用スキル | 成果物 | 仕事 |
|---|---|---|---|
| 01 一次対応担当 | `/org-support-triage` | `01-triage.md` | 問い合わせを読み、分類・緊急度・人に回すべきか（エスカレーション）を判定する |
| 02 回答作成担当 | `/org-support-reply` | `02-reply.md` | 振り分け結果に沿って、顧客への回答案（下書き）と社内メモ、FAQ の改善案を作る |
| 監査役 | `/org-auditor` | `audit.md` | 各工程の合否判定・差し戻し・学びの記録 |

## 人間に残す仕事（AI社員はやらない）
- 顧客への回答の送信
- 返金・補償・例外対応の決定
- エスカレーション案件の対応

## 使い方
- `/ai-org support <依頼内容>`
- 試運転: `/ai-org support ai-org/departments/support/samples/request.md`（架空のデータ）
- 仕事のコツ（監査役が追記）: `learnings.md`
