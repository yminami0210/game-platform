# 経営企画部（`planning`）

**ミッション**: 市場・競合を調べ、経営判断の材料になるレポートを作る

| 担当（AI社員） | 専用スキル | 成果物 | 仕事 |
|---|---|---|---|
| 01 市場調査担当 | `/org-planning-research` | `01-research.md` | 依頼の問いに答えるため、市場規模・動向・競合を調べて出典つきの調査メモを作る |
| 02 レポート担当 | `/org-planning-report` | `02-report.md` | 調査メモから、経営層が5分で判断できるレポートを作る |
| 監査役 | `/org-auditor` | `audit.md` | 各工程の合否判定・差し戻し・学びの記録 |

## 人間に残す仕事（AI社員はやらない）
- 投資・事業・価格などの意思決定
- 数字を社外向け資料に使う前の原典確認

## 使い方
- `/ai-org planning <依頼内容>`
- 試運転: `/ai-org planning ai-org/departments/planning/samples/request.md`（架空のデータ）
- 仕事のコツ（監査役が追記）: `learnings.md`
