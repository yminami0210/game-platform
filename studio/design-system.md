# デザインシステム（トモシムレ）v2 T-040（初稿 T-002 は破棄）

> 作り直しの理由: 初稿（紺黒 #07080F の闇＋琥珀の光の粒＋クリーム文字＋system-ui＋同じpillボタン）は game-art-direction §2 の「夜空に光る粒」系にほぼ全部当たっていた。題材（洞窟・ホタル）を「墨と和紙」と「蛍籠」に取り替えた。

## §借りてくる物
**墨と和紙** ＋ **蛍籠（竹ひごの虫かご）の手仕事感**。洞窟の闇は「墨で塗りつぶされた和紙」。ホタルの光が墨をぬぐい、下の紙の地を見せる。＝光の輪の中は明るい紙、外は墨。
- 画面は1枚の刷り物: ホタルは実際の蛍の黄緑で、墨の輪郭から 1〜2px ずらして重ね刷り（版ずれ）。岩は墨のかたまり（縁ごつごつ、顔料が少しずれて下に覗く、点苔）。罠だけ朱・藍。
- 初稿の方向（紺＋ネオン）に見えないことが最重要。ネオン色・グラデの光の玉・暗い青は使わない。

## §レイアウトの考え方
プレイ画面は「墨の中に紙の輪」。UI は2系統に分ける: 墨の画面（タイトル/リザルト/ひとやすみ）＝光が少ない時間、紙の画面（あそびかた/ずかん/せってい）＝全部が光で照らされた読み物。
```
タイトル（墨）           あそびかた（紙）          リザルト（墨）
┌──────────┐            ┌──────────┐            ┌──────────┐
│  ╭─────╮  │            │あそびかた~~│            │ ここまで ひかり│
│ ╱ ひ  ト ╲ │ 紙の輪      │ ●●  文 文   │ 左右交互    │     5      │ 蛍色の大数字
│ │ か  モ │ │ 縦書き     │ 文 文  ●●   │ 枠なし      │ [ベスト こうしん]│ 朱の判
│ │ り  シ │ │ 題字       │ ■ ■ 文 文   │            │ 層 ......  1 │ 点線の引き出し
│  ╲ ●  ム╱  │ ●=蛍       │            │            │ ....       │
│   ╰───╯   │            │ もどる~~    │            │ [もう一度 ともす]│ 下半分
│ [ ともす ]  │ 下半分     └──────────┘            │  タイトルへ~~  │
│ あそびかた ずかん せってい│                          └──────────┘
│ ● ● ● ● ●  │ 色えらび（ゆがんだ丸）
└──────────┘
```
- 整列: タイトルとリザルトは中央、紙の画面は左揃え（見出しは左、説明は左右交互の絵＋文）。同じ形のカードの繰り返しはしない。
- ボタン: 主役は蛍色の版1つだけ（墨の太枠・ずれた紙色の影・不揃いな角丸、押すと沈む）。副次は字だけ＋筆の下線。トグルは角ばった判子（オン=墨ベタ＋蛍の版ずれ）。確認は朱の枠。
- 縦持ち片手前提。主要ボタンは下半分、タップ領域 44×44px 以上（主役 72px）、safe-area は #ui の padding で対応。操作は画面全体のドラッグ。
- HUD: 上端は常に墨の中なので紙色の字。スコア/群れ数は Yuji Boku 26px、層名は筆の下線つき。

## §いちばん印象に残す1点
**光の輪の中だけ、墨がぬぐわれて和紙の繊維が見える。** 輪の縁は円でなく手ぬりのにじんだ形で、群れの数で広がる＝得点・視界・体の大きさが「紙が見える面積」として目に見える。タイトルの題字の下の紙の輪が同じ絵のミニチュア。

## §形のルール
- ホタル（味方）: 丸。墨の輪郭円に蛍色の円を (+0.035,-0.03) ずらして重ね、芯に淡い点。群れはゆらゆら追従。
- はぐれ: 紙色と墨の二重の輪（明るい紙の上でも墨の上でも見える）＋小さなホタル。毎秒約1.2回のゆるい明滅。
- 岩: 墨のごつごつした帯。縁は当たり判定の内側にだけ欠ける（見た目で不利にならない）。かすれ線と点苔。層の顔料が (+0.07,+0.06) ずれて覗く。
- 罠: 尖る。根のカーテン=朱の尖った帯（墨の版ずれ）、水たまり=藍＋波線2度刷り、風穴=墨の細い流線＋矢羽根、黒石=尖った墨の結晶＋藍の版ずれ＋朱の点（周りに墨がにじむ）。
- 花: 未点灯は暗い紙色の蕾、点灯は薄紅の五弁（墨が少しずれる）＋蛍色の芯。
- 人の手の跡: 座標のばらつき・版ずれ・手ぬりの縁・かすれ・紙の繊維と粒子。紙とざらつきは resize 時にオフスクリーン canvas へ1回だけ描いて毎フレーム drawImage（全面2回）。

## §光の表現（実装: game/src/render/renderer.js）
- 毎フレーム: ①紙の canvas を貼る ②世界（水・風・岩・罠・蕾・はぐれ）を墨で描く ③「墨のぬり」: 群れ重心から半径 R の外側を evenodd クリップで墨 0.96、さらに外にじみ 1.12R を 0.38、内側は 0.55R〜R で 0→0.38 のグラデ ④岩の縁だけ紙色の細線（闇でも見える） ⑤点灯した花・ホタル・粒子 ⑥ざらつきを全面に薄く。
- 輪の縁の形は低周波の正弦でゆがめ、ゆっくり揺れる（calm で停止）。R は N で 0.1 秒補間（sight(N)）。N≤5 で光を微かに脈動（毎秒1.5回、calm で停止）。層到達で R が一瞬ひろがる。全滅は 0.8 秒で墨が閉じる。
- 明滅はすべて毎秒3回以下。加算合成は使わない（紙の上で白飛びするため）。

## §動き
- イージングは ease-out 中心。画面フェード 0.4 秒。何もしていない時の動きはタイトルの蛍の呼吸（4秒）1種類だけ。
- 返事の動き: ボタンは押すと沈む（主役は影の分だけ移動）。拾う=輪の粒が群れに吸い込まれる。散る=粒が漂って消える。花=点灯。
- prefers-reduced-motion / 設定「うごき控えめ」: 画面のフェード・蛍の呼吸・縁の揺れ・脈動・ホタルの揺れ・粒子の飛散を止める。

## §音の方針（eco: 方針のみ。gs-sound が実装前に確認）
- 音色: やわらかい鈴（サイン波＋倍音、減衰 0.4〜1.2秒）と水滴（短いサインのピッチ下降）。ノイズ系・金属音は使わない。
- 効果音（すべて Web Audio 合成、外部音源なし）: 開始＝低→高の2音鈴／拾う＝高い鈴1音、連続拾いで音階が上がる(五音階)／散る＝短い水滴の下降音（小音量）／花を灯す＝3音上昇アルペジオ／層到達＝ゆっくり広がる和音ドローン＋鈴／全滅＝低い単音が減衰して消える。
- BGM: 層ごとに調と音数が変わる静かなループ（約60BPM、ペンタトニック）。深い層ほど低音ドローンと水滴の間隔が増える。群れ数が多いほど高音の鈴が1声部ふえる。
- 音なし前提: 重要情報は必ず視覚でも出す。初回タップ後に AudioContext 開始、設定でミュート即時、タブ非表示で自動停止。
- 音量: マスター 0.5、効果音が BGM より常に大きく、耳に痛い高音(4kHz超)は避ける。

### 実装済み効果音（T-022）
| SFX名 | 周波数 | 用途 | 質感 |
|---|---|---|---|
| start | 440→660 Hz | 開始 | 低→高の2音鈴、ふんわり立ち上がり |
| pickup | 880 Hz | ホタル拾う | 高い鈴、pitch引数で五音階 |
| scatter | 330→110 Hz | ホタル散る | 短い水滴の下降、小音量・やさしい |
| gate | 550 Hz | 隙間通過 | 小さな水滴パルス、0.08秒 |
| bloom | 264/330/396 Hz | ねむり花灯す | 三音上昇アルペジオ、五音階ペンタトニック |
| layer | 110 Hz + 440 Hz | 層到達 | ゆっくり広がる和音ドローン＋鈴、1秒 |
| fail | 220→110 Hz | 光が静まる | 低い単音が優しく下降、0.8秒、責めない |

### BGM実装（T-022）
- ファイル: game/src/audio/bgm.js
- API: startBgm(layerIndex 0-4), setBgmLayer(i), stopBgm()
- 特性: 各層で周波数オフセット（深層ほど低音）、ペンタトニック、60BPM風、パッド＋稀な鈴の組み合わせ
- ボリューム: 効果音より小さく（約0.15）、BGMのフェードイン/アウト0.5秒でクロスフェード対応
