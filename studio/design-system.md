# デザインシステム（水墨の軍師）

注: `.claude/game-studio/references/tech-stack.md` は存在しなかったため未参照。サイズ/PWA/Canvasは下記の一般的前提で記述（coderと要調整）。

## 1. ビジュアルの一言
「和紙の上に墨で描く戦場」。質感＝和紙の繊維、墨のにじみ・かすれ、朱の落款印、巻物の軸。写実は避け、筆致の省略で描く。残虐表現なし（倒れる駒は墨が薄れて消える）。

## 2. カラートークン（ライト1種のみ）
コントラスト比は和紙 `paper` 背景上の値。本文は4.5:1以上、大きな図形は3:1以上。

| トークン | 値 | 役割 | 対比 |
|---|---|---|---|
| `--paper` | #F1E8D4 | 背景（和紙） | - |
| `--paper-2` | #E4D8BC | パネル・凹み | - |
| `--ink` | #1F1B16 | 本文・輪郭・味方の主色 | 14:1 |
| `--ink-soft` | #5A5247 | 補助文字・地形の薄墨 | 6:1 |
| `--vermilion` | #B5341F | 敵・危険・落款・主ボタン | 4.9:1 |
| `--indigo` | #2F4A6B | 水・味方軍旗・情報(斥候) | 7.4:1 |
| `--ochre` | #7A5C14 | 報酬・習得・勝利 | 5.1:1 |
| `--moss` | #3E5B3A | 森・補給・安全 | 6:1 |

- ボタン上の文字は `--paper`（朱/藍/墨の塗りに対し4.5:1以上）。
- 色だけで区別しない: 味方＝丸＋藍、敵＝尖り＋朱、報酬＝四角の印＋黄土、危険＝二重線＋朱。
- 新しい色を足さない。濃淡は不透明度（`ink` の 100/60/30/12%）で作る。

## 3. 形のルール
- 駒: 味方は丸（藍の縁）、敵は三角/菱形（朱の縁）。シルエットだけで判別。
- 兵科駒（直径48px、中央に筆文字1字）: 歩＝丸に「歩」、弓＝丸＋上に弧線「弓」、騎＝丸＋斜めの流線「騎」。敵は同じ記号を尖り枠で。
- 地形アイコン（SVG、1色線画、64px基準、線幅3）: 山＝三峰の稜線、川＝二本の波線、森＝三本の松、平原＝横の掃き線、隘路＝向かい合う二つの崖。地形ごとに模様（ハッチ）も変え、色なしでも識別。
- 火攻適地（草/森）は炎の印（朱の小さな三角を3つ）を重ねる。
- 実装: SVGまたはCanvas関数（`game/src/render/`）。筆致は線のゆらぎ（座標に±1〜2pxノイズ）とSVGフィルタ/Canvasの重ね描きで表現。画像ファイルは使わない。

## 4. 斥候報告：信頼度の見せ方
報告は「印」で示す。信頼度は3段階。必ず色以外の手がかり（形・線種・文字）を併用。

| 信頼度 | 印の濃さ | 輪郭 | 靄 | 文字 |
|---|---|---|---|---|
| 高 | ink 100% | 実線・くっきり | なし | 「確」 |
| 中 | ink 60% | 破線・少しにじみ | 薄い靄 | 「概」 |
| 低 | ink 30% | 点線・強いにじみ | 濃い靄（地図が隠れる） | 「疑」 |

- 靄＝ぼかした白い楕円を重ねる（opacity 0.2〜0.6）。敵兵力の数は低信頼では「約」と範囲表示（例: 3〜6千）。
- 斥候の出所（間者の種類）は小さな落款アイコンで示す。報告は1枚3行以内。

## 5. 文字・余白・角丸
- フォント: 外部フォント不使用。`"Hiragino Mincho ProN","Yu Mincho","Noto Serif JP",serif`（見出し・解説）、`"Hiragino Sans","Yu Gothic UI","Noto Sans JP",system-ui,sans-serif`（数値・UI）。筆文字はSVGパスで自作した字のみ（タイトル・駒の字）。
- サイズ: 本文16px、補助12px（下限）、見出し20/24px、行間1.6。解説は1画面に収まる短文。
- 余白は4pxグリッド: 4/8/12/16/24。画面端の余白16px。
- 角丸: 4px（札・パネル）、999px（丸ボタン・駒）。影は使わず、墨の縁と薄い紙色の差で段差を出す。

## 6. 動きの原則
- イージング: `cubic-bezier(.2,.7,.2,1)`（筆が走って止まる）。UI遷移200〜300ms、演出は最長1.2s。
- 操作の手応え: 配置確定＝駒が墨の滴のように着地（80ms縮み→戻り）＋小さな墨にじみ。ヒット/衝突＝画面を揺らさず、墨の飛沫と0.1sの停止で表現。
- `prefers-reduced-motion`: 巻物スクロールは瞬間切替+フェード（150ms）、揺れ・飛沫を無効化、自動再生は「次へ」タップ式に。

## 7. 画面設計（縦持ち 390x844基準、片手）
共通: 上部は情報のみ（タップ要素を置かない）。主要操作は下半分、下端は `env(safe-area-inset-bottom)` 加算。タップ領域44x44px以上、隣接間隔8px以上。ノッチは `safe-area-inset-top` で回避。

**① 統一地図/戦場選択**
```
[ 統一度 ●●○○○  習得 3/13 ]  ← 情報のみ
+-----------------------+
|  水墨の中華地図        |  塗り=支配(藍/朱の淡墨)
|  戦場の印(落款)×N      |  印を直接タップ
+-----------------------+
| [選択中:赤壁 概要1行]   |
| [   出陣（大ボタン）  ] |  ← 親指ゾーン
```
**② 戦場（地形＋斥候報告）**
```
[赤壁  第1報/3]  ← 情報
+-----------------------+
| 地形マップ(3〜4区画)   |  区画タップ=詳細
| 敵の印+信頼度の靄      |
+-----------------------+
| 斥候報告札(3行・信頼度印)|  左右スワイプで切替
| [ 戻る ]   [ 配置へ → ]|
```
**③ 配置操作**
```
[ 残り兵: 歩2 弓1 騎1 ]  ← 情報
+-----------------------+
| 地形マップ(区画=置き場) |  上半分。区画をタップで選択
+-----------------------+
| 孫子の原則(5枚の札・横並び)| 1枚選ぶ(札に一行要旨)
| 駒トレイ: (歩)(弓)(騎) |  駒タップ→区画タップで配置
| [ 取消 ]   [ 開戦 ]    |
```
ドラッグ不要（タップ2回で配置）。ドラッグも併用可。

**④ ダイジェスト再生**
```
[ 巻物の軸(上) ]      進行 ●●○
|  カット1枚 (全幅)    |  数秒ごと、左→右/上→下に巻物が流れる
|  一行キャプション     |
[ 巻物の軸(下) ]
|  介入ポイント: 下部に札が出現（下記） |
| [ ⏭ 早送り ]  [ ⏸ ]  |
```
- 1カット2〜4秒、全体30〜60秒。カット間は巻物が滑る（400ms）。
- 介入ポイント（最大1〜2回）: 再生が止まり、画面が薄墨に暗転、朱の落款枠で「機」を表示。下部に選択札2〜3枚（各高さ64px）と5秒の墨の滴タイマー（時間切れ＝既定案）。見逃し防止に振動なしの脈動枠。

**⑤ 結果と孫子解説**
```
[ 勝 / 敗 ]  落款印が押される（勝=黄土の印、敗=朱で「惜」）
+-----------------------+
| 孫子の一節（原文＋読み下し）|
| なぜこうなったか 2〜3行  |  原因の箇所を地図の小図でハイライト
| 習得した兵法: [印+名]    |
+-----------------------+
| [ もう一戦 ]  [ 地図へ ] |  ← 親指ゾーン、「もう一戦」が主
```

## 8. ダイジェスト演出方針
巻物が横に流れる短いカット連続（駒のシルエットと地形線のみ、各カット3要素以内）。因果が分かるよう、原因カット（例: 火攻の炎）→結果カット（敵が散る）の順で必ず並べる。キャプションは15字以内。

## 9. 音の方針（Web Audio生成、外部音源なし）
- 音色: 琴＝三角波+短い減衰（Karplus-Strong風でも可）、笛＝サイン+微ビブラート+息ノイズ。音階は陰旋法（D E G A B）で統一。
- テンポ: 戦場選択・配置は約60BPMのゆったりした環境音、ダイジェストは約90BPMで太鼓を足す。BGMは常時ループ短めの生成、無音区間を多めに（疲れにくく）。
- 効果音一覧: タップ（琴の単音）、配置確定（太鼓低音+琴）、原則札選択（笛の短音）、介入出現（銅鑼風の鈍い響き）、衝突/火攻（ノイズバースト+低音）、勝利（上昇する琴アルペジオ+笛）、惜敗（下降2音、短く優しい）、習得（高い琴の1音+きらめき）。
- 報酬音は短く（1.2s以内）、失敗音は責めず余韻を残す。
- ミュート: 画面右上固定でなく設定札からBGM/効果音を独立ON/OFF、状態を保存。初回は自動再生せず、最初のタップで AudioContext を開始。タブ非表示で停止。
- 音量: マスター既定0.5、BGMは効果音より約-6dB、同時発音は最大8。クリップ防止にコンプレッサを挟む。音だけに情報を載せない（必ず視覚の対応あり）。

## 10. アクセシビリティ
- 色だけに頼らない: 敵味方=形、信頼度=線種+文字、地形=模様。
- タップ領域44x44px以上、主要ボタンは高さ56px。文字下限12px（本文16px）。
- 介入タイマーは延長/無効（設定）を用意。reduced-motion対応（§6）。
- 全ボタンに aria-label、フォーカスリングは2px `--indigo`。
- アイコン類: アプリアイコン（192/512）は朱の落款に「軍」風の自作字、紙地背景。OGPは巻物+地図の図案（自作SVGで制作）。
