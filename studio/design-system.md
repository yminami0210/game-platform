# デザインシステム（トモシムレ）初稿 T-002

## §アートディレクション
- 一言: 「墨色の洞窟に、群れの周りだけ琥珀色にじんわり灯る」。質感は和紙に滲む行灯の光、切り絵の影、湿った苔。
- 画面の大半は暗い。明るさ＝群れの数＝今の強さ。光の外は見えない（ただし岩の輪郭だけは薄く見えて事故死を防ぐ）。
- 暴力表現なし。ホタルは「散る」: 光の粒がふわっと離れて消える。

## §色トークン（CSS変数 `--c-*` と Canvas 定数で共通）
| 役割 | 名前 | HEX | 補足 |
|---|---|---|---|
| 背景(洞窟の闇) | bg | #07080F | theme-color も同値に更新 |
| 岩・壁 | cave | #1E2236 | 縁取り #3A4160（暗闇でも輪郭が見える） |
| 苔(光で見える飾り) | moss | #2F5D50 | 装飾のみ |
| 主役ホタル | main | #FFC94A | 中心 #FFF3C4。光は rgba(255,190,80,α) |
| 報酬(花・はぐれ) | reward | #7FE0D4 | 青緑。主役の黄と色相・明度差が大きい |
| 危険(罠) | danger | #FF5A6E | 必ず形・点滅とセット（色だけに頼らない） |
| 文字 | text | #F4F1EA | 補助文字 #B8B4C8（背景比 7:1 以上） |
| ボタン | accent | #FFC94A | 文字は #07080F（比 11:1 以上） |
- 色覚対策: main(黄)/reward(青緑)/danger(赤桃)は明度も差をつけ、さらに形（下記）で区別。群れ色アンロックは色相でなく模様（羽のハイライト形）でも違いを出す。

## §形のルール（Canvasで描ける単純形）
- ホタル: 丸い光点（半径5〜6px）＋小さな羽2枚（楕円）。味方は丸。群れは位置を少しずらしてゆらゆら追従。
- はぐれホタル: 丸＋外周にreward色の細リング、ゆっくり明滅。拾うと main 色に変わる。
- 岩: 角のある多角形（5〜8頂点、ノイズでギザ）。cave色塗り＋縁取り。隙間は左右の岩の間の空白（幅が群れ幅の目安になる）。
- 罠3種（すべて尖る・danger色）: ①棘＝下向き三角の連なり（岩から生える）②水滴＝上から落ちる涙形の影（落下前に影が点滅）③蜘蛛糸＝斜めの細線の網（触れると数匹がはぐれる）。
- 花: 茎なしの5枚花弁（円5つ）。未点灯は cave 色の輪郭のみ、点灯で reward 色に光る。
- シルエット判別: 丸＝味方/報酬、尖る＝危険、多角形の塊＝壁。

## §光の表現
- 毎フレーム: ①オフスクリーン相当の全画面を bg で塗る ②世界（岩・花・苔）を描く ③最後に「闇マスク」を重ねる。
- 闇マスク: 群れ重心を中心に radial gradient（中心 α0 → 半径R で α0.96 の bg 色）を `fillRect` 全面。R = 70 + 5.5*n px（n=群れ数、上限40で約290px）。n 変化時は R を 0.3秒で補間。
- 光源は各ホタルにも小さな加算合成の glow（`globalCompositeOperation='lighter'`、半径18px）。重い処理は避け、gradient は事前生成した小canvasを再利用。
- 苔・花は光の内側でのみ描くので、闇マスクだけで「大きい群れ＝見える物が増える」が伝わる。岩の縁取りだけは常時薄く見せる。
- 群れが少ない(n<=5)ときは光を微かに脈動（危機感）。

## §UI
- 配置（縦持ち、safe-area 対応済み）: 上端 HUD は左にスコア、中央に層名、右に群れ数（ホタルアイコン＋数）と設定ボタン。主要操作はドラッグのみで画面全体が操作領域。ボタンは画面下半分に置く。
- 文字: システムフォント（既存スタック）。最小12px、HUD 18px、見出し28px。外部フォントなし。
- タイトル: 中央に題字「トモシムレ」、下半分に大きな「はじめる」ボタン（高さ56px）、その下に「あそびかた」「設定」「ずかん」(各 44px 以上、間隔12px)。ベスト層・ベスト点を小さく表示。
- 遊び方: 文字を極力使わず、3コマ（ドラッグで導く／拾うと明るく大きく／狭い隙間は犠牲か回避か）をCanvasのミニ図で。初回は実プレイ中の吹き出し1行で教える。
- リザルト: 到達層・点数・灯した花・ベスト更新を上から。下半分に「もう1回」（最大ボタン）、「タイトルへ」。広告・引き留めなし。
- 設定: 音（ミュート切替）、振動オン/オフ、動き控えめ。トグルは幅56×高44px以上。データ消去は確認2段階。
- 全ボタン最小44×44px、隣接間隔8px以上。ボタン形は角丸全開(pill)、accent 色。

## §動き
- イージング: 基本 ease-out（cubic-bezier(.2,.8,.2,1)）。UI遷移 200ms、画面フェード 250ms。
- 拾う: はぐれが群れへ 150ms で吸い込み、群れ光が 0.3秒でふくらむ。+点数が上へ浮いて 600ms で消える。
- 散る: 端のホタルが 400ms かけて光の粒になり外へ漂い消える。群れ光が縮む。0.1秒の画面微振動(2px)と振動API 20ms。
- 花を灯す: 花弁が順に点灯(60ms刻み)、周囲に reward 色の輪が 500ms 拡大。
- 層到達: 画面全体が一瞬ふわっと明るくなり（300ms）、層名を中央に 1.2秒表示。
- 全滅: 光が 0.8秒でゆっくり闇に溶けてからリザルト。
- prefers-reduced-motion: 画面振動・明滅・脈動を停止し、フェードのみにする（設定の「動き控えめ」でも同様）。

## §音の方針（eco: 方針のみ。gs-sound が実装前に確認）
- 音色: やわらかい鈴（サイン波＋倍音、減衰 0.4〜1.2秒）と水滴（短いサインのピッチ下降）。ノイズ系・金属音は使わない。
- 効果音（すべて Web Audio 合成、外部音源なし）: 開始＝低→高の2音鈴／拾う＝高い鈴1音、連続拾いで音階が上がる(五音階)／散る＝短い水滴の下降音（小音量）／花を灯す＝3音上昇アルペジオ／層到達＝ゆっくり広がる和音ドローン＋鈴／全滅＝低い単音が減衰して消える。
- BGM: 層ごとに調と音数が変わる静かなループ（約60BPM、ペンタトニック）。深い層ほど低音ドローンと水滴の間隔が増える。群れ数が多いほど高音の鈴が1声部ふえる。
- 音なし前提: 重要情報は必ず視覚でも出す。初回タップ後に AudioContext 開始、設定でミュート即時、タブ非表示で自動停止。
- 音量: マスター 0.5、効果音が BGM より常に大きく、耳に痛い高音(4kHz超)は避ける。

## §アイコン方針
- 192/512px と maskable: 背景 bg の円形闇の中央に、琥珀の大きなホタル光＋小さな仲間2〜3粒、外周に radial の温かい光。文字なし。
- 安全領域は中心80%に収める。SVG（icons/icon.svg）を原本にして PNG を書き出す。
- OGP(1200×630)とスプラッシュも同モチーフ: 暗闇に光る群れと題字「トモシムレ」（システムフォント太字、光で縁取り）。
- 既存作のロゴ・キャラに似せない。素材は全て自作SVG/Canvas、外部素材なし（LICENSES.md への追記不要）。
