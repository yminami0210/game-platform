## 確認した範囲で問題なし

- 決定性: core は createRng のみ。`Date`/`Math.random` なし（game.js 全体）。seed は main.js:67 で外から渡す。
- 例外・耐性: save.js の migrate が純粋関数で、型不正、null、配列、負数を整える。JSON 破損時は DEFAULT で起動（save.js:21）。localStorage 不可でも例外を握る（save.js:23）。
- リーク: input.js のリスナーは起動時に 1 回だけ登録。rAF は 1 本。リトライで増えない。setTimeout（main.js:93）は `!running` ガード付き。
- 入力: pointercancel と keyup で解除。ボット経路と人の経路が同じ。
- アクセシビリティ: prefers-reduced-motion と「動き控えめ」設定が renderer（calm()）と CSS に効く。明滅は約 1.1〜1.5 回/秒で、基準の 3 回/秒以下。ボタンは min 44px（index.html:21,57）。
- 積み上げ: ベスト、到達層、花の累計、図鑑 12 種、群れの色解放が動機になる。
- コンセプト忠実度: N が半径・視界・倍率に同時に効く（game.js:12-14）。最大 N=40 の直径は約 2.65 で、全層の隙間 1.3〜2.3 を超える。大群は最後まで散るリスクを負うので、ジレンマは深層でも効く。
- 画面: 3-play-deep.png で、群れの光が闇をくり抜き、隙間と花と風の矢印が読み取れる。HUD の ひかり/層名/群れ が一目で分かる。
