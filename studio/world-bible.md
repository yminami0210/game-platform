# 世界観バイブル（Gate 1 版）

根拠: `studio/concept.md` / 権利メモ: `studio/research/novelty.md` §権利メモ
権利方針: 史実・演義の人物と孫子の原文（短い引用のみ）はパブリックドメイン。解説・台詞・UI文はすべて自作。

## 1. 一文で言うと
乱世の後漢末、名もない軍師見習いが孫子の兵法で地形と情報を読み、戦を重ねて中華統一への道を開く物語。

## 2. ゲームルールと世界の対応表
| ゲーム要素 | 世界での意味 |
|---|---|
| 地図・地形 | 戦場の実際の土地。地形篇の教えどおり、地形は「兵の助け」にも罠にもなる |
| 斥候報告 | 間者・斥候が持ち帰る知らせ。真偽は「信頼度」で測る。疑うことも軍師の仕事 |
| 配置 | 軍師が軍議で兵科を地形へ置く策。数の多さより置き場所が勝敗を決める |
| 孫子の原則（選択） | 軍師が拠り所にする兵法の教え。選んだ原則が、その戦の読みの筋になる |
| ダイジェスト | 戦の経過を記した巻物。流れるように広がる |
| 介入（1〜2回） | 戦のさなかに軍師が下す、ひと言の号令 |
| 勝利 | 策が通った証。統一地図の色が塗り替わる |
| 失敗 | 負けは「読み違い」であり死ではない。解説が孫子の言葉で原因を示す |
| 解説 | 師の講評。短く、一戦につき数行 |
| リトライ | 「もう一度、軍議を開く」。罰も待ち時間もない |
| 成長・習得 | 勝つたびに「兵法」が身に付き、少ない兵で勝てる。巻物（図鑑）に書き加えられる |
| 統一地図 | 中華の勢力図。戦に勝つほど一色に近づく |

## 3. トーン
- 重厚・静謐・知的
- 避ける: 軽薄・煽情的・説教くさい
- 文体見本:
  - 「江の上に霧が降りた。斥候の知らせは二つ。どちらが真か、見極めよ。」
  - 「敵は退路を断たれ、死に物狂いで抗った。九地にいう死地の理である。」
  - 「兵法は覚えるものではない。使って身に付くものだ。」
- 文章ルール: 一文は短く。常用漢字中心、難語にはルビまたは一言説明。講義調の長文は禁止。

## 4. 舞台・歴史（ゲームに出る分だけ）
- 時代: 後漢末〜三国時代（二世紀末〜三世紀）。漢の権威が衰え、群雄が割拠する。
- 主人公: 無名の「軍師見習い」。名前・顔は固定しない（プレイヤー自身）。師は匿名の「老軍師」。
- 筋: 赤壁で初陣を飾り、官渡・街亭・夷陵など諸戦で兵法を学び、統一へ進む。
- 史実の扱い: 大筋は史実・演義に従う。勝敗が史実と変わる場合は「もし策が違えば」の軍議として扱う。

## 7. 用語集（表記の正解・重複なし）
| 用語 | 意味・使い方 | 避ける表記 |
|---|---|---|
| 軍師 | 策を立てる者。プレイヤーの立場 | 参謀・司令官 |
| 軍師見習い | 初期の称号。成長で称号が上がる | 新人・初心者 |
| 軍議 | 配置を決める画面・場面 | 作戦会議・準備フェーズ |
| 配置 | 兵科を地形へ置くこと | 布陣・設置 |
| 斥候報告 | 戦前に届く敵情の知らせ | 偵察レポート・情報 |
| 信頼度 | 斥候報告の確からしさ（高・中・低） | 確度・信用度 |
| 兵科 | 兵の種類の総称 | ユニット・兵種 |
| 歩兵 | 兵科。守りと粘りに強い | 槍兵 |
| 弓兵 | 兵科。高所と遠距離で力を出す | アーチャー |
| 水軍 | 兵科。川・江で力を出す | 水兵・海軍 |
| 騎兵 | 兵科。平地で機動する（次段階） | 騎馬隊 |

| 山地 | 地形。高所を取れば守りに強い | 山岳 |

| 孫子の原則 | 選んで使う兵法の教え。UIでは単に「原則」 | スキル・カード |
| 地形篇 | 原則。地形の利を読む | 地形編 |
| 九地 | 原則。土地の性質で兵の心を読む | 九つの地 |
| 死地 | 九地の一つ。退路なき土地 | 絶地 |
| 火攻 | 原則。火と風を使う | 火計・火責め |
| 用間 | 原則。情報を得て真偽を見極める | 諜報 |
| 知彼知己 | 原則。敵と己を知る（謀攻篇） | 彼我 |
| ダイジェスト | 戦の経過の再生（巻物演出） | リプレイ・戦闘シーン |

孫子の原文は短い引用に限る（例: 「兵者、詭道也」「知彼知己、百戦不殆」「火攻有五」）。出典の篇名を添える。

## 8. 禁止事項
- 既存作品・既存ゲームの固有表現、台詞、キャラ造形、技名、BGM・イラストの模倣（コーエーテクモ等の用語を含む。例: 無双、乱舞、真・）。
- 現代語・外来語の混入（ステータス、スキル、レベルアップ、バフ、デバフ、ターン、クリア、ミッション等）。UI上必須の語は和語・漢語に置換。
- 残虐描写（流血、遺体、拷問、虐殺の具体描写）。死は「敗走」「討ち取られた」程度にとどめる。
- 現代の孫子訳書・解説書の文言の転用。解説は自作の現代語。
- 長文の講義、プレイヤーを責める文言、課金・待ち時間・煽りを連想させる表現（「あと◯分」「今すぐ」など）。
- 運だけを示す表現（「運よく」「ガチャ」）。勝敗は読みと配置の結果として書く。
- 特定の国・民族・宗教への蔑視、史実人物の過度な貶め。
- 迷う表現は `studio/legal/` に1行メモ。
