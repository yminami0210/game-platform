# 世界観バイブル「トモシムレ」初稿 (T-001)

一文で言うと: 暗い洞窟で、ついてくるホタルの群れを灯りに、奥の花をめざす静かな旅。

## トーン
- 守る形容詞: やさしい / 静か / 少し神秘
- 避ける形容詞: 激しい / 急かす / 説教くさい
- 暴力・戦い・仕事（ノルマ、業務、評価）を題材にしない。長文にしない（1文20字前後）。
- 文体見本: 「ひかりが ふえた。」「また、くらい ほうへ。」「みんな、まってる。」
- 表記: 基本ひらがな＋やさしい漢字。ゲーム内は「です・ます」でなく言い切り。感嘆符は使わない。

## 舞台（洞窟の5つの層）
あなたは名もなき「灯り手」。洞窟の底に咲く「ねむり花」を、群れの光で起こしにいく。
| 層 | 名前 | 見た目 | 新しく増える罠 |
|---|---|---|---|
| 1 | あさせ | 淡い青の苔、水が浅く光る | 岩の隙間（基本。幅を読む練習） |
| 2 | こけの道 | 緑の苔の回廊、胞子が漂う | 風穴（横へ軽く押す） |
| 3 | しずくの間 | 天井から水滴、鍾乳石の林 | 水たまり（浸かると光が一瞬弱まる） |
| 4 | ねの森 | 古い根が垂れ下がる暗がり | 根のカーテン（触れた端が散る） |
| 5 | ねむりの底 | 紫の水晶と大きな花畑 | 光を吸う黒石（近いと群れが暗くなる） |
- 実装メモ: スコープ上の罠は3種。5種のうち風穴・水たまり・根のカーテンを優先し、他は隙間の変形で代用可（PM判断）。

## ルールと世界の対応
| ゲームの要素 | 世界での意味 |
|---|---|
| 群れの数 | ホタルがそばにいてくれる数。仲間が多いほど心強い |
| 明るさ（視界） | ホタルの光が重なった分だけ洞窟が見える。数が多い＝明るい |
| 倍率 | 明るいほど苔や花が見え、みつけた喜びが大きい＝ひかりの実り |
| 幅 | 仲間が増えると体を寄せきれず、場所をとる |
| スコア | 「ひかり」の量。灯した苔と花の数で積み上がる |
| はぐれホタル | 暗闇で迷っている仲間。近づくと群れに加わる |
| 隙間を通る判断 | 全員で行くか、端の子が少し遅れても進むか。置いていくのではなく「はぐれる」だけで、また会える |
| 失敗（数が減る） | ホタルは死なない。「散る」「はぐれる」。岩や根にぶつかると端の数匹が散り、その場に残って小さく光る |
| 終了（0匹） | 光が静まり、洞窟がひと息つく。ホタルは眠り、次の灯りを待つ |
| リトライ | もう一度、灯りをともす。散った子たちは、ほどなく戻ってくる |
| 成長 | 深い層へ進むほど、洞窟は深く・狭く・罠が増える。到達層が記録に残る |
| 花を灯す | 群れの光が十分に届くと「ねむり花」が咲く。咲いた数が積み上がる（保存） |
| 図鑑 | 出会った光る生き物の記録 |
| 群れの色 | 出会った生き物から分けてもらう光の色（アンロック） |
