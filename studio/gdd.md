# ゲームデザイン文書（GDD）— トモシムレ

前提: studio/brief.md（要点）、concept.md、world-bible.md、design-system.md、balance.md。

## 1. 概要とコアループ
縦スクロール。洞窟が上から下へ流れ、群れは画面下寄り（論理 y=11、論理座標 幅9×高さ16）。左右に群れを導き、隙間を抜け、はぐれホタルを拾う。N=0 で終了。

## 2. ルール
- 群れ: N 匹（開始5、最大40）。リーダー x の周りに半径 r(N) の円盤状に配置（描画用の各ホタル位置は core が決定的に持つ。黄金角配置など）。
- 壁: 一定間隔で横一列の岩壁。隙間（幅 gap、中心はランダム、前の隙間から gapSpread 以内）。壁の行を通過する瞬間、隙間の外にいるホタルは散る（N 減）。全員外なら全員散る。
- はぐれホタル: 壁と壁の間に出現（+1〜+3）。群れの円に触れると加わる。
- 罠（層ごとに追加）:
  - 風穴（層2〜）: 帯の範囲で群れ全体を横に押す（強さ f）。
  - 水たまり（層3〜）: 帯に入ると 2秒間 倍率が半分・視界が縮む（散らない）。避ける価値の判断用。
  - 根のカーテン（層4〜）: 縦に垂れる細い帯。触れたホタルのうち最大 webCatch 匹が散る。
  - 黒石（層5）: 近くを通ると群れを引き寄せ、円に触れると frogFrac の割合が散る。
- ねむり花: 各層に数本、壁の脇。群れの視界 R(N) が花に届く距離で通過すると灯る（ボーナス +N×5 ひかり、保存で累計）。N を育てる動機。
- 得点（ひかり）: 毎フレーム 速度×dt×m(N)。表示は整数。
- 層: 距離 80 ごとに次の層。層5以降は層5の表を使い、速度が距離に応じて少しずつ上がる（上達者のランを150秒前後で終わらせる）。

## 3. 操作
- ドラッグ: 指の横移動量でリーダーの目標 x を動かす（相対ドラッグ。指が群れを隠さない）。速度上限 moveSpeed。
- core の行動は left / right / none（ボット用。ブラウザでは目標 x への追従を left/right/none に変換するか、core に setTargetX を足してもよいが、actions() と step(state, action) は必須）。
- キーボード ←→ も可。

## 4. 画面フロー
起動 → タイトル（ともす / あそびかた / ずかん / 設定、ベスト層・ベスト点）→ プレイ → 0匹で光が静まる演出0.8秒 → リザルト（到達層・ひかり・灯した花・ベスト更新）→ もう一度 ともす（最大ボタン）/ タイトルへ。
リトライまで3秒以内（gates.json）。

## 5. 要素一覧
- 層5種（名前・色・罠は world-bible §舞台）。生き物図鑑12種（world-bible §生き物）。出現条件はデータで定義。
- 群れの色（アンロック）: 灯した花の累計で解放（例 0/30/80/150/300）。見た目のみ。

## 6. 進行と積み上げ（保存）
ベスト点、ベスト到達層、ねむり花の累計、図鑑の発見フラグ、解放した群れの色と選択中の色、設定（ミュート・振動・動き控えめ）。

## 7. チュートリアル
初回プレイのみ、層1の最初の3枚の壁は広く、吹き出し1行ずつ（world-bible §UIテキスト のチュートリアル3行）。止めない。

## 8. データスキーマ（game/src/data/）
- balance.json: 数値（studio/balance-proposal.json がベース。罠キーは wind / puddle / roots / blackstone）
- layers.json: 層の名前・到達メッセージ・色・罠の出現（content-creator）
- creatures.json: 図鑑12種（id, name, desc, layer, 出現条件）
- texts.json: UI文言
- colors.json: 群れの色と解放条件
注意: simulate.mjs は data/ に JSON が複数あると `{ balance, layers, ... }`（ファイル名キー）で createGame に渡す。main.js も同じ形で渡すこと。

## 9. イベント一覧（core → main）
start / pickup{n} / scatter{n, x, y} / gate（壁通過） / bloom{flowerId} / layer{index} / puddle / creature{id} / score{value} / fail{score, layer}
