# GDD（スライス範囲のみ。必要な項目だけ）

## スコープ
赤壁1戦で、軍議→配置→ダイジェスト→解説→リトライが通ること。連戦・統一地図・図鑑は枠だけ（画面は仮でよい）。

## 画面（design-system §7 を参照）
1. 戦場選択（スライスでは赤壁のみ）
2. 軍議：地形4種の配置盤＋斥候報告4件（信頼度の見せ方は design-system §4）＋原則2枠の選択
3. ダイジェスト：events[] を順に再生。3ラウンド目の頭に介入（1部隊を別地形へ移す）
4. 解説：reasons[] を孫子の言葉＋自作の現代語で数行。スコア0〜3
5. 結果の導線：「もう一度、軍議を開く」を最も押しやすい位置に。リトライは1タップ・即時

## ルール（balance.md が正）
- 配置: 歩兵40・弓兵30・騎兵30 を地形へ割り当てる（部隊単位。ドラッグまたはタップ選択→地形タップ）。
- 斥候報告4件（歩・弓・騎の位置、風）。信頼度で真偽が決まる。あり得ない報告（騎兵が江にいる等）は偽と見抜ける。
- 原則を2つ選ぶ。条件を満たさないと効かない。用間は報告1件を確定の真実にする（枠を1つ消費）。
- 勝敗: スコア 0 敗 / 1 善戦 / 2 勝利 / 3 完勝。初回は「善戦以上」で達成と感じられること。

## 保存
localStorage（キー: sangoku_gunshi_v1）。保存するもの: 最高スコア、習得した原則、直近の戦績。失敗時も遊べること。

## 音（design-system §9）
Web Audio で生成。初期はミュート解除を1タップで。効果音は Phase 4 で追加（スライスでは無音で可）。

## スライスで確かめる仮説（concept.md と同じ）
1. 配置後のダイジェストで「なぜこうなったか」が分かり、もう一戦やりたくなる。
2. 原則の選択が勝敗に効くと体感できる。
3. 斥候報告の信頼度を読む判断が腕として効く。
