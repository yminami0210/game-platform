# GDD — ツギと ほつれ島（ワールド1）

## 操作
| 行動 | キーボード | パッド | スマホ（横持ち） |
|---|---|---|---|
| 移動 | ← → / A D | 十字・左スティック | 左下の十字 |
| しゃがむ／見下ろす | ↓ / S | ↓ | 十字の下 |
| ジャンプ（長押しで高く、綿毛中は滑空） | Z / Space / K | A（下ボタン） | 右下の大ボタン |
| ダッシュ（押しながら走る） | X / Shift / J | B・X | 右下の小ボタン |
| 一時停止 | Esc / Enter / P | Start | 右上 |

## 手触りの仕様（`game/src/data/tuning.json`）
- 歩き最高 92px/s、ダッシュ最高 150px/s。地上加速 520、減速（摩擦）820、切り返し 1500 px/s²、空中加速 420
- ジャンプ初速 330 + |vx|×0.13。上昇中ボタン押しっぱなしの重力 900、離すと 2700、落下 1650、最大落下 330
- 頂点付近（|vy|<45、押しっぱなし）は重力半分（ふわっと止まる）
- コヨーテタイム 7f、先行入力 8f、天井の角の補正 5px
- 着地: 着地速度に応じたつぶれ・砂ぼこり、強い着地は 2px の画面揺れ
- ヒットストップ: 踏みつけ 4f、被弾 8f、ボスに当てる 10f
- カメラ: 向いている方向に最大 56px 先読み（ゆっくり追従）、縦は着地した高さに合わせる（ジャンプ中はゆれない）
- 綿毛: 落下中ジャンプ押しっぱなしで落下速度 48px/s、蒸気の上昇気流に乗れる

## ワールド1 構成
| ステージ | 名前 | 新しい仕掛け | 見せる → 試させる → ひねる → 決めさせる | 隠し |
|---|---|---|---|---|
| 1-1 | はぎれ野のはし | ばねボタン | 目の前の段にボタン → ボタンで高い崖を登る → 穴の上・敵の頭上でボタン → 連続ボタンで大穴を越える | 金ボタン3（高所の裏道・見えない壁の奥・ばね最高点） |
| 1-2 | ほつれ橋 | ほつれ糸の橋（乗ると少しして落ちる） | 低い所の短い橋 → 穴の上の橋を走り抜ける → 崩れる橋の上に敵 → 長い連続橋を止まらず渡る | 金ボタン3 |
| 1-3 | ファスナー谷 | ファスナーの動く足場（横・縦） | 低い所の1つ → 穴越え → 縦と横の乗り継ぎ → 針の上を乗り継ぐ | 金ボタン3＋**隠し出口**（ひみつの縫い目へ） |
| 1-4 | アイロン台地 | 蒸気の吹き出し口（上昇気流・一定／息つぎ） | 蒸気で少し浮く → 蒸気で高台へ → 息つぎの蒸気でタイミング → 綿毛で蒸気を乗り継ぐ | 金ボタン3 |
| 1-ひみつ | ひみつの縫い目 | 1-3 の隠し出口から。糸玉の多い短いご褒美ステージ | | 金ボタン3 |
| 砦 | 針山の砦 | スナップ切替（赤と青のブロックが入れ替わる） | 切替を見る → 切り替えて道を作る → 針の上で切り替える → 敵に追われながら切替 → ボス | 金ボタン3 |
| ボス | 大蛾ケバ | 3段の攻撃（突進 → 鱗粉＋速い突進 → 幼虫呼び＋針の三方撃ち＋2連突進）。突進の後に地面で息を切らす間に踏む。1段2回、計6回 | | |

エンディング: 結び玉を取り戻す → 縫い目が締まる → 次の島が流れていく → 「つづく」。以降はマップに戻って金ボタン集め。

| 名前 | 動き | 踏める |
|---|---|---|
| イガ | 歩いて壁で折り返す。段差から落ちる | ○ |

| チョキ | 近づくと、ためてから跳びかかる | ○ |

## 進行とセーブ
- マップのノード: 1-1 → 1-2 → 1-3 → 1-4 → 砦。1-3 の隠し出口で「ひみつ」が開く（ひみつのゴールで砦の手前の近道も開く）
- セーブ（localStorage、バージョン付き）: クリア済み、金ボタン、隠し出口、最短タイム、死亡数、糸玉の合計、エンディングを見たか
- ステージ内: 待ち針（中間）から即リトライ。取った金ボタンと糸玉は死んでも残る
