# 依頼: 横スクロールアクション「ツギと ほつれ島」ワールド1の追加区画（4つ）

## 目的
ワールド1の遊ぶ時間が少し足りない。ステージ 1-3（ファスナー谷）と 1-4（アイロン台地）に、それぞれ区画を2つずつ足す。初心者でも1〜2回の失敗で越えられる程度の「組み合わせ・おさらい」の区画にする。新しい仕掛けは作らない。

## 区画の書き方
- 区画は JSON オブジェクト: {"note": "役割: 内容", "rows": [20行の文字列]}
- rows はちょうど20行。全行同じ長さ（36〜48文字）。1文字＝16pxのマス
- 下の4行のうち左端と右端の列は地面 # でつながること（前後の区画と床の高さがつながるように、左端4列と右端4列は下から4行を # にする）
- 文字の意味: . 空き / # 地面 / % ブロック / - 下から抜けられる足場 / ^ 針（触れるとダメージ） / o 糸玉（コイン） / x 崩れる橋 / B b 箱
- 敵: 1 イガ（歩いて折り返す） 4 ハリ（段差で折り返す） 6 指ぬき砲（その場で針を撃つ、上に乗れる） 7 毛玉（弾みながら進む）
- 仕掛け: Z 横に4マス動く足場 / z 横に8マス動く足場 / Y 縦に4マス動く足場 / y 縦に7マス動く足場 / V 蒸気の吹き出し口（上に吹き上げる） / W 息つぎする蒸気（出たり止まったり） / C 中間地点
- 使わない文字: P G E M 8 A S T r u h f（スタート・ゴール・メダル等は既存の区画にある）
- ツギのジャンプ: 高さは最大3マス、助走ありで横に最大4マスの穴を越えられる。これを超える段差・穴は仕掛けで渡らせる
- 1-3 では Z z Y y を、1-4 では V W を中心に使う。1区画に敵は2体まで、針は1か所まで
- 糸玉 o を各区画に4〜8個、道すじに沿って置く

## 返す形式
JSON だけを返す。説明文やコードブロックの記号は付けない。
{"1-3": [区画, 区画], "1-4": [区画, 区画]}
note は日本語で「おさらい（3）: …」「組み合わせ: …」のように役割と内容を書く。
