# 見本で決めた細かいルール（scene.png / swatch.png の作図で実際に使った数値）

内部解像度 256x144、拡大は最近傍の整数倍のみ。色は 6色＋重ね刷りの8色（下表）。ここに無い色は使わない。

## 色（hex は studio/design-concept.md §4 と同じ）
- 重ね刷り（版が重なって出る色。しぼ・影・面の明暗はこの中だけで作る）: 藍濃 #1f3752 / 藍淡 #3f6590 / 縹濃 #5683a3 / 縹淡 #8fb5cb / 茜濃 #8a2c22 / 刈安濃 #a4852b / 刈安淡 #e6cd6e / 生成影 #c9b88f
- グラデーション・半透明・アンチエイリアスは使わない。

## 抜けの線（輪郭）
- 墨の輪郭は無し。全キャラ・小物・地形の外周を生成り(#ebdfc3)で囲む。
- 太さ 1px。ただし線の約14%（区間単位）は 2px にふくらむ。小物（ばね・つづら・HUDの札）は 1px 固定。
- つり（途切れ）: 外周の線は「7〜14px 続いて 1〜2px 途切れる」を繰り返す（途切れ2pxは4回に1回）。向き（上下左右）ごとに周期の位相を変える。
- 斜めの段差の角は、30%の確率で1px欠かす。
- 色の面どうしの境目は、キャラ内部では生成りの線を1px手で置く。背景の反物の輪郭は縹淡(#8fb5cb)の1px・つり無し・太らせない（弱い抜け）。

## 版ずれ
- キャラ: 茜の版を右へ +1px、刈安の版を下へ +1px（墨=目と藍の版は動かさない）。ずれて空いた1pxは「布の地」の生成りが見える。
- 背景（反物・地形の柄）: 柄の版を右へ +2px、下へ +1px。面の左端と上端に柄の無い帯ができる。
- 重ね刷り（逆向きに -1px）では境目に茜濃が出る。使うのは swatch の見本のみ。

## しぼ
- 点ではなく「短い皺の線」。長さ 2〜4px、線と線の間隔 5〜18px。色は面の色から藍濃/藍淡など重ね刷りの2色へ。
- 面積に対する密度: 空 約3%、地形の継ぎ布 約10%（地面の下段は約8%）、キャラ 約5〜7%（軽く）。
- 向きは布の面ごとに変える: 横 / 縦 / 斜め（同じ向きを隣の面に使わない）。画面全体に1枚かけない。

## 運針（縫い目）
- 針目の長さ 2〜4px（一様乱数）、針目の間 1〜2px。等間隔の点線は使わない。
- 角の手前・端の3px以内は針目2px・間1pxに詰める。
- 針目ごとに18%の確率で垂直方向に1px ずらす（手縫いの揺れ）。
- 刺し子（袖・継ぎ布）は生成り、当て布の縫い付けは藍。地形の継ぎ目は継ぎ目線上に1本、内側2〜4px に縫い代の1本。
- 継ぎ目の交点（4枚が会う所）に生成りの X 止め（5px、中心＋斜め4点）を置き、その4方向へ短いしわ（藍濃の線 2〜4px、3本の扇）を出す。

## 縫い縮めのしわ
- 継ぎ目・縫い止めに向かって、藍濃(茜は茜濃)の1px線を2〜4px長で扇状に3〜4本。キャラは袖の付け根と胴の裾、ちりめん小物は口の周り。

## 形（ドット絵の寸法）
- ツギ: 身長24〜26px（髷〜足）、頭 14x10、胴 10px幅、袖は長さ約11・幅 約8の平行四辺形（袖の裏の茜は端から2px）。針(簪)は生成り1px・糸は茜1px。目は左 2x3・右 2x2 で大きさと高さを変える。口は1〜3針。
- イガ 22x11（筒＋片側だけとがった頭）、コナ 22x16（大三角の翼＋筒の胴）、つづら 24x20、ばねボタン 18x22、糸玉 8x8、ボス 64x52。
- 縦線は縞・七宝(格子の円弧 d=8〜15)・青海波(R=9, リング幅 R×0.27)・矢絣(幅5)・鱗(10x4)の5種から。丸い木・もこもこの雲・なだらかな丘は無し。

## 地形・背景
- 地面の上端は「布の耳」3行: 生成り / 生成り+生成影の斑 / 生成り+藍の織り目の点、その下に藍濃1行。
- 継ぎ布の境界は ±1px で揺らす（7〜9px ごと）。上段の高さ 13〜16px、下段 20px。
- 背景は 3層: 干し場の竿（消炭 3px＋刈安の洗濯ばさみ）→ 反物（縹濃 or 藍淡、幅22〜29、長さ36〜76、下端は燕尾・ピンキング・斜め・ほつれ房の4種）→ 手前の遠景帯（青海波）。遠くの反物は縹淡で縮めて薄く。

## HUD（織りネーム）
- 札は生成り、高さ13px、左端は3行ごとに1px欠け・右端は4行ごとに欠ける（裁ち切り）。上下の縁は生成影の織り目、内側2px に藍の運針。文字は 3x5 のドット数字、字間1px、版ずれで札から+1px。
- 実機の見出しは Kaisei Decol Bold、本文は DotGothic16（game/fonts の woff2。OFL）。
