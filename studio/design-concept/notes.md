# 見本（改訂2）で決めた細かいルール — 320x180、scene@4x = 1280x720

内部解像度 320x180（1280x720 で4倍、1920x1080 で6倍）。拡大は最近傍の整数倍のみ。地形のマスは16px。
作図スクリプトは scratchpad/concept/{lib,sprites2,scene2,swatch2,measure}.js（一時置き場。エンジンへはこの文書の数値で移す）。

- **暖色（生成り・茜・刈安と、それぞれの重ね色）= 30.9%**（基準 25〜30% 以上）。基本の3色だけなら 13.9%（残りは茜濃 4.3%・刈安濃 10.1% など木と反物の濃い面）
- **淡い縹（縹+縹淡）= 1.2%**（基準 20% 以下）。空の地は縹濃にした（空まで淡い縹だと背景が白っぽく霞んだため）。縹系すべてでは 33.7%
- 藍系（藍・藍濃・藍淡）= 31.9%、消炭 3.4%（影は藍濃で作るため少ない）
- 文書の比率表（design-concept.md §4）はこの実測に合わせて書き直すこと（PM 作業）。縹の役割を「淡い縹は空の一部だけ、空の地は縹濃」とする案を出す。

## 画面の構成
- 層: 竿と支柱（刈安濃の木。支柱 8px、竿 4px、ブレース 4px）→ 遠景の淡い反物（縹・縹濃の柄、7枚、背後）→ 手前の反物9枚 → 洗濯ばさみ → 地面
- 洗濯ばさみ: 6x18px、割り箸型（左の棒=刈安淡/刈安/刈安濃、右の棒=刈安/刈安濃/消炭、支点は消炭2行）。反物1枚につき左右2個、竿の高さ y=4〜21
- 反物: 手前9枚は藍濃×4（七宝・青海波・縞・七宝小）、茜濃×3（矢絣・縞・青海波）、刈安濃×2（鱗・縞）。幅20〜34、長さ64〜124、裾は燕尾・ピンキング・ほつれ房（3〜6px の糸、手で決めた長さの表）の3種。1枚（x118）は風で 0.05px/行だけ傾ける。両端の耳は1px（藍の反物は藍淡、茜は刈安、刈安は刈安淡と生成り）
- ツギの背後（x84〜146）は藍濃の長い反物2枚。ツギの周囲40pxの背景は藍濃/縹濃で、ツギ（生成り・茜・刈安を含む）より暗い
- 地面: 上端 y=144。耳は刈安淡/刈安/刈安/刈安濃の4行（織物の端の色糸）。継ぎ布は上段（高さ20）5枚＋下段（高さ16）4枚。うち1枚は茜濃（暖色の面）。1枚の生成りの当て布（34x12）は右下に縫い付け
- 足場: 62x16、上面は刈安の耳3行＋藍淡の折り返し3行＋藍濃1行、下に房

## 抜けの線（生成り）の使い分け（全周を縁取らない）
- 規則: 置いた絵の外周の画素ごとに、「背景の明度と絵の明度の差が22未満」の所だけ生成りの線を1px引く（明度=0.3R+0.59G+0.11B）。差があれば線なし
- 結果: ツギ（藍の頭巾・袖・草履が藍濃の反物に溶ける所）と、つづらの藍の紐・敵の暗部が反物に重なる所だけに線が出る。糸玉・ばね・イガ・コナ・足場は縁取りしない
- 線が出る所も、7〜14px続いて1〜2px途切れる（つり）。太らせない（常に1px）
- 絵の内側の抜けは手置き: ツギの袖の下の縁（1px）、袖口の折り返し（5px目の1本）、衿のV、頭巾の運針、帯の運針、イガの胴の継ぎ目3本、つづらの紐の運針

## 手置きの場所（乱数は使わない。座標は sprites2.js / scene2.js の配列）
- ツギの顔（頭 20x16、head-local 座標）: 目 3x4 は左 x3..5・y9..12、右 x13..15・y10..13（右が1px低い）。ハイライト各1px（左 (4,10)、右 (14,11)）。眉は茜1px線を左 (3,8)(4,8)(5,7)、右 (13,9)(14,9)(15,8)。口は消炭2針 (8,13)(9,13) と (10,12)(11,12)。鼻筋は生成影2px (9,11)(10,11)。頬の点・赤い口・点目はなし
- 頭巾: 十字刺し子3か所 (4,2)(10,1)(15,2)、運針は行5に 3・4・2・3 針（x1..3、6..9、12..13、16..18）。髪際はピンキング（周期6、深さ0〜2）
- 髷（刈安の糸玉）と簪（生成りの針1px＋輪＋茜の糸）。糸の端は2本にほつれる
- 袖: 長さ約18・厚さ8〜9の平行四辺形、下の縁は生成り1px、上の縁は藍濃1px、袖口 4px は茜＋刈安の小花、5px目は生成りの折り返し。十字柄は中心線上に3つ。付け根に藍濃のしわ4〜5px（縫い縮め）
- 左右非対称: 左袖は先端を8px上げ、右袖は16px上げる（跳びの非対称）。足は左が1px高い
- 継ぎ目の交点7か所に生成りのX止め（5px）と、その4方向に藍濃の短いしわ（2〜4px、3本の扇）
- 縫い目（運針）は継ぎ目の上だけ。上段下の横縫いは4区間に分け（x3..76 / 84..128 / 136..210 / 218..314）、区間ごとに針目長（3〜4 / 2〜3 / 2〜4 / 3〜4）と間（1〜2）を変える。縦の継ぎ目は短い1本ずつ。画面幅いっぱいに同じ調子で続く縫い目はない
- 針目の長さは 2〜4px（角の3px以内は2px・間1px）。針目ごとの垂直ずれは入れない

## 版ずれ
- キャラ: 茜の版を右へ+1px、刈安の版を下へ+1px（生成りの地が1px見える）
- 背景・地形の柄: 柄の版を右へ2px、下へ1px。面の左端2px・上端1pxは柄なし

## しぼ
- 短い皺の線（長さ2〜4px、線の間隔5〜18px）。地面の継ぎ布で3枚だけ（横・縦・斜め）。キャラと反物には入れない。密度は継ぎ布 約8%

## ドット絵の寸法
- ツギ: 髷から足まで 32px（簪の輪まで 44px）、頭 20x16、胴 12px 幅。32〜34px の基準を満たす
- イガ 約32x20（筒に3本の背棘・片側だけとがった尻尾・茜の目と口のほころび）、コナ 約26x24（生成影の大三角の翼＋茜の目玉模様＋筒の胴）、つづら 約30x24、ばね 約26x30、糸玉 12x12、ボス 64x52（旧版。320x180 では 96x64 に作り直す）
- シルエット確認: silhouette16.png（16px の影。ツギ・イガ・コナ・つづら・ばね・ボス）。実機の縮小ではなく高さ16pxへの面積縮小

## HUD
- 織りネーム: 生成りの札、高さ18、左端は3行ごと・右端は4行ごとに欠け、上下は生成影の織り目。内側3pxに藍の運針。数字は 3x5 を2倍、ツギの命は茜の結び玉3つ、糸玉の数は刈安の糸玉アイコン
