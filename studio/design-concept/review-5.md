「書いてあるが絵がそうなっていない」のがいちばんの減点。このまま作ると、文書の約束と画面が食い違い、8点台前半で止まる。

## 2. 残る問題（場所つき）

1. **HUD 右上札の糸玉アイコンが高解像度**（scene-hires、x≈995〜1040, y≈125〜160）。文書とは逆の状態。直さない限り「層の規則が見本で守られている」と言えない。
2. **毛羽の質感が全面に均一**（tsugi-final-face、顔布・頭巾・袖・簪の頭の糸玉）。実物の布は、縫い目と縁に寄って、面の中央は平らに見える。「縁に寄せ、中央は薄い」と notes に書いたが、顔布の中央にも同じ強さの傷が入っている。
3. **袖が「複葉機の翼」のまま**（tsugi-final-face 全身、silhouette-hires 上段）。袖口の茜の棒と水平の板で、「たたんだ布」より機体に見える。シルエットとして読めるのは長所だが、「かわいい／ぬいぐるみとして手元に置きたい」より「記号」に寄る。袖に少しのたるみ（上下に数度の傾き、波打ち）を手で付ける余地がある。
4. **つづらの足場の影**は沈めて落とした（良い）が、**ツギとイガの接地は貼り付いた楕円**に見え、規則（階段状）が適用されていない。
5. **ツギの足が小さい**（上記6）。
6. **イガの顔**（scene-hires、x≈740〜760, y≈530〜545）は、赤い目＋白い牙で敵らしく、ぬいぐるみにできる。ただしツギと並ぶと、敵のほうが質感が濃く、画面の主役が敵に寄る。背景より濃い刈安の背棘でよく目立つので、ツギの茜（主役）を強める方向で一段下げるのがよい（推奨）。

## 3. ツギの顔の新しい読み（review-4 §6 の3）

14倍と6倍の両方を見た。第三者として一言で答えるなら **「眠そう（半目）で、ちょっと得意げ」**。

- 良い: 茜のまぶたが水平で、黒い面にハイライトの点・斜めの光が無い。口は中央にあって、茜の弧は上がり、口角が穏やか。「不機嫌」「怖い」「生意気なニヤリ」は消えた。review-4 のブラインド（横縞）も無い。
- 問題1: **左右の目の形が違って見える**。左目は半月の面が大きく右へ傾き、右目は小さく下へ寄って見える。face-c-compare の右側（現行）では、左右で目の高さが少しずれ、**ウィンクに近い**。オーナーが選んだ C の骨格は半月の目だが、手置きの左右差は「眠い」でなく「片目だけ閉じている」と読まれる危険がある。左右の目の中心の高さを揃え、傾きの差を小さくする（顔の手作り感は眉と口の玉止めで十分に出る）。
- 問題2: 下まぶたの白い糸が**涙・目やにの跡**に見える。外側半分だけという規則のため、目の下に白い斜めの線が離れて残る。目の縁に近づけ、短くし、位置をまぶたの輪郭に沿わせる。
- 問題3: 顔の下半分の生成影（茶色の水平の帯）が、**口ひげ・無精ひげ**に見える。顔布の中央の帯は、帯でなく顎の周りだけのふくらみの影にする。
- 総合: 愛される顔かの点では、review-4 の「生意気」からは脱した。「眠そう」は、愛嬌として成立する。左右差とひげの帯を直せば 8.5 → 9 近くまで届く。

## 4. 愛される軸・ぬいぐるみにできるか

- ツギ: 作れる。頭巾・顔・胴・袖は布の面で分けられる。簪の頭の糸玉は縫い付ければよい。**ただし簪の針と輪は硬い芯が要る**（ワイヤー）ので、plush.md に「針金入り」と書いておくこと。袖の長さ（身体の約3倍）は綿を詰めると支えられず、芯入り（細い板）になる。これを plush.md に書かないと、ぬいぐるみ化できるか疑われる。
- イガ: 作れる。背棘は硬い布と芯。牙は刺繍。
- コナ: 作れる。三角の翼は薄い芯。
- 愛される軸の予想: 8.5 前後。review-4 と同じ。ツギの愛嬌は顔の「眠そう」で出たが、袖と足のシルエットがまだ記号寄り。

## 5. 直すこと（優先順）

1. **【必須】scene-hires の HUD 右上札の糸玉アイコンをピクトに落とす**。左上の札と同じ4倍ドット。確認: scene-hires の札の中に高解像度の陰影が1つも無いこと（目視、または札の矩形を切り出して色数を数え、パレット+中間色の数がピクト層と同じ）。
2. **【必須】tsugi-final-face の毛羽を「縁と縫い目に寄せ、中央は無地に近く」描き直す**。notes の座標表のとおり面ごとに向きを変え、かつ密度を縁にだけ置く。顔布の中央の横帯影は、顎の下とあごの合わせ目の周りだけの影にする。確認: 顔布の目と目の間・頬の中央が14倍で平らに読めること、顔の下の横帯が消えていること。
3. **【必須】顔 C の左右差を直す**: 左右の目の中心高さを揃え、傾きを近づける。下まぶたの白糸を、目の縁に沿った短い弧にする。確認: face-c-compare の新版で、14倍と6倍の両方で「ウィンク・泣いている」と読まれないこと（別セッションに一言で答えさせる。「眠そう／穏やか／得意げ」は可。「ウィンク・泣き・ひげ」は不可）。
4. **接地影**: ツギとイガの影を、notes の決定どおり階段状にして scene-hires に反映する。空中のツギの影は、真下の足場・地面に落とす（高いほど薄く、幅は狭く）。確認: scene-hires で足もとの影が段差状であること。
5. **ツギの足を一回り大きく**（実寸で幅1.5倍）。確認: silhouette-hires 下段で足が「立っている」重さに見えること。
6. 袖に少しのたるみ（微小な傾き・波）を入れる。
7. plush.md に、簪（針金）と袖（芯）の構造を書く。

## 6. 5回目で PASS にならない理由（短く）

review-4 の必須3つのうち、1（質感）と2（境界）は、文書だけが直って見本の絵が直っていない。
独立審査は、文書の約束でなく、見本の絵そのもので判定する。絵が直れば、次回は 9.0 を見込める。
