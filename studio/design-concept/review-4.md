# デザインコンセプト事前審査 4回目（独立レビュー）

対象: design-concept.md（改訂4）、review-3.md、notes.md（改訂4節）、hires/ の4枚（tsugi-final-face / scene-hires / silhouette-hires / tsugi-hires-options）、plush.md（目の節のみ）
物差し: (A) game-art-direction「AIが作った感」9/10。(B) Core「多くの人に愛される作品」＋ぬいぐるみにできること。
問い: 「このコンセプトと見本のまま作れば 9/10 に届くか」

## 判定: FAIL（このまま作った予想スコア 8.0 / 10）

内訳: 構想（2層、「触れる物は本物の布、触れない物はピクト」）は良く、review-3 の最大の穴だった「不機嫌な顔」も大きく動いた。
しかし見本の絵の仕上げが「AI が作った 3D 風ぬいぐるみ素材」の定番に寄っていて、混在解像度の境界も決めきれていない。
顔は C のまま（オーナー決定）で、仕上げだけを判定した。なお「愛される」軸は 8.5 前後で、review-3 の顔の問題は半分残っている。
review-3 の「必須1〜5」のうち顔以外（簪・袖・破線・足もと線・swatch）は、ぬいぐるみ層への移行で大半が別の問題に置き換わった。

## 1. 混在解像度は「意図したギャップ」か「安っぽい」か

判定: **意図したギャップとしては成立するが、境界の規則が見本の中で守られておらず、このままだと安っぽい側に倒れる。**

良い点: scene-hires のイガ・コナは、フラットな型染めの世界に置かれた実物の布として読める。ツギの茜と袖口が背景から浮く。ギャップは「触れる物＝本物」という遊びの読みやすさにも効いている。

問題（場所つき）:
1. **境界が一貫していない（最大）**。
   - 左上の HUD 札（「1-1 ♥♥♥」）は 4倍ドットのまま。右上の札は、札と数字はドットなのに、左端の糸玉の絵だけが高解像度のぬいぐるみ。1枚の札の中で2つの解像度が混ざっている。
   - 糸玉（空中の3つ）、つづら、ばね、ツギの簪の輪は高解像度。一方、つづらが乗る足場の布、地面の縫い目、洗濯ばさみ、反物はドット。つづらは「背景の足場に乗った物体」で、足場との境が1か所で急に切り替わる。
   - notes は「触れる物もぬいぐるみ層へ移した」としているが、scene-hires は notes の旧段落（小物はドットのまま）と食い違う。どちらが決定か書かれていない。
   - 直す: 規則を1行にして守る。「触れる・取れる・当たるものは全部ぬいぐるみ層。HUD の札は（札自体は触れないのでピクト）、札の中のアイコンもピクトに落とす、またはHUD 全体を第3の層として扱うと決めて全部ぬいぐるみにする」。足場・地面の耳は背景（触れない）。
2. **背景に影が落ちない**。ツギ・イガの足もとの接地影は薄い楕円で、ピクトの地面に「貼った」ように見える。ツギは空中で、影は x≈380 付近に薄く出るだけで、足場・地面との高さ関係を示さない。notes のリスク(2)「背景に影を落とさない」と書いてあるが、実際は 2 層の間の接点がここだけなので、接地影の色・形（藍濃の半透明、ピクトの段差に合わせた階段状のふち）を決めておく。
3. **ピクセルスナップが未決**。キャラを 1論理画素=4px に揃えるか、サブピクセルで動かすかが書かれたまま。サブピクセルだと、4倍ドットの背景の上で滑らかに動くぬいが「別のゲームを重ねた」感じになる。決めてから実装に入ること。
4. 背景ドット面の「ガタガタした拡大」を 1280x720 で見ると、ぬいぐるみの滑らかな縁と並んで、背景の階段状の縁（反物の下端の房、七宝の面）が相対的に粗く見える。意図としては良いが、背景の文様は今より少し大きく、少なく（密度を下げる）して「粗い」ではなく「平ら」に読ませる。

## 2. ぬいぐるみの質感は「AI 生成の 3D 風ストック」に寄っていないか

判定: **寄っている。AI っぽさの最大の源はここ（このまま作ると 8.0 止まり）。**

具体的な所:
- **全面に同じ密度の細い斜め傷（毛羽）**: tsugi-final-face の顔布と頭巾、袖の布に、同じ太さ・向きの細い引っかき線が一様にかかっている。実物のちりめん・ブロードの「しぼ」や綿の「毛羽」は、面ごとに向きが違い、縫い目と縁に寄る。ここは「ノイズを全面にかけた」見え方で、AI の生成画像によくある質感。
- **影が全部同じ柔らかいグラデーション**: 顔の下半分の生成影、袖と頭巾の縁の暗い内影、すべて同じ太さの内影＋ぼかし。「ふくらみの陰」が一様で、布がたるむ・縫い縮めで寄る方向（design-concept §2 の放射状のしわ）が見えない。顔布の縫い代・合わせ目が無い。
- **「光沢のあるプラスチックのパーツ」感**: 頭巾の茜と藍の面、糸玉、簪の針に、同じ白い細い反射線が走る。糸の艶は「糸の向きに沿う」と書いたのに、簪の針と袖口は1本の白い斜めハイライトで、金属・プラスチックに見える。
- **口と眉は、ベクターの丸い線のまま**: 顔の茜の眉2本と口（消炭の斜めの一文字）は、太さが均一で縫い目の針目が無い。刺繍と言うなら、サテンステッチの密な糸の筋（短い糸の並び）が要る。眉は糸のたるみ・玉止めがあれば人の手になる。
- **袖が飛行機の翼**: 6倍の全身で、袖は水平な長い板（茜の袖口＋刺し子の十字3つ）。体が小さく、袖が長く、まっすぐ。縫い目の十字も等間隔。悪くはないが、「布をたたんだ四角」より「複葉機」「十字架」に見える。シルエット（silhouette-hires 上段左）でも、袖の板と頭の丸＋簪でキャラは読めるが、「かわいい」より「記号」。
- 解決の方向: 質感の AI っぽさは、細部を足すのでなく**手置きの不均一さ**で消す。縫い目の位置・針目・玉止め・合わせ目の「ずれ」・綿の片寄りを、notes.md に座標で決める（改訂3の「手置き」ルールをぬいぐるみ層にも引き継ぐ）。

## 3. ツギの顔（C 半月の目）の「仕上げ」

方針は再議論しない。仕上げだけを判定する。

- 良い: 茜のまぶたが水平。ハイライトの点が無い。口角が上がる。review-3 の「眉をひそめた不機嫌」「目の下のクマ」はほぼ消えた。
- 問題1（最大）: **目が「ブラインド」に見える**。半月の黒い面に横縞（糸の艶の帯）が強く入り、細い横線の束に見える。14倍では「サングラス」「スモークのシャッター」に見える。2針の口が斜めの一文字（左下がりで右が上がる）で、**ニヤリ・得意げ・生意気**に読む。review-3 §2-1 で挙げた「愛嬌＝ベビースキーマ」が、C では表情の癖（半目＋片側に上がる口）で別方向に出ている。**かわいい子ではなく「ちょっと生意気な子」**。ぬいぐるみとして手元に置く顔かの確認が弱い。
- 問題2: 口が顔の中心より右に寄る。目の間から口までが近く、顔の下半分が空いて見える。口の位置を中心に、2針の傾きを水平に近く（上がりをわずかに）する。
- 問題3: 下まぶたの生成影の弧は、等倍（6倍の全身）では見えない。サングラス対策として効いていない。目の幅をあと 10% 広げるか、艶の帯を細く（本数を減らして、1〜2本）する。
- 問題4: **顔の下端と衿**（review-3 §2-2）は解決: 顎の下に生成りの首が出て、茜の逆三角が口に見えなくなった。残す。
- オーナーが選んだ C を、plush.md が「横1.1cm×縦0.6cm」と書き、concept §3 が同値。notes は「幅1.15×高さ約1.8論理画素」と書き、約18×14px で、plush.md の縦横比（0.55）と notes（約0.78）が合わない。数値を1つにそろえる。

## 4. 遊んでの読みやすさ（シルエットとコントラスト）

- シルエット: silhouette-hires の上段（約130px）で、ツギ・イガ・コナは互いに別物として読める。下段（約32px）でも、ツギ（水平の袖と簪）は読める。イガの背棘3本＋尻尾、コナの三角の翼は残す。
- ただしツギの下段は「頭＋細い横棒」で、足が小さくて接地が弱い。足を一回り大きく（実寸で幅 1.5倍）、足もとのシルエットに「立っている」重さを出す。
- コントラスト: ツギの顔と茜の胴は背景の藍濃から浮く（良い）。袖は藍淡→藍濃にしたので、背景の藍濃と近く、**袖が背景に溶けて、袖口の茜の棒だけが浮く**。袖の表を背景より少しだけ明るく（藍の明 #4f78a6 側）すること、または縁に生成りの抜け線（意味のある所だけ）を戻す。
- 敵: イガ（刈安の背棘＋暗い胴）は地面（藍濃）の上でよく見える。コナは赤い反物の前に重なると茜濃に埋もれる位置がある（右上、x≈880,y≈230）。コナと茜濃の反物を重ねない配置規則を追加する。
- 糸玉（集める物）は刈安で、背景の刈安の反物（左、右）と同色で重なる箇所がある。集める物は背景の刈安の面の前に置かない、またはぬいぐるみ層に抜け線の縁を付ける。

## 5. 直すこと（優先順）

1. **【必須】質感を「全面ノイズ・同じ内影・白い反射線」から手置きの布に変える**。毛羽は布の面ごとに向きを変え、縫い目と縁に寄せる。合わせ目・縫い代・玉止め・綿の片寄りを座標で決める。艶は糸の向きの帯だけにし、簪の針の白い斜め線を消す。見本（tsugi-final-face、scene-hires）を作り直す。
2. **【必須】2層の境界の規則を1行で決めて、見本全体に適用する**。「触れる・取れる・当たる物＝ぬいぐるみ層、触れない物（地形・背景・HUD の札）＝ピクト」。HUD の札の中のアイコン（右上の糸玉）をピクトに揃えるか、HUD ごと決める。notes.md の旧段落（小物はドットのまま）を消す。
3. **【必須】顔 C の仕上げ**: 目の艶の帯を1〜2本に減らす、口を中央寄りで傾きを弱くする、眉・口を縫い目の糸の筋にする（均一な線をやめる）、下まぶたの線が等倍で見えるようにする。確認: 顔の等倍（6倍全身）で「ブラインド・サングラス・ニヤリ」に見えない。plush.md の目の縦横比と notes の数値をそろえる。
4. 接地影・ピクセルスナップを決める（実装前に1行ずつ）。影は藍濃の半透明で、背景の段差に合わせて切る。スナップは「キャラは4pxに揃える（動きは1論理画素ずつ）」を推奨（背景と同じリズムになる）。
5. 袖の背景との分離（藍の明 #4f78a6 側へ）、コナと茜濃の重なり、糸玉と刈安の反物の重なりを避ける配置規則を足す。
6. ツギの足を一回り大きく、袖の十字の針目を等間隔でなくす。
7. 背景ピクト層の文様は、密度を下げ「平ら」に見せる（粗さに見えないように）。

## 6. 直ったことの確認方法（PM / 機械）

- 1: 新しい tsugi-final-face の顔布・頭巾・袖に、毛羽の向きが面ごとに違う（3面以上で違う）こと。簪の針に白い斜め線が無いこと。notes.md に座標つきの手置き表があること。
- 2: design-concept.md §1.6 に境界の規則が1行で書かれ、scene-hires の HUD 札と notes が一致すること（Grep「小物をドットのまま」が notes に残っていない）。
- 3: 顔の等倍で第三者（または別セッション）に「不機嫌・眠そう・生意気・怖い」のうちどれに見えるか一言聞く。plush.md と notes の目の寸法が同じこと。
- 4: design-concept.md に「接地影」「スナップ」の決定が書かれていること。
- 5〜7: scene-hires を出し直して、袖・コナ・糸玉が背景から読めること。

## 7. 良かった点（修正で壊さない）

- 2層の考え方（触れる物は本物の布、触れない物はピクト）と、背景の型染め（干し場、七宝・青海波・矢絣、ツギ周りの藍濃）。
- 茜がいちばん強い赤で、ツギの茜と袖口が背景から読める。
- 顔 C の骨格: 水平の茜のまぶた、ハイライトの点が無い、口角が上がる、生成りの首で茜の逆三角が口に見えない。
- シルエット: ツギ（水平の袖＋簪の輪）、イガ（背棘3本＋尻尾）、コナ（三角の翼）は 32px でも別物。
- イガ・コナのぬいぐるみ化は愛嬌があり、背景との「ギャップ」が最も上手くいった所。
- 六色の色相を守り、新しい色相を足さない規則。

## 8. PASS になった場合に実装が守る条件（次回以降の参考）

- 描画は2層: 背景＝320x180 を整数倍（最近傍）、キャラ・触れる物＝1280x720 の別キャンバス。カメラ・当たり判定は論理座標（16px マス、足もと 12x24）のまま、描画だけを分ける。
- ピクセルスナップ・接地影・HUD の層の決定を実装メモに残す。
- ぬいぐるみ層はパーツ（頭・袖・胴・脚）の事前レンダリング＋リグ。走り2〜4コマ・跳び・着地・踏まれ・顔の表情6種を、1キャラ数十枚以内（200x180 前後）に収める。質感テクスチャは共有してメモリを抑える。
- 色相は6色のまま、陰影の中間色は design-concept §4 の範囲だけ。

## 9. 5回目の通過条件

- 上の必須1〜3が直り、tsugi-final-face と scene-hires が作り直されている。
- 「このまま作れば 9/10 か」に対し、質感が手置きに見え、境界の規則が見本で守られ、顔の等倍で「生意気・ブラインド」に見えない。これで 9.0 を見込む。
