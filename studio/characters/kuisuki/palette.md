# 虫食いのクイスキ パレット（10色）
| 名前 | hex | 使う所 | 実在する染め・材 |
|---|---|---|---|
| 錆浅葱 | #5f7773 | 外套・頭巾 | 浅葱を錆びさせた青緑 |
| 焦茶 | #4a3326 | 虫食い穴の縁 | 焦げ茶（柿渋の重ね） |
| 練色 | #ead7ae | 顔・手・足 | 練った生糸 |
| 芥子 | #d39a22 | 目 | からし色 |
| 茜 | #b8372b | 糸くず・頭巾の印 | 茜染め |
| 白練 | #fbf8ef | 食べている糸・歯 | 練った絹糸 |
| 藍 | #26426b | 戦利品の絣 | 本藍染め |
| 萌黄 | #8fa23f | 戦利品の市松 | 藍と刈安 |
| 栗 | #b98550 | 糸巻き | 栗の木地 |
| 墨 | #2b2420 | 輪郭 | 松煙墨 |
- 補助: 灰浅葱 #93aaa4（頭巾の縫い目）。
- 黒幕なのに黒・紫を使わない（定番の悪役配色を避ける）。冷たい青緑は、暖色が多い島の中で一目で「外から来た者」に見える。
- 戦利品の藍・萌黄は、これまで食べた島の布（ツギ・ヌイばあの色）。
