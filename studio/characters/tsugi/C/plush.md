# C案 ぬいぐるみ（高さ20cm）
型紙の分け方（11枚）:
1. 顔布（頭の前面）: 生成り綿布。2. 頭巾（頭の上半分）: 藍縞の綿、境はピンキングばさみで裁ち、運針で縫い付け。3. 頭の後ろ: 頭巾布。
4. 髷: 芥子色の毛糸を丸巻き（直径4cm）。5. 簪: 縫い針は実物ではなく、ワイヤー入り生成りの細いフェルト棒（長さ6cm・太さ6mm。針先は丸める）＋茜の糸（針穴から）。
6. 胴: 茜の更紗柄の綿1枚＋打ち合わせの生成り衿（別布）。7. 帯: 芥子のフェルト、巻いて縫う。
8. 袖×2: 藍絣の綿布、長方形（10×14cm）の二重袋。中に薄いキルト芯。手は袖の中なので手の型紙なし。
9. 足×2: 生成りの足袋布の短い筒＋藍フェルトの草履底。
素材: 綿（絣・更紗・縞）、フェルト（帯・草履）、毛糸（髷）。頭と胴は綿を詰める。袖は軽く詰めてはためきのシワを出す。
刺繍: 目は黒の刺繍糸で楕円を埋めサテンステッチ（縦1.1cm×0.8cm）、ハイライトは生成りの1針。眉は短い2針。口は黒1本取りのバックステッチ。頬は茜の3本ステッチ。
確認: 最も細い所は簪（6mm・安全のため糸巻きのフェルト芯、針先は丸め）。縫えない所は無し。針は子ども向けでは外して刺繍の印に差し替え可。袖の下端は丸い角（半径1.5cm）にして縫いやすく。
