# C案 振袖の継ぎはぎ童子
- 性格: 口数は少ないが、袖いっぱいに感情が出る、ちいさな世話焼き。
- 狙い: 太い長方形の袖が両腕で、走ると流れ、跳ぶと翼になる。正面でも動きでも「藍の四角い袖＋髷に刺さった針」で判別できる。端切れ（絣・更紗・縞）ごとに部位を分け、継ぎ目に白い運針。手は袖の中に隠れ、針は武器でなく簪（髷の飾り）。
- 印: 芥子の糸の髷に刺さった縫い針と、針穴から出る茜の糸。
- 似ているものとの違い（similarity.md 照合）:
  - リビッツ: 麻布・ジッパー・丸頭でない。頭は横長のおまんじゅう型、素材は和の端切れ、ジッパー無し。
  - 毛糸のカービィ/ヨッシー: 毛糸の線や編み目は使わない（髷の糸玉のみ）。
  - Sally/Coraline: ボタン目・×口は不使用。目は黒の楕円刺繍、口は小さな弧。配色も明るく、暗い継ぎはぎ全身ではない。
  - 靴下猿・Jellycat系: 赤い口縁取り無し、手足は短い丸でなく四角い袖と足袋、配色は藍と茜。
  - Ryn: 針は武器でなく髪飾り。
- 懸念: 「和の継ぎはぎ童子」は日本の郷土玩具・キャラ（ゆるキャラ）と近づく恐れ。顔は大きい楕円目で一般的なため、実際の公開前に類似確認を。袖が大きく足が短いので、ドット絵では胴が袖に隠れやすい。
