# A案 パレット（5色）

| 名前 | hex | 使う所 |
|---|---|---|
| 茜（あかね） | #b8372b | 頭巾・胴・手足。主役の色。ゲーム内の茜と同じ |
| 生成り（きなり） | #f0e6cf | 顔布・針・当て布の縫い目 |
| 藍（あい） | #26426b | 胴の当て布（四角い継ぎ） |
| 墨（すみ） | #2b2420 | 輪郭・刺繍（目・眉・口） |
| 芥子（からし） | #d39a22 | 角の先の糸の房・針の糸（「印」） |

- 茜の陰（折り目）は 墨 を 10〜13% 重ねて作る（別色にしない）。ドット絵だけ陰用に #8f2a21 を1色足す（sprite.json は6色）。
- 地面の藍・若草とぶつからないよう、ツギの茜は輪郭の墨で必ず囲む。
- 色覚多様性: 茜と若草は明るさが近いので、境は墨の輪郭と形（三角頭巾）で区別する。
