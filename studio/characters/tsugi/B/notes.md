# B案 巾着袋の子 ノート
- 性格: 慎重で心配性だが、一針ずつ確かに進む。気持ちが紐の玉に出る（浮かれると跳ねる、困ると絡まる、眠いと垂れる）。
- 狙い: 印は「口紐の玉2つ＋ピンキングのフリル」。下ぶくれで底が平らな重心の低い雫型は、丸胴のぬい群とも2.5頭身の袋人形とも別の輪郭。ドット絵でも「頭の房＋左右の玉」で読める。顔は大きな刺繍の目、1本線の口、頬の絣。縮緬のしぼ（ざらつき）と輪郭の揺れで手仕事感を出した。
- 針は杖。武器にしない（Ryn系を避ける）。糸は針穴から芥子色で出ている。
- 似ているものとの違い: リビッツ（麻布・ジッパー・丸い大頭）と違い素材は縮緬、頭がなく袋の口が頭。毛糸のカービィ・ヨッシーとは違い、毛糸線の輪郭なし。ボタン目・×口なし（Coraline系回避）。点目の量産ぬいと違い大きな白目。靴下猿とは口の赤・素材が違う。多色パッチなし（背中の当て布1枚のみ＝「継ぎ」の名前の印）。
- 弱み: 袋＋玉飾りは「福袋・お守り」連想で和風の既存意匠と近づく可能性。年齢の低い読者には顔が大人びるかも。腕が短く操作表現の幅は小さい。
- 注意: 2.3頭身より「袋全体が頭」に見えるため、ゲームでは歩きで袋が揺れる動きを足す。
