# ツギ 決定版 notes
- 性格: 口数は少ないが、袖いっぱいに感情が出る、ちいさな世話焼き。ヌイばあを助けに行く、最後に縫われた端切れ人形。
- 印: 髷（芥子の糸玉）に刺さった縫い針と、針穴から出る茜の糸。針は武器でなく簪。袖の「藍の板＋茜の折り返し＋生成りの裏地」。
- デザインの狙い: 一枚布で縫い上げた振袖の子。正面は「大きな茜の胴と左右の藍の袖」、横は「細い帯のような袖と針」、後ろは「生成りの裏地の袖と芥子の蝶結び」で、どの方向からも判別できる。袖が腕で、走ると流れ、跳ぶと翼になる。3DCG化の基準は `turnaround.png` と `structure.md`。
- C案からの変更点（review.md の直しを反映）
  1. 袖: 裏地を生成り、袖口の折り返しを茜に。ドットでも袖口の茜と内縁の生成りで、地面の藍から浮く。滑空のときは裏地側が見える。
  2. 胴の茜を大きく: 袖を細く（片側15.5）、胴を広げて茜が主役の面積に。ゲーム内でも胴は袖に隠れない。
  3. 針: 髷の上へ長く出し、先に針穴の輪をつけ、黒塗りでも穴が抜ける。頭の輪郭から外へ22以上出る。
  4. 顔の定型を外す: 頬の赤は片側の縫い目1か所だけ。目は楕円でなく縦の俵形の刺繍（糸の向きが見える）。まゆは2針の縫い目。
  5. 柄を3種から2種に: 絣（袖・頭巾）と更紗（胴）。頭巾の縞は絣に統合。
  6. 肩を高く、足を短く太く（足袋と草履に厚み）。色は6色に整理し、縹を草履と絣の差し色に。
  7. 頭巾は縁をギザギザ（ピンキング）にして後ろへ結びたれ、帯は背中に蝶結び。後ろ姿でも個性が出る。
- 類似照合（`similarity.md`）: ボタン目・×口・ジッパー・毛糸の線・麻布は不使用。針は武器でなく簪（Rynと別）。郷土玩具・和装のゆるキャラ連想は残るため、公開前に類似確認（J-PlatPat）が必要。
- 自己採点（AIが作った感）: 7/10。人の手の跡は、線の揺れ、版ずれ（塗りを0.5ずらす）、運針の縫い目、絣の十字の不揃いで入れた。残る減点は顔の目の形がまだ可愛い系の定型に近い点と、横向きの頭巾の生え際の斜めが機械的に見える点。
- 作図: 設定画は `tools/` の生成スクリプト（lib.mjs が寸法と描画。作業ディレクトリで node build_*.mjs）（パラメトリックな3D射影）から出力。同じ寸法で6方向を描いたので矛盾しない。ファイル一覧: turnaround.svg/png、sheet.svg/png、silhouette.png/svg、portrait*.png（透過、720x830）、sprite.json、sprite-preview.png。
