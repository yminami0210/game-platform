# ツギ 3D化のための部品構造（決定版）

基準画像: `turnaround.png`（正面・斜め前・横・斜め後ろ・後ろ・真上）。描画に使った寸法は全高=100の単位で、設定画の横線ガイドと一致する。右手系ではなく「x右・y下・z手前（正面）」で書く。

幅・奥行（楕円体・箱の半径）

## 2. 部品構造（親→子。名前は3Dのノード名にそのまま使える）
```
root（足の間の地面）
└ hips（y=88）
  ├ leg_L / leg_R : 足袋（生成り・円柱＋つま先の丸み）、草履（藍の底＋縹の面＋茜の鼻緒）
  └ spine（y=70）
    └ torso : 胴（茜の更紗）＋ 衿（生成り・V字）
      ├ obi : 帯（芥子・運針の線）、obi_bow : 蝶結び＋たれ2（背中）
      ├ sleeve_L / sleeve_R（袖。肩 y=49 が支点）
      │   ├ sleeve_outer : 表（藍の絣）　※外向きの面
      │   ├ sleeve_cuff  : 袖口の折り返し（茜、高さ8.5。表側に折り上げる）
      │   └ sleeve_lining: 裏地（生成り、縁に藍の表布1.6のぞく、すそは茜）
      └ neck（y=47）
        └ head : 顔布（生成り。顔の面・縫い代の線）
          ├ zukin : 頭巾（藍の絣。顔の生え際はギザギザ=ピンキング。生え際は前 y=21、うしろ y=38）
          │   ├ zukin_hem : 頭巾の縁（ギザギザ部分。揺れ物）
          │   └ zukin_tie_L/R : 後ろの結びたれ（幅3.6・長さ11。揺れ物）
          ├ face : 目×2（縦の俵形、刺繍）、まゆ（2針×2）、口、頬の縫い目（片側だけ）
          └ mage : 髷の糸玉（芥子、直径14、頭の上・やや後ろ z=-2.5）
              ├ needle : 縫い針（髷を貫く。長い側33＝上・後ろ・右に傾く、短い側9.5＝前下。太さ2.4）
              │   └ needle_eye : 針穴（輪、長径9）
              ├ thread : 針穴の糸（茜、長さ約25、先は2本にほつれる）
              └ mage_strand : 髷から垂れる糸の端（芥子、長さ6）
```
針の向き（単位ベクトル）: (x +0.62, 上 0.62, z -0.48)。正面では右上、横では後ろ上、後ろでは画面の左上、真上では右奥へ向く。どの方向から見ても頭の輪郭の外に出て、先の輪が見える。

## 3. 揺れ物の動かし方と骨
| 揺れ物 | 骨の目安 | 動き方 |
|---|---|---|
| 袖（左右） | 各3本: shoulder（肩、回転は3軸）→ mid（y=66）→ tip（y=83）。板なのでボーンの間は曲げ。物理は mid と tip に | 走る: 風上側が後ろへ60〜80度流れる。跳ぶ・滑空: 肩を外・上へ100度まで開き、先端がはためく（上下±12度、周期0.25〜0.4秒）。着地: 先端が0.15秒遅れて落ちる。からだが止まるとゆっくり元の位置へ |
| 針穴の糸 | 4本: 針穴 → 3節（各約8）。先端は自由。重力＋風 | 感情で先端の向きが変わる（笑う=はずむ、困る=だらり、怒る=ぴんと立つ）。走ると後ろへまっすぐ流れる。針（剛体）は頭に固定で揺らさない |
| 頭巾の縁 | 縁に沿って片側3本のごく短い骨（またはシェイプキー）。結びたれは各2本 | 走るとたれが後ろへ。ジャンプの着地で縁が1回だけ波打つ。ギザギザは動かしすぎない（±1.5） |
| 髷の糸の端 | 1〜2本 | 頭の動きに遅れて揺れる |
| 帯の蝶結び | 1〜2本のオプション | たれだけが小さく揺れる |
- 針・髷・顔は頭の剛体に固定。表情は目のパーツの差し替えかシェイプキー（6種: ふつう・笑う・驚く・困る・怒る・眠い）で切り替える（`sheet.png`）。
- 腕と手はない（袖の中）。ジャンプ・滑空は袖の回転で表す。足は上下とスライドのみで、指はない。

## 4. シルエットの基準
`silhouette.png`（正面・横・ジャンプの黒塗り。`silhouette.svg` は同じ図のベクター）。3Dモデルを同じ視点・同じ高さで黒塗りしたとき、次が重なること。
- 正面: 頭＝大きなまんじゅう、肩の左右に袖の長方形（幅15.5ずつ、胴より下まで）、髷の上から針が右上へ長く出て先に輪、糸が垂れる。袖の外端は x=±31（頭の幅±20より外）
- 横: 袖は細い帯、胴は細く、背中の帯の結び（厚み5）が出っ張る。針は後ろへ傾いて頭の輪郭の外へ
- ジャンプ: 袖が左右に水平〜やや上へ張り出して全幅が全高の約1.2倍。針の先の輪と糸が頭の上に離れて見える
- 針が頭に溶けるのを防ぐ数値: 針の太さ2.4・髷から頭の輪郭の外までの露出長さ 22以上・先の輪の長径9（黒塗りで穴が抜ける）

## 5. 3Dで守る質感
- 平らな布の継ぎはぎ。素材は和の端切れ（絣・更紗）。頭巾と袖の絣は十字の織り柄、胴は更紗の小花（芥子）。柄は2種（絣・更紗）まで
- 縫い目（運針の点線）は生成り。頭巾の縁、袖口の折り返し、帯の中央、裾に入れる
- 輪郭の墨線は、3Dではトゥーン用のアウトライン（太さは全高の1.5%）にして、版ずれ（塗りを0.5%ずらす）をシェーダーで再現してもよい
