## A 三角頭巾の端切れ
1. AIが作った感: **4/10**。赤い三角頭巾＋白い顔布＋縦線の目は「赤ずきん/ノーム/ヘイホー（Shy Guy）」の複合に見える。決め要素が無く、手の跡も版ずれ程度。notes 自身が連想リスクを認めている。
2. キャラ感・シルエット: 三角頭＋垂れる角は黒塗りでも分かるが、「頭巾をかぶった小人」で止まる。胴が小さく頭巾が大きいので、体のキャラが立たない。針が斜め掛けで輪郭が散る。
3. ドット絵: 6コマとも頭巾が大きい塊で読みやすい。ただし顔が白い仮面のように見え、縦線の目は無表情に寄る。ゲーム内では房が3×3px級で、印が潰れやすい（ingame では房が市松の点に見える）。当て布の3×3pxも弱い。感情は房頼みだが、ゲーム内の小ささでは伝わらない。
4. ぬいぐるみ: 最も作りやすい（7枚、フェルト、茜1色）。ただし頭巾が大きく胴が小さいのでバランスが崩れやすく、角（先端1cm以上）の返しは手間。目の縦3本は5mm間隔で刺繍の限界に近い。
5. 類似リスク: **高**。赤ずきん・ノーム・ヘイホー・赤頭巾の忍者。similarity.md 禁止項には当たらないが、一般連想に負ける。
6. 7点にする直し:
   - 頭巾の形を替える（角を後ろに垂らす案は捨て、一枚布の「折り目・裁ち端」を輪郭に出す＝similarity 余白1）。三角頭巾＝小人帽の連想を切る。
   - 顔を「白い仮面」から外す。顔布の面積を減らして布の色に溶かすか、目を縦3本束から別の形に。
   - 房の大きさと色をゲーム内で読める大きさに（最低6×6px、芥子を2色にして動きを出す）。

## B 巾着袋の子
1. AIが作った感: **6/10**。題材（縮緬の巾着）から形を取り、口紐の玉・ピンキングのフリル・頬の絣と、物からの借り方に筋が通る。ここまでの3案で最も他と入れ替えにくい。減点は、白目＋黒目＋ハイライトの顔と、玉飾りの金が整いすぎて量産キャラの顔に寄ること。
2. キャラ感・シルエット: 3案で最強。下ぶくれの雫型＋口の房＋左右の玉＋長い針の杖は、黒塗りでも一目で分かる。「頭が無く袋全体が頭」という設計が新しい。弱みは腕が短く、動きの表現が小さいこと。
3. ドット絵: ingame（compare 内）では赤い塊と杖に見え、顔・玉がほとんど読めない。キャラ全体が小さい（brief の「大きく見せる」に未達の恐れ）。針の杖が細く、1pxの線で背景の電線・縫い線と紛れる。
4. ぬいぐるみ: 雫型の袋は立たせやすく、底に重りを入れる案もよい。フリルのピンキングは5mm以上に間引く、玉は二重縫い、針は布製、と配慮が具体的。ただし約9パーツで房3本は短く作る必要あり。口紐を実際に絞る機構は子ども向けでは締め付け事故の観点で固定にすべき（現状は「絞れる巾着」と書いてあり矛盾）。
5. 類似リスク: **中**。similarity.md の禁止項には当たらない。福袋・お守り・巾着キャラ・きんちゃくぶくろの擬人化（ぬいの市場に既に多い）、赤いトマト/ざくろに見える点が連想される。玉飾りの金＋赤は縁起物に寄る。
6. 7点にする直し:
   - ドット絵で袋の口の房と玉を大きく描き、顔を1段大きくする（顔の白目を最低5×5px）。杖は太くし、背景の線と色を変える。
   - 縁起物（福袋・お守り）に見えないよう、玉飾りを減らすか金一色にしない。「継ぎ」の印である背中の当て布を前から見えるようにし、ほつれ（糸が出る）要素を足す。
   - 手を短い三角でなく、感情が出る形に（袋の口の房や紐で動きを出す案を設定画に明記）。ぬいは口紐を固定と明記して plush.md の矛盾を直す。

## C 振袖の継ぎはぎ童子
1. AIが作った感: **6/10**。設定画の作り込み（絣・更紗・縞の柄分け、運針の縫い目、パレット表）は3案で最も人の手に見え、袖が翼になる動きの発想も良い。減点は、顔（大きな楕円目・頬のピンク・まんじゅう頭）が量産の「かわいい和風キャラ」の定型で、柄を3種盛った衣装が整理されすぎる点。茜の更紗の胴が小さく、主役の色が藍に負けている。
2. キャラ感・シルエット: 太い長方形の袖が両側に張り出す形は、正面でも跳躍でも独特。ただし黒塗りでは袖＋髷の塊で、顔と髷の針が潰れ、「着物の子」までしか分からない。印の「簪の針」は黒塗りで出ない。
3. ドット絵: ingame では袖の藍が背景の藍の地面と近く、跳躍中は翼として読めて良いが、地面に立つと藍同士で溶けるおそれ（背景の地面も藍）。胴が袖に隠れる（notes の懸念どおり）。顔の白と髷の芥子は読みやすい。7色と多めだが読める。
4. ぬいぐるみ: 11パーツと最多で、柄布3種の調達と型紙が重い。簪（6mm）は安全上外せる前提で、印が失われる。袖は二重袋で軽く詰めるので縫えるが、手が無いぬいは抱きやすい一方、袖の自重で垂れる。目の刺繍（縦1.1cm）は十分大きく、顔は3案で最も刺繍向き。
5. 類似リスク: **中**。郷土玩具・こけし・日本のゆるキャラ、「ちびまる子」系の和装の子、座敷わらしの連想。ゲーム内に既存の布人形（リビッツ等）との直接類似は低い。
6. 7点にする直し:
   - 袖の藍を地面の藍から切り離す（ステージ側に明るい下地を足すか、袖の裏を茜か生成りにして、ドットでは袖を2色に）。茜の胴を大きく、主役の色を茜1か所に集める。
   - 顔を定型から外す（頬の赤を消すか1つに、目の形を楕円から縫い目の特徴ある形へ）。柄は3種から2種に絞る。
   - 黒塗りで「針の簪」を出す（簪を長く、頭の輪郭から飛び出させる）。ドットでは髷の針を最低3px幅の塊で。

## 推薦順位
1. **C**: キャラ感・表情の幅・ゲーム内の動き（袖が翼）が揃い、ぬいぐるみの顔も作りやすい。ドット絵での藍同士の溶けは直せる範囲。
2. **B**: シルエットの強さと新しさは一番。ただしゲーム内で顔が読めず、縁起物連想と、口紐の矛盾を直す必要。ドット絵の拡大が間に合えば C と入れ替わり得る。
3. **A**: 連想が強く（赤ずきん/ノーム/ヘイホー）、決め手が無い。採るなら形から作り直し。

最後に: 全案、設定画は AIが作った感の閾値（7）に届かないので、オーナーに見せる前に各案の直しを入れたい。オーナーが今のまま選ぶ場合は C か B。商標・意匠の確認（J-PlatPat）は要確認のまま。
