# ヌイばあ パレット（染め色10）
| 名前 | hex | 使う所 | 実在する染め・材 |
|---|---|---|---|
| 藤鼠 | #8a7fa3 | 羽織（縞）・左袖 | 藤染めを灰がけ |
| 萌黄 | #8fa23f | 羽織（市松）・右袖 | 藍と刈安の掛け合わせ |
| 薄柿 | #d9a07f | 着物・鼻 | 柿渋の薄染め |
| 藍 | #26426b | 継ぎ布・襟・袖口（ツギと同じ） | 本藍染め |
| 生成り | #f0e6cf | 顔・手・足袋 | 未晒しの木綿 |
| 白練 | #fbf8ef | 髪の糸・糸巻きの糸 | 練った絹糸 |
| 芥子 | #d39a22 | 巻き尺・鼻緒 | からし色（ツギの帯と同じ） |
| 茜 | #b8372b | 縫い糸・頬・針山 | 茜染め（ツギの糸と同じ） |
| 栗 | #b98550 | 糸巻きの木 | 栗の木地 |
| 墨 | #2b2420 | 輪郭 | 松煙墨 |
- 補助: 銀鼠 #b4b1a6（指ぬき・針・草履）、薄水 #bcd3d4（眼鏡・汗）。
- ツギと共有する色は藍・生成り・芥子・茜・墨。ヌイばあ固有は藤鼠・萌黄・薄柿・白練・栗。縫い手から縫われた子に色が渡った、という関係。
- 色覚多様性: 萌黄=市松、藤鼠=縞、藍=十字絣、薄柿=水玉と、色が近くても柄で区別できる。
