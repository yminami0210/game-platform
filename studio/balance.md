# バランス設計: 赤壁1戦スライス

実体の試作: `studio/balance_prototype.mjs`（純関数）、検証: `studio/balance_sim.mjs`（`node studio/balance_sim.mjs --runs 3000`、約4分）。
実装先の想定: `game/src/core/battle.js`（makeScenario / makeReports / applySpy / resolveBattle）、定数は `game/src/data/balance.json`（下表のB.*）。乱数は `core/rng.js` のみ。

## 狙う体験（数値）
| 指標 | 目標 | 現状(3000戦) |
|---|---|---|
| 上達者/初心者 勝率比 (gates skillRatioMin 1.5) | >=1.5 | 3.91 (90.7% / 23.2%) |
| 中央値スコア比 / 平均スコア比 | >=1.5 | 2/1 = 2.0 / 2.03 |
| 初心者の最初の達成(score>=1, noviceReachMin 0.5) | >=50% | 77.4% |
| 運だけ(ランダム配置・原則)の勝率 | <=10% | 8.8% |
| 同配置・別シードの結果 | 似る | 揺らぎは±5%のみ(下記) |
| 1戦の長さ | 3〜5分 | 6ラウンド(再生約30〜60秒)+配置・読み |

スコア: 0=敗(本陣陥落 or 敵残>75%) / 1=善戦(本陣無事・敵残<=75%) / 2=勝利(敵残<=40%) / 3=完勝(敵残<=20%かつ自軍残>=50%)。勝=2以上。

## モデル
- 地形4: 山(hill)・谷(gorge)・川(river)・平地(plain)。兵科3: 歩(inf)・弓(arc)・騎(cav)。自軍 歩40/弓30/騎30=100、敵 歩50/弓40/騎30=120（劣勢）。
- 敵は兵科ごとに1ゾーンに布陣（重みは 山.15 谷.2 川.35 平.3、騎は川に入れない）。風は東/西 50%。
- 相性: 歩>騎>弓>歩 で x1.3、逆は x0.8。地形係数(攻撃側兵科):
  歩 山1.0 谷1.2 川0.9 平1.0 / 弓 山1.25 谷1.1 川1.1 平0.9 / 騎 山0.7 谷0.6 川0.5 平1.3
- 戦闘: 6ラウンド同時解決。同ゾーンで 与ダメ = 兵数 x k(0.22) x 相性 x 地形係数 x (1±0.05)、敵が複数なら等分。
- 敵だけがいるゾーン(自軍不在)は2ラウンド目から本陣に 兵数x0.12/ラウンド の被害（本陣HP40）。自軍だけのゾーンは遊兵（ダイジェストで「空振り」）。
- 介入: 3ラウンド目の頭に1部隊を別ゾーンへ移動可（この時点で敵位置が見える=報告ミスを一度だけ取り返せる）。

## 孫子の原則（2枠を選ぶ。条件を満たさないと効かない）
| 原則 | 条件 | 効果 | 外すと |
|---|---|---|---|
| 高所を先に占める | 山に自軍と敵が会敵 | 自軍攻撃x1.3・被ダメx0.85 | 山に敵不在なら遊兵 |
| 険所を先に占めて待つ | 谷で会敵 | 被ダメx0.65（騎は谷で更に弱い） | 同上 |
| 死地に追い込む | 敵のいるゾーンの退路(谷/川→平地、平地→山)にも自軍がいる | そのゾーンで自軍与ダメx1.5・敵攻撃x0.8 | 退路が空なら無効 |
| 火攻は風を読む | 弓がいる。3R目以降、川・平地 | 東風: 敵の川/平地部隊に毎R 10%、味方も5%。西風: 味方の川/平地が毎R 12%自滅 | 風を誤ると損 |
| 間者で敵情を知る | 報告1件を選ぶ | その報告(敵布陣1つ or 風)が確定の真実になる | 枠を1つ消費 |

## 斥候報告と見抜く腕
- 報告4件（歩・弓・騎の位置、風）。各報告に出所の手がかり 高(真92%)/中(70%)/低(35%)（出現 .3/.4/.3）。偽報は他ゾーン/逆風。
- 騎が川にいる等の「あり得ない報告」は偽と見抜ける(feasible=false)。
- 腕=報告の確率を重みづけて配置・火攻・間者の使いどころを決めること。初心者ボットは鵜呑み・相性無視・原則ランダム・介入なし。上達者は事後確率で配置全探索、不確かな報告に間者、介入を使う。
- 運の配分: 配置・原則・読み7〜8割、残りは報告の偽(真の不確実性)と±5%揺らぎ。同じ入力+同シードで完全再現。

## パラメータ（balance.json に外出し）
B.k=0.22 / B.noise=0.05 / B.rounds=6 / B.baseHp=40 / B.baseHit=0.12 / B.typeAdv=1.3 / B.typeDis=0.8 / B.terrain.* / B.high / B.choke / B.trap / B.fireEnemy=0.10 / B.fireSelf=0.05 / B.backfire=0.12 / B.fireFrom=2 / B.srcTrue / B.enemyCount / B.playerCount / B.enemyZoneWeight / B.windEast / スコア閾値(good .75, win .4, perfect .2/.5)。調整範囲は各値 ±30% を目安。

## イベント列（ダイジェスト再生用）
`events[]`: deploy / intervene / high_ground / choke / trap / clash{zone,p:[[type,残]],e} / base_hit{zone,dmg,baseHp} / fire / backfire / end{score,win,eLeft,pLeft,baseHp}。`reasons[]`（uncovered:ゾーン, idle:ゾーン, fire_backfire, fire_ok, trap:ゾーン, high, choke）が「孫子の言葉での解説」の元。

## 注意・懸念
- 上達者の勝率が90%超でやや高い。リリース時は敵増(歩60)か完勝閾値で調整。スライスの判定には十分。
- 上達者ボットは事後確率を使う(プレイヤーが学べる情報のみ)。「空振りしやすい」初心者(23%)は突き放しすぎではない(善戦77%)。
- 詰まり地点: 配置ミスでの敗北原因は uncovered/backfire に分散。要計測。
