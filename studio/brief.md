## ゲームを一言で
トモシムレ: 暗い洞窟を、ついてくるホタルの群れごと導いて進む。群れが大きいほど明るく高得点、でも大きいほど狭い隙間を抜けられない。

## コアループ（30秒）
左右ドラッグで群れを導く → はぐれホタルを拾う（明るく・倍率UP・幅が広がる）→ 岩の隙間 → 全員通すか端を犠牲にするか → 散っても また拾える → 奥へ（速く・狭く・罠）→ 0匹で終了 → 即もう一度

## 新規性の一点 / 熱中の仕掛け
- 群れの数 N が「視界・得点倍率・体の幅」を同時に動かす欲張りのジレンマ
- 惜しさ（端から数匹ずつ散る）/ 上達（幅読み・ルート選び）/ 積み上げ（到達層・ねむり花・図鑑・群れの色）

## 世界観の要点（world-bible より）
- トーン: やさしい・静か・少し神秘 / 避ける: 死・敵・倒す・全滅・ゲームオーバー、仕事語、急かし、課金・広告語、英語混じり
- ルールと世界の対応: スコア=ひかり、数が減る=散る/はぐれる（死なない）、0匹=光が静まる、成長=深い層へ、花=ねむり花を灯す
- 層: 1 あさせ（隙間のみ）/ 2 こけの道（風穴）/ 3 しずくの間（水たまり）/ 4 ねの森（根のカーテン）/ 5 ねむりの底（黒石）

## デザインの要点（design-system より）
- 色トークン: bg #07080F / cave #1E2236 / main(ホタル) #FFC94A / reward #7FE0D4 / danger #FF5A6E / text #F4F1EA
- 形: 丸=味方（ホタル・花）、尖る=罠。光は群れ重心の radial gradient で闇をくり抜く（半径は N で補間 0.3秒）
- タップ領域 44px 以上、ボタンは画面下半分。操作は画面全体のドラッグ。動き控えめ設定と prefers-reduced-motion 対応
- 点滅は毎秒3回以下（光過敏への配慮。legal）

## 数値の要点（balance より）
- r(N)=0.25+0.17√N / 倍率 m(N)=1+0.1(N−1) / 視界 R(N)=2.2+0.55√N / 開始 N=5、最大 40
- 速度 3.0→4.6（層1→5）、隙間 2.3→1.3、壁間隔 約9、層の長さ 80。層5以降は速度がじわじわ上がる
- 1ラン目安: 初心者 約30秒 / 上達者 60〜150秒。最初の小さな達成 = 100 ひかり

## 禁止事項
- core（game/src/core）で Math.random / Date / DOM を使わない。外部通信・外部フォント・外部素材ゼロ
- 既存作（SwarmLight、Count Masters 系、ホタルノニッキ）の名前・見た目・UI を寄せない。「世界初」等の表現をしない
- arcade/ に触らない
