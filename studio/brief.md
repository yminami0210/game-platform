## ゲームを一言で
三国志の軍師見習いとなり、孫子の兵法で地形に軍勢を配置して戦を重ね、中華統一を目指す。終えると兵法が身に付いている。

## コアループ（30秒〜1戦3〜5分）
軍議（地形・斥候報告を見る）→ 原則を2つ選ぶ → 兵科を地形へ配置 → ダイジェスト再生（3ラウンド目に介入1回）→ 解説（孫子の言葉）→ 次の戦／もう一度、軍議

## 新規性の一点 / 熱中の仕掛け
- 新規性: 孫子の原則そのものがルール。数値の強さ比べでなく読みと配置。
- 熱中: 惜しさ（原因が解説で分かる即リトライ）／上達（原則を覚えるほど少ない兵で勝つ）／積み上げ（兵法図鑑・統一地図）

## 世界観の要点（studio/world-bible.md）
- トーン: 史実の後漢末、重厚だが読みやすい日本語。残虐描写なし。
- 失敗=「読み違い」（死ではない）。成長=兵法の習得。勝利=統一地図が塗り替わる。
- 避ける: 現代語（スキル・ステータス・ターン・クリア等）、既存作の固有表現、課金・待ち時間の煽り。

## 確定した語彙（スライス範囲。world-bible §用語集 と同表記）
| 項目 | 表記 |
|---|---|
| 地形4種 | 山地・谷・江・平地（design の「森/平原/隘路」「葦原」は使わない。谷=隘路の役） |
| 兵科3種 | 歩兵・弓兵・騎兵（水軍は次段階） |
| 原則5つ | 高所を先に占める(地形篇)・険所を先に占めて待つ(地形篇)・死地に追い込む(九地)・火攻は風を読む(火攻)・用間(用間) |
| 画面/場面 | 軍議・斥候報告・信頼度(高/中/低)・配置・ダイジェスト・介入・解説・兵法図鑑・統一地図 |
- 内部コードの識別子は balance.md の hill/gorge/river/plain、inf/arc/cav を使い、**表示文字列だけ**上の表記にする。

## デザインの要点（studio/design-system.md）
- 色トークン: paper #F1E8D4 / ink #1F1B16 / vermilion #B5341F(敵・危険) / indigo #2F4A6B(味方・情報) / ochre #7A5C14(報酬) / moss #3E5B3A。新色は足さず濃淡は不透明度。
- 形: 味方=丸+藍、敵=尖り+朱、色だけに頼らない。地形はハッチで区別。
- 縦持ち 390x844 基準、主要操作は下半分、タップ 44px 以上。画像ファイルは使わずSVG/Canvasで描く。

## 数値の要点（studio/balance.md、純関数は studio/balance_prototype.mjs）
- 1戦: 6ラウンド、再生30〜60秒＋軍議。自軍100(歩40弓30騎30) vs 敵120。
- 3000戦の検証: 上達者90.7% / 初心者23.2% / 運だけ8.8%（比3.91）。
- 実装先: game/src/core/battle.js、定数は game/src/data/balance.json。乱数は core/rng.js のみ（同入力+同シードで完全再現）。
- 出力: events[]（ダイジェスト用）と reasons[]（解説用）。
