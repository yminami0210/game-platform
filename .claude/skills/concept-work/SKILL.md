# /concept-work — コンセプトのつくりかた

出典の要点は `docs/references/concept-no-tsukurikata.md`。相棒の過去の失敗（結論から逆算して論拠を並べる、スペックやテーマから入る、きれいな言葉に早くまとめる）を防ぐための手順。

## 原則
- 起点は「モノ」ではなく「体験」。誰が、どんな感情を抱き、周りとどう関わるかの光景から考える。
- 起点は市場データではなく、オーナーの「好き」と「違和感」。
- コンセプトは数字を除く20字程度。「良い」という言葉を入れない。何を用いて何をしたいかを言う。
- コンセプトは「やらないこと」を決める判断基準。やらないことを最低3つ決める。
- 発散中は結論に導かない。リーダー（相棒）の仕事は答えを出すことではなく、ズラすことだけ。

## 手順
1. **悪口を言う（すきになるあなた）**：その分野・業界・ライバル・自分たちへの不満、羨ましさ、違和感を素直に出す。きれいな言葉に直さない。
2. **ズラす（かわるあなた）**：負のオーラが強い悪口を選び、次の質問で付箋を増やす。結論は出さない。
   1. 逆に言うと／さらに突き詰めると
   2. それが絶対に避けられない真実だとしたら
   3. 立場をズラすと（友達・家族・同僚、する側／される側）
   4. 関係ない2つを無理矢理つなげると
   5. 自分も悪いことをしているとしたら
   6. 本音では／建前では
   7. 悪いこと2つを掛け合わせると
   8. 時期をズラすと（去年・来年・朝夜・死ぬ直前・100年後）
   9. ドラマ・小説・映画・アニメ・音楽に例えると
   - 業界の常識か自分の感覚か迷ったら、6つの力（供給業者・競合・新規参入・顧客・代替品・政府）に悪口をかけて原因を切り分ける。
3. **言葉の星座をつくる（わかるあなた）**：付箋を並べ、つながりから「未知の良さ」を見つけ、20字程度のコンセプトにする。
4. **物語をつくる（できるあなた）**：コンセプトを、体験の流れ（最初に触れた瞬間から使い終わるまで）の物語にする。やらないことリストを決める。
5. **影を乗り越える**：紙芝居や簡単な試作で体験を確かめ、コンセプトとズレた部分、体験が途切れる部分を削る。

## 進め方の分担
- 手順1・2は人格を分けたサブエージェント（互いの答えを見せない）で発散させてよい。オーナーの悪口・違和感が最優先の素材。
- 手順3以降でだけ収束させる。仕上がったら `/review-board` にかける。

## メンバー構成
同じモデルの分身は同じ盲点を持つ。違いは「役職」ではなく「その分野との距離」と「具体的な暮らし」でつくる。各メンバーには年齢・暮らし・最近の具体的な一日を与え、業界用語を禁じる。

| 段階 | メンバー | 役割 |
|---|---|---|
| 1 悪口 | オーナー本人 | 本物の「好き」と「違和感」。最優先の素材で、AIでは代わりにならない |
| 〃 | どっぷり浸かった人（ヘビーユーザー） | 慣れすぎて当たり前になった不満 |
| 〃 | 離れた人（昔やっていて、やめた人） | やめた理由。業界が見ないようにしている穴 |
| 〃 | 拒む人・巻き込まれる人（Wiiのお母さん役） | 自分は使わないが、迷惑や影響を受ける側の本音 |
| 〃 | 作り手・売り手（業界の内側） | 供給側の愚痴、やりたくてもできない事情 |
| 〃 | 隣の世界の人（代わりのもので満たしている人） | なぜこっちではなく、あっちを選んでいるか |
| 2 ズラす | 相棒（進行役） | 9つの質問を投げるだけ。答えも結論も出さない |
| 〃 | 段階1の全員＋遊び人 | 質問に答える。遊び人は現実味を無視して無理矢理つなげる |
| 3 星座 | 編集者 | 付箋のつながりを見つけ、20字程度の言葉にする |
| 4 物語 | 作り手 | 体験の流れを描き、「やらないこと」を決める。実現できるかを見る |
| 5 影 | `/review-board`（マーケ・副社長・プレイヤー） | 外から壊しにいく |

- 段階1は互いの答えを見せずに並列で出す。人数はオーナーを含めて5〜7人まで（それ以上は同じ声が増えるだけ）。
- 分野が決まったら、「拒む人・巻き込まれる人」を誰にするかを最初に決める。新しい価値はここから出やすい。
