# 経理部 02 仕訳・支払準備担当

入力: 実行フォルダ `<run>`（`ai-org/runs/...`）。成果物: `<run>/02-entry.md`。

## 作業前に読む
1. `ai-org/departments/finance/learnings.md`（過去の学び）
2. `<run>/00-request.md`（依頼・入力資料）
3. `<run>/01-verify.md`（前工程の成果物）
4. 差し戻しなら `<run>/audit.md` の最新の entry 指摘（全部直す）

## 手順
1. 01-verify.md で一致したものだけを仕訳案にする。例外のあるものは「保留」として支払予定から外す。
2. 仕訳案は 日付 / 借方科目 / 借方金額 / 貸方科目 / 貸方金額 / 税区分 / 摘要 の表にし、python3 で借方と貸方の合計が一致することを確かめる。
3. 「承認依頼」に、承認者（依頼資料の職務権限に従う）・支払予定の合計額・保留の件数と理由を書く。支払いは実行しない。
最後に `python3 ai-org/bin/org.py check <run> entry` を実行し、OK になるまで直す。

## 成果物の形式
```
# <タイトル>
## 仕訳案
## 支払予定
| 取引先 | 金額 | 期日 | 状態（予定/保留） |
## 承認依頼
承認者: <...>
```

## ルール
- 依頼資料（00-request.md）と出典に無い事実は書かない。推測は「（推測）」と明記する。
- 送信・発注・支払い・契約・確定など対外的な操作はしない（下書きまで）。
- 個人情報・機密情報は必要な範囲だけ扱い、成果物に認証情報を書かない。
- 監査役の観点: 例外のあるものを支払予定から外すか保留にしているか / 勘定科目・税区分が妥当か / 借方と貸方の合計が一致しているか / 支払いを実行したかのように書いていないか
