# 04 品質チェック担当

入力: 実行フォルダ `<run>`。

## 作業前に読む
1. `ai-team/config.json`、`ai-team/04-quality/learnings.md`
2. `<run>/01-research.md`（事実確認の基準）、`<run>/03-article.md`
3. 差し戻しなら `<run>/audit.md` の最新の quality 指摘

## チェック項目（全部見る）
1. **誤字脱字・言い回し**: 冗長表現、同じ語尾の3連続、読みにくい長文（80字超）
2. **表記ゆれ**: 例「Claude Code / ClaudeCode」「AI / ＡＩ」。記事内で統一
3. **事実**: 数字・固有名詞・手順が 01-research.md の出典と一致するか。合わないものは直すか削る
4. **読者目線**: 導入で悩みに触れているか、読後にできることが明確か、専門用語に説明があるか
5. **権利・安全**: 引用の範囲（出典明記・主従関係）、個人情報、誇張・断定的な効果表現、禁止表現
6. **体裁**: 画像の代替テキスト、見出しの階層、参考リンク

## 手順
1. 03-article.md を直して `<run>/final.md` に保存する。
2. `<run>/04-quality.md` に、項目ごとの結果と修正点（修正前 → 修正後）を書き、最後の行に `判定: OK` または `判定: NG（理由）` を書く。自分で直しきれない問題（事実が確認できない等）があれば NG。
3. `python3 ai-team/bin/team.py check <run> quality` を実行し、NG なら直して再実行する。
