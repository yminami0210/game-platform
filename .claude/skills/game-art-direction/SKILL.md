# ゲームの美術監督（game-art-direction）

**まず `.claude/skills/frontend-design/SKILL.md`（/frontend-design）を全部読む。** 以下はそれをゲームに当てはめる追加ルール。両方に従う。

## 1. 題材から決める（どのゲームにも同じ見た目を使わない）
企画の題材・舞台・素材から、実在する「物」や「場所」を1つ選び、そこから色・形・文字を借りる。
例: 駄菓子屋の包み紙 / 銭湯のタイル / 夏祭りの屋台の提灯 / 古い図鑑の挿絵 / 子どものクレヨン画 / 喫茶店のマッチ箱 / 謄写版（ガリ版）刷り / 海辺の色あせたパラソル / 鉄道の切符 / ブリキのおもちゃ
→ `plan.md` の `## 見た目と音` に「借りてくる物」「パレット（名前つき hex 4〜6色）」「フォント（役割つき）」「いちばん印象に残す1点」を書く。

## 2. 使わない（いまのAI生成デザインの定番）
- 紺〜黒の背景にネオンのピンク・水色・紫の点や光（「夜空に光る粒」系）
- クリーム色の背景（#F4F1EA 付近）＋テラコッタ（#D97757 付近）
- 黒背景＋蛍光グリーン1色、紫→青のグラデーション
- 全部同じ角丸カード＋薄い灰色の影、グラデーションの飾り
- 全大文字の小見出し、「A · B · C」の区切り、文字の末尾の「→」、小さな数字ラベルだけ等幅フォント
- system-ui / Arial / Roboto / Inter / 指定なしの sans-serif だけ。これらは**フォールバックとしてのみ**使う
- 「〜しよう！」「さあ、〜の世界へ」のような定型のあおり文句

## 3. フォント（Google Fonts を使ってよい）
- 読み込みは `<link href="https://fonts.googleapis.com/css2?family=...&display=swap" rel="stylesheet">` だけ許可（自動QAもこの2つのドメインは許可している）。**フォントが読めなくても遊べる**よう、フォールバックを必ず書く。
- 1本のゲームで最大2書体。見出し（ロゴ・スコア）と本文で役割を分ける。
- 日本語の候補（題材に合わせて選ぶ。毎回同じものにしない）: Dela Gothic One（太く力強い）/ RocknRoll One（丸く元気）/ Mochiy Pop One（ポップ）/ Hachi Maru Pop（手書き風の丸文字）/ Yusei Magic（マジック書き）/ Klee One（鉛筆の手書き）/ Kaisei Decol・Kaisei Opti（クラシック）/ Shippori Mincho（端正な明朝）/ DotGothic16（ドット）/ Zen Maru Gothic（やさしい丸ゴシック）/ Reggae One（筆の勢い）/ Stick（棒の文字）
- 英字だけの見出しなら: Bagel Fat One / Bowlby One / Fraunces / Bricolage Grotesque / Rubik Mono One / Silkscreen / Chango など
- スコアなど数字が動く所は `font-variant-numeric: tabular-nums`

## 4. 人の手を感じさせる
- 完全な円・直線だけにしない。線にわずかな揺れ（座標に ±1〜2px のノイズ）、図形の角にばらつき、版ずれ（色を1〜2pxずらして重ねる）
- 平らな塗りに紙の質感やざらつき（canvas で薄いノイズを1回描いて使い回す。毎フレーム作らない）
- 配色は「主役1色＋地の色＋墨（真っ黒ではない濃い色）」が基本。主役の色は1か所で強く使い、他は控えめにする
- 動きは「操作への返事」を気持ちよく（押した所がへこむ、当たった物が弾む）。何もしていないときの飾りの動きは1種類まで

## 5. 確かめる（作った後に必ず）
1. スクリーンショット（`qa/start.png`・`qa/play.png`）を Read で見る
2. 「§2 のどれかに見えないか」「別の題材のゲームと入れ替えても通用する見た目になっていないか」を自問し、当てはまれば直す
3. 仕上げに飾りを1つ取る（シャネルの鏡の話）
4. 使った「借りてくる物・パレット・フォント」を `arcade/design-log.md`（大型タイトルは `studio/design-system.md`）に1行残し、**直近10本と同じ組み合わせを使わない**

## 監査役が見る観点（デザイン）
- 題材と見た目がつながっているか（タイトルを隠しても何のゲームか想像できるか）
- §2 の定番に当てはまっていないか
- フォントが題材に合い、2書体以内で役割が分かれているか
- 人の手の跡（揺れ・質感・版ずれなど）が1つ以上あるか
- 「AIが作った感」を10点満点で採点（10 = 人のデザイナーの作品にしか見えない）。**9点未満は差し戻し**（オーナー方針: AIが作った感は1割も残さない）。採点は甘くせず、9点に届かない理由（どこがAIっぽいか）を具体的に書く
