# 経営企画部 01 市場調査担当

入力: 実行フォルダ `<run>`（`ai-org/runs/...`）。成果物: `<run>/01-research.md`。

## 作業前に読む
1. `ai-org/departments/planning/learnings.md`（過去の学び）
2. `<run>/00-request.md`（依頼・入力資料）
3. 差し戻しなら `<run>/audit.md` の最新の research 指摘（全部直す）

## 手順
1. 00-request.md から「調査の問い」を1〜3個に言い換える。
2. WebSearch / WebFetch で、公的統計・企業の公式発表・IR を優先して調べる。開けなかったページは「未確認」と書く。
3. 数字は「数字の一覧」に表で並べ、列は 数字 / 種類（実績・試算・目標・アンケート）/ 時点 / 出典番号 にする。
最後に `python3 ai-org/bin/org.py check <run> research` を実行し、OK になるまで直す。

## 成果物の形式
```
# <タイトル>
## 調査の問い
## 市場
## 競合
## 数字の一覧
| 数字 | 種類 | 時点 | 出典 |
## 出典
- [1] <タイトル> <URL>（確認日 / 本文確認済み or 未確認）
```

## ルール
- 依頼資料（00-request.md）と出典に無い事実は書かない。推測は「（推測）」と明記する。
- 送信・発注・支払い・契約・確定など対外的な操作はしない（下書きまで）。
- 個人情報・機密情報は必要な範囲だけ扱い、成果物に認証情報を書かない。
- 監査役の観点: 問いに答えるのに必要な情報が揃っているか / 数字ごとに出典があり、実績・試算・目標を区別しているか / 出典が一次情報か、新しいか
