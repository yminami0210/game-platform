# リーガルチェックリスト

このチェックは法的助言ではなく、リスクの洗い出しです。RED は人間の判断（必要なら専門家への相談）に回します。

## 1. 知的財産（コンセプト段階とリリース前）

- [ ] タイトル・ゲーム内の固有名詞で、同名/酷似のゲーム・アプリを検索した（ストア、itch.io、Steam、Web）
- [ ] タイトルが著名な登録商標と紛らわしくないか確認した（J-PlatPat、USPTO、WIPO Global Brand Database 等で検索し結果を記録）
- [ ] キャラクター・ロゴ・UI・画面構成が特定の有名作を連想させない
- [ ] 実在の人物・団体・ブランド・楽曲・キャラクター名を使っていない（使うなら理由と許諾の有無）
- [ ] 「〜風」「〜のような」を公開文言（README、OGP）で有名作の名前を使って言っていない
- 補足: ゲームのルールや仕組みそのものは一般に保護されにくい一方、グラフィック・音・テキスト・キャラ・名称の表現は保護対象になりうる。仕組みが似ること自体より、表現が似ることを重く見る。

## 2. ライセンス（素材・コード）

- [ ] `game/LICENSES.md` に全ての第三者物（ライブラリ、フォント、画像、音、コード片）が、名前・URL・ライセンス・表記義務とともに載っている
- [ ] コード中の外部URL・ライブラリ名を grep し、LICENSES.md に無いものがない
- [ ] コピーレフト（GPL/AGPL等）のコードが意図せず混ざっていない
- [ ] CC-BY 系ならクレジットをゲーム内か README に表示している。CC-NC や ND の素材は使っていない（改変・再配布の制約が強い）
- [ ] 生成AIで作った素材は、使ったツールと、そのツールの利用規約上の公開可否を記録した
- [ ] リポジトリ自体のライセンス（例: コード MIT、素材は別扱い）を決めて LICENSE ファイルを置いた（PM と相談し decisions.md に記録）

## 3. プライバシー・通信

- [ ] 外部への通信（解析、広告、CDN、Webフォント、API）が無い。あるなら何を送るかを README かゲーム内に明示
- [ ] 個人情報を集めない（名前入力やランキング送信があるなら、何をどこに保存するか明示）
- [ ] localStorage の使用は端末内のみであることを確認

## 4. ランダム報酬・課金・表示

- [ ] 有料要素は無い（ある場合は特定商取引法表示や決済規約など別途要検討 → RED）
- [ ] ランダム報酬（ガチャ的要素）がある場合: 無料でも確率を表示するのが望ましい。有料なら景品表示法（いわゆるコンプガチャの禁止など）や業界ガイドラインの観点で RED
- [ ] 「No.1」「世界初」など根拠の要る表現を公開文言で使っていない

## 5. 表現と年齢配慮

- [ ] 暴力・流血・恐怖・性的表現・ギャンブル的演出の程度を記録し、README に対象年齢の目安を書くか判断した
- [ ] 差別的・ヘイト的と受け取られうる表現、実在の宗教・民族・地域への揶揄がない
- [ ] 点滅（光過敏性発作）の強い演出を避けるか、演出を弱める設定がある

## 6. プラットフォーム

- [ ] GitHub の利用規約・GitHub Pages の利用上の制限（商用目的の主用途利用の制限、容量・帯域の目安など）の最新版を確認し、逸脱しない（確認日を記録）
- [ ] リポジトリに秘密情報（トークン、個人のメールアドレス等）が含まれていない（`git log -p` も含めて grep）
