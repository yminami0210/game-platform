# コンセプトの作り方 — 新規性と熱中度

## 熱中度はどこから来るか

「もう1回」を押させるのは、だいたい次のどれか（複数の重ね掛けが強い）:

1. **惜しさ** — 失敗が自分のせいだと分かり、次は行けそうだと感じる。原因が見える失敗、短いラン、即リトライ。
2. **上達の手触り** — 同じ状況で前よりうまくできた実感。腕が結果に反映されるルール。
3. **組み合わせの発見** — 要素同士の相互作用で、プレイヤーが自分だけの解を見つける（ビルド、連鎖、コンボ）。
4. **変化** — 毎回少し違う（手続き生成、ランダムな配り、ドラフト）。ただし運が腕を上回らない配分で。
5. **積み上げ** — 失敗しても何かが残る（アンロック、図鑑、永続強化）。惜しさと組み合わせると「1回だけ」が止まらない。
6. **ひと目で分かる目標** — 画面を見ただけで次にやりたいことが分かる。

熱中度を「時間待ち」「課金」「通知」で作る設計はこのスタジオでは採らない。GitHub Pagesで配る無料ゲームとして、純粋に面白さで戻ってこさせる。

## 新規性はどこから来るか

完全に新しいルールはまず無い。実用的な作り方:

- **掛け合わせ**: 既存ジャンルA × 異質なメカニクスB（例の形式: 「タワーディフェンス × 料理の火加減」「リズムゲーム × 地形の彫刻」）。掛け合わせたとき、Bが単なる飾りでなくAの判断を変えるかを確かめる。
- **定石の一つを反転**: ジャンルの当たり前（敵を倒す、上に登る、時間は進む）を一つだけひっくり返す。
- **スマホならではの入力**: 傾き、長押しの圧、2本指、画面の回転、マイクの息、時刻。ただし必須にせず代替操作を用意する。
- **制約から**: 「1タップだけ」「10秒で1ラン」「画面の半分しか見えない」。制約は発想を尖らせる。
- **世界観がルールを説明する**: ルールの奇妙さを世界の理屈で自然にすると、新規性が「分かりやすさ」に変わる。

新規性の判定は `gs-researcher` の調査で裏付ける。「似たものが見つからなかった検索語」も記録する。

## 人間へのインタビュー（Phase 1）

一度に3問まで。答えを待たずに先回りした提案をしてよい。聞く候補:
- 最近ハマったゲームと、ハマった瞬間（ジャンルでなく「瞬間」を聞く）
- どんな場面で遊んでほしいか（通勤中の片手、寝る前5分、友達と見せ合う）
- 絶対に避けたいもの（暴力、長文、運ゲー、など）
- 作りたい気持ちの種（アイデア、モチーフ、好きな質感）があるか

## 3案の出し方

案ごとに、以下をそれぞれ2〜3行で:
- **一行ピッチ**（15秒で言える）
- **新規性の一点**（既存作を名指しし、どこが違うか）
- **30秒のコアループ**（入力 → 結果 → 判断 → 入力…）
- **熱中の仕掛け**（上の1〜6のどれを、どう重ねるか）
- **見た目の一言**（スクショ1枚の想像）
- **技術リスク**（HTML5で重い処理、端末差の出やすい入力 など）

3案は方向を散らす（安全策/尖った案/掛け合わせ案）。似た3案では選ぶ意味がない。

## 合意後に concept.md へ書くもの

テンプレート `templates/concept.md` を使う。特に「スライスで確かめる仮説」と「代替コア」（スライスで面白くなかったときの第二案）は必ず埋める。代替コアがあると、Phase 3 で人間を呼ばずに方向転換できる。
